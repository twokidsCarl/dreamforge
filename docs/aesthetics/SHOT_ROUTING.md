## 宏观英雄资产 · 默认候选（效果优先）

> Carl 2026-10-23 原意：**说的是方法和心法——怎么出效果，又快又好又省。** 现在的问题是效果不好，不是「我说什么方法就用什么方法」。调研里的「小王子」只是例子，不是验收名号。

**适用**：可复用的宏观英雄（人物、小鼠等；E2 如 SF04/05/10 类）。微观机关、图解叠层不走这条。

**默认候选步骤**（配方 1 / 8 的效果优先写法）：
1. 锁参考图 + 三视图（外形先定，不狂生图）
2. Tripo / Blender 出模
3. Blender 渲染与参考图并排对比，一点点改材质 / 拓扑 / 相机
4. **定一个**可复用 3D 角色模型（全片复用，不逐镜重抽）
5. 用该模型渲镜头 → 最后微修

**生图角色**：只作定稿前的参考补丁；**不作**宏观英雄主引擎、禁止逐镜反复重抽刷分。

**为何通常又快又好又省（ROI）**：一次定模、全片复用；光影与运镜可控；避免「生图球团硬磨」导致的脸/毛皮颗粒、地面蠕动、镜间不一致和预算空转。

**验收（效果优先，配方名不是成功标准）**：
- 脸 / 毛皮无颗粒；地面不蠕动；资产可复用；同角色跨镜一致
- 达不到就改流程或换配方，**不刷分凑合**
- 若某镜上分层 / 2.5D / 实拍 / 其它路线更快更好且效果过线 → **用那条**，并记进试验记录；禁止把「小王子环」「配方 1」当验收口号

## 在试的配方
1. **先图后模，对着调**（宏观英雄默认候选，效果优先；名号不是验收标准）：定稿静帧/三视图 → Tripo/Blender 出模 → 渲染 ↔ 对照参考迭代 → **一个**可复用模型定稿 → 再渲镜头/动画。详见上节。
2. **先结构后风格**：专利图 / CAD / 论文示意图 → 准确渲染 → 再过生图做风格化 → 动画。适合光刻机等「结构错了就不行」的工业/光学题材。
3. **静帧 → 图生视频**：有机生命、氛围动作。
4. **分层做机关**：分子开关、离子路径等必须可控的节拍。

每期在视觉规范里写「镜头分流表」，并记一笔哪条配方在哪类镜头上赢了，回写进本标准和技能。

### 新增配方
5. **ComfyUI 静帧工厂（锁画风）**：工作流 JSON 进仓库；IP-Adapter（风格权重常 &lt;0.5）+ ControlNet（构图强度常 ≥0.7）+ 轻 img2img；出图先 staging，人审后再进成片。4090 本地批量，减少「每次 API 手感不一样」。
6. **万相 3.0 首尾帧（科学节拍）**：定稿起止静帧（同主体/镜头/灯光/画幅，无烧录文字）→ `wan3.0-video` → prompt 只写动作+运镜+秒级节拍 → 标注后期叠。适合视黄醛弯折、通道开合。注意：`first_frame`/`last_frame` 不能和 `reference_*` 同请求混用。
7. **万相 flash 有机试稿**：小鼠/衣藻/光波等 → `wan2.6-i2v-flash` 短试 → 好的再升 3.0 或分层抛光。
8. **多视角静帧 → Tripo/Meshy → Blender 对齐环**：2–4 视角输入；先 Smart/低模迭代；全角度检查背面；导入后修拓扑/UV；可选只重贴纹理；和原静帧并排一点点调。单视角背面会瞎编；薄结构/透明体先别指望一步到位。
9. **CAD/专利准渲 → ControlNet 锁几何风格化**：光刻机等工业/光学；几何板 A/B 对照，风格化不得改比例。
10. **灰模 360°/深度 → ComfyUI → 球面投影回场景**：片头棚、机台氛围 lookdev；相机基本钉在投影原点，不适合大范围推轨/环绕。
11. **本地 FLUX→Wan 单图**（NVIDIA/社区模板）：4090 上静帧+短片一条龙，先短、低分、关掉放大，基线通了再加。
12. **机关用代码/分层，生命用 I2v**（强化原默认）：Manim/分层保结构正确；Goodsell 静帧+万相保生命质感。别反过来。
