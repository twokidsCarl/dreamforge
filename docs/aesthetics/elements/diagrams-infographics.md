# 元素：示意图 / 信息图 / 标注

**状态：PARTIAL**

## 已锁定
- **示意图叠在真实画面上**，作为一层标注。禁止在纯色底上直接铺方框、箭头和文本框（PPT 感）。依据：Carl 的偏好 v1，以及否决 v7 时说的「示意图粗糙」。
- 每个形状、每种颜色第一次出现时都要有标注（SCALE_v2 H6：信息维度封顶 70）。
- 连线用缓动曲线「画出来」，不能整段直接冒出；至少一个元素在持续运动。
- 一帧最多 1 个标题加 3 个标注；画面上的字只写名词和数字；字幕放在深色底条上；小字不低于画面高度的 2.5 %。
- 化学式上下标要真排版（`shared/tools/richtext.py`），不要压平成 Sn8+ 这种写法。
