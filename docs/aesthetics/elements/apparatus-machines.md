## E1 锁定（Carl 2026-10-23：`2A+B`，原话「2 A和B（B做极细致和还原）」）
- **2A 白色产品棚拍**：只学布光、留白、地面反射和轮廓光（`k2A_studio_white_product_lighting.jpg`）。**不仿 ASML 外观和标志**。整机外观镜头、片名卡、转台展示用这一套光。
- **2B 去掉机壳的 CG 剖视，紫色光路贯穿各模块**（`k2B_cg_cutaway_violet_path_modules.jpg`、`k4A_cg_mirror_mounts_violet_bounce.jpg`）。Carl 特别强调：**B 要做极细致和还原**。硬要求：
  - 高密度、结构可信的多模块细节：光源腔、收集镜座、照明光学镜组、掩模台、投影物镜箱体、晶圆台、真空框架、管线、线缆、法兰、螺栓、肋板。
  - 紫色光束（`#8A5CFF`）在镜座之间清楚折返，每次拐弯都落在镜面上。
  - 金属是拉丝 / 阳极氧化 / 喷砂的真实材质，有倒角和环境反射；棚拍级轮廓光分层。
  - 简陋几何体（几块方盒、几个圆柱、散落镜片）一律算不及格：SCALE_E1 v2 的 A 维不得过 75。
- 落选：2C 洁净室组装实拍、2D 无品牌暗厅剪影（mock-up）。
- 跨集规则（**宏观工业设备**）：工业 / 工程类题材的机器一律走「2A 棚光 + 2B 高精度剖视」，白模只允许作为 2A 棚拍级产品材质（有倒角、面板分缝、AO），不允许玩具白模。生物实验装置（显微镜、光纤植入体等）仍按 E2 规则，可走插画家族。
