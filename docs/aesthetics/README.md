# EigenLens 频道审美校准库

为什么有这个库：Carl 的审美才是标准，我们自己写的量表不能替他判断（流程见技能 aesthetic-alignment-pick-pack）。每期开拍前，先拿选图包请 Carl 点选，点选结果锁进这里。各期的结果累积下来，以后的剧集**只问还没锁定的元素**。

## 目录

| 文件 | 内容 |
|---|---|
| `CHANNEL_PREFERENCES.md` | 跨剧集的口味：喜欢的家族、不喜欢的、尺度规则、Carl 原话，以及哪些是通用规则、哪些只属于某个题材 |
| `elements/*.md` | 每类可复用元素一份：锁定状态、已锁定的选择、锚点参考、反例、还没问过的问题 |
| `topics/<剧集>.md` | 题材专属的选择（只适用于这一期的元素） |
| `picks/<剧集>/` | 每期选图包：联系表 JPG（1280×720，压到 200 KB 以内）、`QUESTIONS.md`、`SOURCES.md` |
| `tools/sheet.py`、`tools/spec_<剧集>.py` | 生成联系表（16:9 深底，A/B/C/D，中文说明，MOCK-UP 和对照项角标） |

## 新剧集怎么用

1. 读 `CHANNEL_PREFERENCES.md`，再读各个 `elements/*.md`。
2. 从脚本和分镜列出 6–10 个躲不开的视觉元素，每个元素归到一个元素类型（标题卡、人物、机器、光束、分子原子、示意图、纪实、数据图表、片尾卡），归不进去的算题材专属。
3. 元素类型的状态是 **LOCKED**：直接沿用锁定的选择和锚点，不再问 Carl，只在题材文件里写怎么落到本期。状态是 **OPEN** 或 **PARTIAL**：做成选图包里的一张表。题材专属的元素一律要问。
4. 每张表 3–4 个真实顶级参考（工作室、研究机构、期刊、官方科普），先按 Carl 喜欢的家族筛，最多放 1 个对照项。没有真实参考时才用 image2 做 mock-up，并标明 MOCK-UP。每张图都在 `SOURCES.md` 写来源 URL。
5. 把表发给 Carl，每个元素一道多选题。**依赖未回答选择的画面不开工。**
6. Carl 答完后，在同一轮里：更新元素文件（状态改 LOCKED，写选中项、落选项、原话、锚点文件）；写题材文件；修订 `CHANNEL_PREFERENCES.md` 的版本号；再把本期量表（例如 `SCALE_E1.md`）的 100 分锚换成被选中的参考，落选的家族改成反例。
7. 以后 Carl 的每一次修正都在同一轮写成新版本（vN.1），量表锚点跟着偏好走，不能反过来。
