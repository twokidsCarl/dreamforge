### 频道级尺度规则（现行，所有题材默认）
- **微观事物**（蛋白、通道、离子、膜剖面、拥挤胞质、纳米机理、微生物内部等）：允许 Goodsell / 珠粒 / 球团颗粒插画。
- **宏观事物**（人物全身与脸、动物、笼具台面、仪器外观、器官外观、纪实场景）：必须写实或干净非颗粒风格；禁止把球团/珠粒颗粒感画在脸、毛皮、地面上。
- **图解 / 信息图**：可作叠层，压在微观或宏观画面上。
- **跨尺度**：用放大框或推镜过渡；同一画面不混用两种主体画法。
- **多风格切换是有意设计，不是风格不统一。** B 维判的是「尺度选用是否正确、过渡是否清楚」，不是「是否同一画法」。
- **全片美学**：有设计的多风格编排（微观插画 / 宏观写实或干净风格 / 图解叠层）。美学复杂但可量化；**单风格铺满 ≠ 好看**。「全片一种风格」本身记为美学失败（B ≤ 70，见各期量表）。
- **预览交付**：给 Carl 看的成片 / 串片必须带旁白与声音；无声预览不算有效交付。
- **运动质量红线**：主体脚下 / 周围地面、台面不得局部蠕动、沸腾、光流滑动。
- **验收门槛**（2026-10-24 评估流程 v3）：见 [`ACCEPTANCE.md`](ACCEPTANCE.md) / [`PROCESS_LOOP_v3.md`](PROCESS_LOOP_v3.md)。约 15 分钟有声全片；**成片只认观感门 L2（F1–F5）通看勾选**，废止五维加权冲 95；禁止大半旧画风拼片充数。
- **生图只做补丁、不作全片主引擎**（Carl 认可）：见 §5 通用规则。
- **宏观英雄资产生产心法**（Carl 2026-10-23：效果优先；小王子环 = 宏观默认候选，非教条）：见 §5；完整分流 [`SHOT_ROUTING.md`](SHOT_ROUTING.md)。

这与 §0 的 E1 双层系统一致：宏观工业 CG / 纪实 + 微观插画 / 电镜放大框。E2 生物题材同样按微观插画、宏观写实（或干净非颗粒插画）分工，不再强制整片一种画法。

## 4. 尺度规则（v1.2 / E2 PREFERENCES v1.3 现行）

- **微观**（分子、膜剖面、纳米机理、微生物内部）：**主语言 = Goodsell / good-feel 插画**（E2 锚 SF08e/SF09e）；同一段一致。**禁止**用真 3D CG 剖视顶替微观局部主画面（Carl 2026-10-24 t270；Cut7 漂移已否）。
- **宏观**（人物、动物、器官外观、仪器、纪实）：必须写实或干净非颗粒风格；禁止脸、毛皮、地面上的球团颗粒感。
- **细胞 / 组织**：按叙事是「内部结构」还是「外观器官」选微观或宏观语言；跨尺度必须用放大框或推镜。
- 跨尺度：用放大框或连续推镜过渡，不在同一画面里平铺两种主体画法。
- **B 维**：判「尺度选用是否正确、过渡是否清楚」，不是「是否同一画法」。宏观镜出现球团/颗粒插画 → A/B 硬扣（见各期量表）。
- 历史：E2 PREFERENCES v1.1 写「细胞及以上必须写实」→ v1.2 过调成「整片插画家族」→ **v1.3 作废整片插画家族，恢复按尺度多风格**。

## 5. 通用规则和题材专属规则

**通用（所有剧集默认生效）**
- 开头 10 秒内有片名卡，片名配主视觉，不用纯黑底白字。
- 每一镜的主体都对应当下那句旁白，误差不超过 0.5 秒；每个新符号第一次出现就要有标注。
- 禁止静止的纯字镜头，纯字最长 2 秒；字要压在有运动的画面上。
- 禁止白模和玩具道具：3D 一律给真实材质和环境光遮蔽，插画一律分 2–3 级明度。
- 示意图叠在真实画面上（细引线、圆点锚、半透明底条），不做纯色底上的方框箭头。
- 暗底不用纯黑（纯黑像素不超过 5%），主体有轮廓光。
- 一种叙事光只给片中的物理光用，不拿来当装饰色。
- 画面上的字只写名词和数字；一帧最多 1 个标题加 3 个标注。
- 片尾卡：eigenlens.ai 加一句号召，引导观众去本期互动网站；片中不提 token99（见 `elements/end-card.md`）。
- 配乐（非视觉）：要明亮、常规的科普配乐，例如温暖的纪录片钢琴加轻弦乐、轻快好奇的木琴、干净的电子琶音；不要暗、低、怪的底乐。风格由我们自己定，不用请 Carl 挑。

- **生图只做补丁、不作全片主引擎**（Carl 2026-10-23 认可）：image2 等允许用于缺参考静帧、微观定稿后少量补图、已授权的纪实底板；禁止用生图逐镜刷分、做宏观人物/动物主资产反复重抽、或无声串片当交付。全片主路径 = 宏观写实 3D/实拍/可控分层 + 微观程序化或定稿插画复用 + 旁白锁定的成片骨架装配。
