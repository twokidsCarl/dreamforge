## 0. v1.1 更新（E1 校准，2026-10-23）

Carl 对 E1 选图包 v1 的点选：`1C 2A+B 3A+D 4A+D 5A 6C+D 7A 8A+C 9A+B`，原话「2 A和B（B做极细致和还原）」。Vivian 同日拍板整片风格为**双层统一视觉系统**（详见 `topics/E1-euv-lithography.md` §2）。由此得到的跨集结论：

- **工业 / 工程类题材**（机器、工厂、交通、材料）采用：
  1. **高精度 CG 剖视**（Branch Education / 工业产品级）：去掉机壳，高密度、结构可信的模块、管线、镜座、真空框架，叙事光贯穿；白色产品棚拍只借布光、留白和轮廓光。简陋几何剖视和玩具白模是硬反例。
  2. **实拍质感纪实**：夜间货机钠灯、冷白光洁净室；Blender 做不到时用 image2 底板（+ Wan）。
  3. **局部科学插画 / SEM 放大框**：原子、纳米层、光子、跃迁这类微观机理，用圆形 / 局部放大框里的插画，或真实感电镜截面（能数层数），嵌在宏观 CG 画面里。
  4. **人物**：洁净服中景（两人行走）与人站在机器旁的尺度剪影；不出写实人脸。
  5. **片名卡**：白衬线短句 + 主角全景 + 人做尺度（1C）。
  6. **尺度对比**：3D 实物同屏（地球 / 月球 / 高尔夫球 / 芯片），不做纯深底极简线框（7C 反例），不做扁平剖面加文字（5C 反例）。
- **E2 的「整片一个插画家族」不推到工业题材**；反过来，工业题材的 CG 写实也不推到生物题材。两类题材共享的只有：暗底不用纯黑、主体轮廓光、叙事光只给物理光、标注叠在画面上、跨尺度用放大框。
- 两层共用一套色板和光比（E1：EUV 紫 `#8A5CFF`、激光橙 `#FF8A3D`、计量青 `#3FD6E0`，光比 ≥ 8:1）。

## 4. 尺度规则

- 分子尺度：允许 Goodsell 式；同一段里画法一致。
- 细胞及以上：v1.1 写的是「必须写实」，已被 v1.2 作废，E2 统一用插画家族。
- 跨尺度：用放大框或连续推镜过渡，不在同一画面里平铺两种画法。
- 同一画面里出现所选家族以外的画法（照片级写实渲染混进插画，或 PPT 式平面图解）→ 风格统一一维封顶 75。

## 5. 通用规则和题材专属规则

**通用（所有剧集默认生效）**
- 开头 10 秒内有片名卡，片名配主视觉，不用纯黑底白字。
- 每一镜的主体都对应当下那句旁白，误差不超过 0.5 秒；每个新符号第一次出现就要有标注。
- 禁止静止的纯字镜头，纯字最长 2 秒；字要压在有运动的画面上。
- 禁止白模和玩具道具：3D 一律给真实材质和环境光遮蔽，插画一律分 2–3 级明度。
- 示意图叠在真实画面上（细引线、圆点锚、半透明底条），不做纯色底上的方框箭头。
- 暗底不用纯黑（纯黑像素不超过 5%），主体有轮廓光。
- 一种叙事光只给片中的物理光用，不拿来当装饰色。
- 画面上的字只写名词和数字；一帧最多 1 个标题加 3 个标注。
- 片尾卡：eigenlens.ai 加一句号召，引导观众去本期互动网站；片中不提 token99（见 `elements/end-card.md`）。
- 配乐（非视觉）：要明亮、常规的科普配乐，例如温暖的纪录片钢琴加轻弦乐、轻快好奇的木琴、干净的电子琶音；不要暗、低、怪的底乐。风格由我们自己定，不用请 Carl 挑。

**E2 专属（不要带到别的题材）**
- 470 nm 青蓝叙事光、琥珀 590 nm、ChR2 薄荷青等分子配色。
- 小鼠的画法、诺奖得主肖像的配色、ChR2 和视黄醛的结构检查项。
