# 频道评估 × 迭代流程 · v3（Carl t269 · 2026-10-24；t341/t342 起为全频道操作规程）

**适用范围**：E1 光刻、E2 光遗传、以及之后每一期。这是持续生产的操作规程，不是某一刀的笔记。各期 `review/PROCESS_LOOP_v3.md` 只镜像本文件，不得放宽，不得另起一套流程。

目标：**标准做对 → 流程做对 → 无人盯着也能跑到「像好片」**，而不是跑到「局部指标好看」。

---

## A. 标准拆成三层（互不顶替）

| 层 | 管什么 | 产物 | 能抬「过线」吗 |
|---|---|---|---|
| **L0 工程 QA** | 黑帧、红牌、违禁词 OCR、死帧、音轨缺失、pods 泄漏 | PASS/FAIL | **否**（只一票否决） |
| **L1 单镜量表** | SCALE_v2 A–F + H1–H12 硬封顶；对 refs | REVIEW + 分数 | 样张轮可以；**不能**单独决定成片过线 |
| **L2 成片观感门** | F1–F5（主画面/向前运动/信息克制/30s 不像 PPT/工程否决） | 通看勾选表 | **观感过线可以；推送不可以**——全过只是进入 Checkpoint 交付门的必要条件 |

Cut7 错误：用「五维成片自评」把 L0 小技巧和 UI 覆盖率混进 L2，局部最优。

**新增硬封顶 H12**：成片 ≥50% 镜头带固定右上 PIP 或同构四角模板 → 成片不得报「好看/过线」。

## B. 迭代环（每刀固定四步，禁止跳步）

```
1 根因块（观众语言，3–6 条）
    ↓
2 改资产 / 动画 / 合成开关（每条根因 1:1 映射）
    ↓
3 双审：L0 QA + L2 通看勾选（抽帧≥1/20s 或密采样英雄段）
    ↓
4 仅当 L2 全过 → 才进入下方 Checkpoint 交付门；否则只内部改，开下一刀。L2 勾选本身不授权推送。诚实再通看分低于认可线，也不得走出这个门（t334）。技术四门全过也不走出这个门（t341）
```

硬规则：
- **禁止**用「加权总分 ≥95」代替 L2 勾选。废止的是五维加权冲分。**95–98 仍是诚实通看的偏好条**，不是这张加权表。表上填写的「≥95 / 96」没有这次诚实通看就作废。临时再推地板（例如 ≥90）不是这条偏好。见下方 t341。
- **禁止**制作方读自己的「已改清单」打 L2；L2 由独立通看（或抽帧审计脚本 + 人工/独立 agent）完成。
- 每刀必须写：`本刀优化了什么` / `本刀故意不优化什么（防局部最优）`。
- Carl 一票否决的观感（吓人、晃、PPT）→ 立刻升格为 H 封顶或 F 门，写入量表，下刀强制查。

### HARD · Checkpoint 交付门（Carl t327 · 2026-10-24）

**适用范围**：任何推给 Carl 的 Checkpoint——样段、低清全片、1080p，以及同类成片或样片。E1、E2 与之后每一期共用。

技术机器门单独**永远不能**授权推送。包括且不限于：字幕条、冻帧、音画抽样、抽帧脚本、L0 QA、L2 勾选表、`PUBLISH_GATE` 全 ✓、自评分数。这些只能拦截，不能放行。表上的「Vivian 主观 ≥95」或机器 `pass=true` **不是**认可。

**Checkpoint = Vivian 再通看之后亲自认可。** 顺序不可跳：

1. Vivian 用观众的眼睛通看完整条（全片，或这条 Checkpoint 的完整样段）。
2. 列出具体修改意见（观众能指出来的问题，不是机器分数）。
3. 改掉这些意见。
4. 再通看完整条。
5. 只有 Vivian 自己认可，且诚实再通看分不低于认可线，才可以把这条 Checkpoint 交给 Carl。认可要写明：再通看已完成，诚实分过线，这条可以交。

未认可、只通看一次、只靠机器门过线、或诚实再通看分低于认可线 → 不得推。口诀：**通看 → 改 → 再通看 → 认可才交。**

**常设环（t327，t341/t342 重申，不可跳）**：通看全片 → 列出修改 → 改 → 再通看全片 → Vivian 认可 → 才 Checkpoint 给 Carl。

### HARD · 声画同构 / VO–visual isomorphism（Carl HARD t353–t360 · 2026-10-24）

**出处**：Carl 对 E2 Cut10 Checkpoint B 低清全片前约 4 分钟的调片口述（t353–t360）。他要求的不是头痛医头的修清单，而是**捕捉并泛化审美**：画面与解说是同一件事的多模态说明。以下七条是**硬门（一票否决）**，叠加在 t327 / t334 / t341 之上，不替代它们。任一条失败 → **不得**因「整体感觉还行 / 技术四门过 / L2 勾选过 / 表上 ≥95」宣称可交 Checkpoint。

通看勾选（任一项否 → 诚实再通看不得报 ≥95 可交）：

1. **声画同构**：旁白说「开了 / 依次作用 / 放电 / 电压翻 / 光一开 / 泵在运」→ **同拍画面必须可见该事件在发生**。静板 + 动旁白 = 不及格。动效是多模态说明，不是摆设好看。
2. **粒子与标注有语义**：离子 / 质子 / 飞舞粒子必须几何对齐通道口、泵口或旁白所指路径；观众看不懂代表什么 = 失败。专名首次出现（如视黄醛）用**知识卡片**：中文名醒目放大 + 化学结构等，旁有指向；禁止只靠角落小字，禁止烧进底板的字随 Ken Burns / 放大移出画面。
3. **风格路由硬门**：平面程序简笔画 / PPT 图解（圆点脂双层 + 方块通道 + `V_m` 条一类）**不得当主画面**。微观主画面锁暮光 Goodsell / `SHOT_REDESIGN` 已定画风。制作偏轨进 `make_plates` 一类程序图解顶替 = 流程失败（制作偏轨 + review 未一票否决）。
4. **连续观看门**：开场运镜跳、人物裁切过大不完整、复用旧镜却不重新锚定（高亮 / 推近对齐当前旁白）——抽帧抓不到。**开场数秒与运镜段强制连播自审**（或稠密帧差 / 光流）；稀疏关键帧不算过此门。
5. **信息层次**：电压差等关键图解必须突出、直观，不得压在背景后当装饰。
6. **声情绪连续**：段落切换时音乐 / 旁白语气不得与前段脱节。
7. **片头身份**：logo + 片名是成片必有，不是可选项（与品牌 sting 一致；缺片头 = 不过线）。

**评价用法**：通看评分时以上任一条失败 → 不得宣称诚实通看 ≥95 可交；记为硬伤，内部改完再通看。案例锚点见 `episodes/E2-optogenetics/v8/review/cut10/CUT10_CARL_NOTES_20261024.md`。

## D. 反「讨好评估」（Carl 2026-10-24 t271）

根因：评估把「真实感 / 真 3D / 技术项」权重抬高后，迭代会反复讨好评分区——例如 Cut7 把已锁的 Goodsell 分子插图换成 `mol_retina_3d` 真 3D CG，分数涨了但风格漂了。

硬规则：
1. **评估不得奖励偏离已锁画法**。微观主画面偏离 Goodsell/SF08e·09e → H15 封顶，不得用「更真实」加分。
2. **禁止为冲维分改画法**。毛发/真3D/PIP/OCR=0 等技术项只作 L0/L1，不得驱动 L2 过线叙事。
3. 每刀自检必问：`本刀是否在讨好某条评分，而不是讨好观众与已锁美学？` 是 → 回滚该改动。

4. **禁止「样片墙」过线**：每镜局部都像那么回事，但**整片画面观感**沉闷/像展览/像样片连播（Carl t272）→ F6 否。用**叙事节奏与镜头变化**修，不得报过线。
5. 每刀自检必问：`通看完整故事线后，画面叙事方式是否仍像样片墙？` 是 → 改审美叙事方式，**不是**先砍章节时长。

## E. 整片优先于单镜（Carl t272 · **澄清 t293 / t295 2026-10-24**）

评估若只盯局部画面「像那么回事」，整片**画面体验**会失败（闷、展览感、样片墙）。

- L2 **F6 = 整片画面观感门（whole-film WATCH feel）**，不是片长门、也不是知识量门。
  - Carl t293：口误「石长城」=「时长」——他要的是**整个画面**通看的感觉，**不是**把片子剪短。
  - Carl t295：不满的是**审美叙事方式**（故事怎么被画面讲出来），不是长度，也不是知识多少。
- **禁止**把 F6 理解成「删章节 / 砍旁白 / 缩短到 X 分钟」。Cut9 误砍 ≈49% 故事线 → 作废该杠杆。
- 改刀默认：在**保留完整科学故事线与 VO** 的前提下，换叙事方式、节拍、镜头变化；避免同构展板循环与展览式多机位堆砌。
- **审美叙事方式**（Carl t295，t341/t342 写明做法）：SHOT_REDESIGN 的缩放链、一镜一概念、多风格过渡、连续因果运动。不满的是画面怎么讲故事。F6 只评整片画面观感。知识密度留着。
- 交付自述必须写：`故事线是否完整` + `通看后画面叙事方式是否像一部片（而非样片墙）`。只有 Carl **明确**要求缩短时，才动片长。
- **小鼠**：不得用同一段写实小鼠循环垫时长（t341/t342）。
