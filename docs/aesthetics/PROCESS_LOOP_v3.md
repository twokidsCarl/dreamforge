# E2 评估 × 迭代流程 · v3（提案 · Carl t269 · 2026-10-24）

目标：**标准做对 → 流程做对 → 无人盯着也能跑到「像好片」**，而不是跑到「局部指标好看」。

---

## A. 标准拆成三层（互不顶替）

| 层 | 管什么 | 产物 | 能抬「过线」吗 |
|---|---|---|---|
| **L0 工程 QA** | 黑帧、红牌、违禁词 OCR、死帧、音轨缺失、pods 泄漏 | PASS/FAIL | **否**（只一票否决） |
| **L1 单镜量表** | SCALE_v2 A–F + H1–H12 硬封顶；对 refs | REVIEW + 分数 | 样张轮可以；**不能**单独决定成片过线 |
| **L2 成片观感门** | F1–F5（主画面/向前运动/信息克制/30s 不像 PPT/工程否决） | 通看勾选表 | **是**——成片推 Carl 的唯一过线 |

Cut7 错误：用「五维成片自评」把 L0 小技巧和 UI 覆盖率混进 L2，局部最优。

**新增硬封顶 H12**：成片 ≥50% 镜头带固定右上 PIP 或同构四角模板 → 成片不得报「好看/过线」。

## B. 迭代环（每刀固定四步，禁止跳步）

```
1 根因块（观众语言，3–6 条）
    ↓
2 改资产 / 动画 / 合成开关（每条根因 1:1 映射）
    ↓
3 双审：L0 QA + L2 通看勾选（抽帧≥1/20s 或密采样英雄段）
    ↓
4 仅当 L2 全过 → 才允许「推 Carl」；否则只内部改，开下一刀
```

硬规则：
- **禁止**用「加权总分 ≥95」代替 L2 勾选。
- **禁止**制作方读自己的「已改清单」打 L2；L2 由独立通看（或抽帧审计脚本 + 人工/独立 agent）完成。
- 每刀必须写：`本刀优化了什么` / `本刀故意不优化什么（防局部最优）`。
- Carl 一票否决的观感（吓人、晃、PPT）→ 立刻升格为 H 封顶或 F 门，写入量表，下刀强制查。

## C. 反局部最优清单（写进工单，每刀自检）

不得作为「变好」证据（可报 QA，不可加分）：
- PIP / HUD / 小窗「覆盖了多少 SF」
- OCR=0、zero_steps、mean_diff>0 单独冲高
- 「有毛发 / 有真 3D / 有多机位」而无解剖与运动合格
- 与上刀比「维分 +X」但 F4 仍像 PPT

必须作为「变好」证据：
- 英雄特写并排（眼、脸、毛发）外行不吓人
- 运动曲线单调向前（yaw/walk 图）
- 同一时间码「去模板 vs 有模板」主画面更干净
- 通看 F1–F4 勾选全过

## E. 建议你拍板的三件事

1. 成片过线 = **仅 L2（F1–F5）**，废除五维加权冲 95。
2. 每刀强制「通看勾选」；无勾选不得推。
3. H12 + 反局部最优清单写入 SCALE / PREFERENCES，频道后续期数共用。

## D. 反「讨好评估」（Carl 2026-10-24 t271）

根因：评估把「真实感 / 真 3D / 技术项」权重抬高后，迭代会反复讨好评分区——例如 Cut7 把已锁的 Goodsell 分子插图换成 `mol_retina_3d` 真 3D CG，分数涨了但风格漂了。

硬规则：
1. **评估不得奖励偏离已锁画法**。微观主画面偏离 Goodsell/SF08e·09e → H15 封顶，不得用「更真实」加分。
2. **禁止为冲维分改画法**。毛发/真3D/PIP/OCR=0 等技术项只作 L0/L1，不得驱动 L2 过线叙事。
3. 每刀自检必问：`本刀是否在讨好某条评分，而不是讨好观众与已锁美学？` 是 → 回滚该改动。

4. **禁止「样片墙」过线**：每镜局部都像那么回事、整片却变长变闷（Carl t272）→ F6 否，内部砍料/重排节奏，不得报过线。
5. 每刀自检必问：`通看后，片子是变短了更好看，还是变长了更像展览？` 后者 → 回滚堆料。


## E. 整片优先于单镜（Carl t272）

评估若只盯局部画面「像那么回事」，成片会堆料变长、整体观感变差。

- L2 增加 **F6 整片时长感**：通看后若觉得变长/变闷/像展览 → 不过线。
- 改刀默认：**先砍与重排，再堆技术**。新增真3D/毛发/分子序列若拉长片感且不提高完播欲 → 回滚。
- 交付自述必须写：`本刀片长变化` + `通看后是否更想一口气看完`。
