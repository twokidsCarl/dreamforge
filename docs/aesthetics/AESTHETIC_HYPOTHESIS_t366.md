## 一句话

你要的不是「好看的科普片」，是**让人跟着旁白把道理想清楚**的片子。画面的职责是：在声音说到那一刻，把那个因果、那个开关、那个专名，变成眼睛也能核对的事实。装饰、气氛、复用旧美图，只要抢了「说明」的位子，都是错的。

## 四层（频道工作假说 · 已同意）

### 1. 同构优先于风格

风格（暮光 Goodsell、宏观写实等）是**约束，不是目标**。目标是：旁白的每一个「变化动词」在画面上有**同拍对应物**。没有对应，再精美也是空镜。反过来：有对应但画成 PPT 简笔画，也会否——因为不可信。**同构 + 可信材质成对，不可拆。**

与七硬门交叉：硬门 1（声画同构）+ 硬门 3（风格路由）。

### 2. 知识要「可指认」，不要「可装饰」

角标小字、飞舞粒子、烧进图里的字，都是假知识层：要么看不清，要么语义漂，要么一推镜就出画。专名首次出现必须像**教具一样被指着**：中文名够大、结构在旁、指线落到实体上。粒子必须走在孔 / 泵的几何里，否则**删掉比留着强**。

与七硬门交叉：硬门 2（粒子与标注有语义）+ 硬门 5（信息层次）。

### 3. 时间轴上的诚实

「跳一下」「光一开没变」「早期方案是静的」本质相同：时间在走，机制却停着。动画预算花在**机制节拍**上（级联点亮、开门、放电、电位翻），不花在 KenBurns 和氛围尘埃。复用旧镜可以，但必须在这一拍**重新锚定**「此刻在讲谁」。

与七硬门交叉：硬门 1 + 硬门 4（连续观看门）。

### 4. 成片要有身份与连贯的「语气」

片头 logo + 片名是频道身份，不是可选项。段落切换时声音情绪断裂，等于换了一个频道。人物裁切、多余鞭毛、拉丝伪影——罚的是**未自审**，不是某一个像素。

与七硬门交叉：硬门 6（声情绪连续）+ 硬门 7（片头身份）+ 硬门 4。

## 延伸（Carl t366 已同意一并采用）

1. **一镜一命题**：每镜进场时，观众应能在约 1 秒内回答「这镜在证明哪一句旁白」。答不出 = 镜废。
2. **反例库入门禁**：平面膜图解、语义不明粒子、静板 + 动旁白，应与「字幕色块」同级，列为**开拍前反例**，不是交稿后残留。
3. **专名卡片系统**：全片统一组件（视黄醛、ChR2、NpHR…）；首次大卡、再现小签；禁止每镜临时发明排版。
4. **B 段不要「另一部片」**：微生物史与 A 段实验的光、色温、音乐能量要有桥，不能像硬切纪录片。
5. **自审改连播抽样**：开场 10 秒、每个「动词旁白」前后 2 秒，强制连播；抽帧只做辅证。
