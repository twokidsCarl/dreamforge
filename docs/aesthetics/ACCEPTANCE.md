## 怎么评

**主评价 = 整段有声全片通看 + L2 勾选**；抽帧（≥1/20s）查硬伤。

1. 整段低清有声通看（或等价密抽帧审计）。
2. 勾选 F1–F5；命中 H12/H13/H14 直接失败。
3. **只修会掉线的硬伤**；每刀写根因块，禁止跳过通看勾选。
4. Carl 原话同回合升格为门禁（写入 HARD / SCALE，并写入频道 `PROCESS_LOOP_v3.md` / 本文件 / `WORKFLOW.md`）。一刀教训不留在该集笔记里就算完成（t331「复盘沉淀」）。
5. 通看时先抓一眼硬伤：实心字幕条、只靠 Ken Burns 的 PPT 式推镜、空笼、样片墙（t341/t342）。抓到就改，不留给 Carl。

### F6 整片画面观感门（Carl t272 · 澄清 t293/t295 2026-10-24）

**定义**：通看**完整故事线**后，整片**画面**的观感——是一部片，还是样片墙/展览。  
**不是**片长门，**不是**知识量门。误把 F6 当成「剪短」→ Cut9 已作废。

通看全片后勾选：
- [ ] 画面叙事方式连贯，不像同构展板/卡片连播
- [ ] 每一镜「都像那么回事」但连起来仍像一部片，不是样片墙
- [ ] 节拍有变化（不是同一段 Ken Burns / 多机位展览循环撑满章节）
- [ ] **故事线与知识节拍完整**（未为「过 F6」删章节）；若闷，改叙事方式而非砍时长
- [ ] 叙事走 SHOT_REDESIGN：缩放链、一镜一概念、多风格过渡、连续因果运动（t295 / t341）
- [ ] 没有用同一段写实小鼠（或写实活体）循环来垫时长

任一项否 → **L2 不过线**。禁止用「单镜都过得去」或「已经剪短了」证明成片过线。知识密度留着。F6 只评整片画面观感。

### 声画同构通看勾选（Carl t353–t360 · 叠加 t327/t334）

通看全片（或 Checkpoint 完整样段）时强制勾选；**任一项否 → 不得报诚实 ≥95 可交**：

- [ ] **声画同构**：旁白说开了/依次/放电/电压翻/光一开 → 同拍可见；无静板+动旁白
- [ ] **粒子与标注有语义**：离子/质子对齐通道或泵口；专名首次有知识卡片（中文醒目 + 结构）；无烧进字随推镜移出
- [ ] **风格路由**：主画面非程序简笔画/PPT 图解；微观锁 Goodsell / SHOT_REDESIGN
- [ ] **连续观看**：开场数秒与运镜段已连播（非仅抽帧）；人物裁切完整；复用镜已重新锚定当前旁白
- [ ] **信息层次**：关键图解（如电压差）突出直观，不压在背景后
- [ ] **声情绪连续**：段落切换音乐/语气不脱节
- [ ] **片头身份**：logo + 片名已接上
