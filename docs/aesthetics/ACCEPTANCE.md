# 验收自评（频道级 · Carl 2026-10-23 对齐）

**用途：内部。** 评价只给制作侧用；Carl **只看成片**，不看分数表、时间线图或刷分报表。

时间：2026-10-23 Asia/Shanghai。来源：Carl 对齐「你要到底要给我什么东西 / 评价怎么评、评什么、评到什么水平才给我」。

## 交付物是什么

推给 Carl 验收的只有一样：

**约 15 分钟、带旁白与配乐的低清全片小样**（成片体验）。

不算交付：中间刷分、无声串片、大半旧画风的骨架拼片、只嵌了几分钟新画面的「初剪充数」。

## 评什么（成片体验，不是单张样张）

1. **尺度美学**：微观插画 / 宏观写实或干净非颗粒 / 跨尺度过渡清楚。**全片一种风格 = 不过线。**
2. **主体质量**：人脸、毛皮无颗粒；地面、台面不蠕动；道具无玩具感。
3. **科学与旁白**：画面跟得上那句旁白；结构画对；新符号第一次出现有标注。
4. **运动与声音**：有持续运动；有旁白与配乐。**无声不算交付。**
5. **可看完**：约 15 分钟连贯，能当片子看完；不是碎片拼盘感。

细则与锚点见 [`CHANNEL_PREFERENCES.md`](CHANNEL_PREFERENCES.md)、各期 `SCALE_*.md`；本文件定的是**推验收前的门槛**，不是替代量表。

## 评到什么水平才推给 Carl

内部自评满意到大约 **95–98**（尺子：Branch / 好的 HHMI 等头部科普「能播」的感觉）才推验收小样。

- 够线 → 推约 15 分钟有声低清全片小样。
- 不够 → **内部接着改**；禁止拿「大半旧画风」拼片充数。

分数与缺陷清单不发给 Carl；他只看片，说哪里不对。

## 怎么评

**主评价 = 整段视频（有声全片）**；抽关键帧只做内部查硬伤（颗粒、地面蠕动、结构错），**不当验收主评价**；样张刷分已停。

1. 整段低清有声过一遍（成片体验，不是单张 contact）。
2. Claude（或同等）对照上面五条写缺陷清单。
3. **只修会掉线的硬伤**（尺度错、颗粒、地面蠕动、无声、科学错、玩具道具等）。
4. 再整段过一遍；仍不够 95–98 就继续内部改，不推。
