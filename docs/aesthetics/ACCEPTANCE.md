# 验收自评（频道级 · Carl 2026-10-23 对齐）

**用途：内部。** 评价只给制作侧用；Carl **只看成片**，不看分数表、时间线图或刷分报表。

时间：2026-10-23 Asia/Shanghai。来源：Carl 对齐「你要到底要给我什么东西 / 评价怎么评、评什么、评到什么水平才给我」。

## 交付物是什么

推给 Carl 验收的只有一样：

**约 15 分钟、带旁白与配乐的低清全片小样**（成片体验）。

不算交付：中间刷分、无声串片、大半旧画风的骨架拼片、只嵌了几分钟新画面的「初剪充数」。

## 评什么（成片体验，不是单张样张）

三层互不顶替（**2026-10-24 评估流程 v3 · Carl 拍板**）：

| 层 | 管什么 | 过线作用 |
|---|---|---|
| L0 工程 QA | 黑帧、违禁词、死帧、无声 | 只否决，不加分 |
| L1 单镜量表 | 各期 SCALE A–F + 硬封顶 | 样张用；不能单独决定成片过线 |
| **L2 成片观感门** | F1–F5（见下） | **推 Carl 的唯一过线** |

### L2 观感门（通看勾选，任一项否 → 不过线）

1. **F1 主画面**：像纪录片英雄镜头；宏观主体不吓人；小鼠眼在头骨侧眶。
2. **F2 运动**：连续向前；禁止镜头内周期左右回摆。
3. **F3 信息层**：默认无右上跨尺度 PIP；HUD 仅章节切换；禁止每镜四角贴满。
4. **F4 前 30 秒**：不会觉得在看 PPT。
5. **F5 工程**：违禁词/黑帧/死帧一票否决。

**废止** Cut5–7「尺度美学/主体/旁白/运动/可看完」五维加权冲 95。  
**H12**：≥50% 镜头固定右上 PIP 或同构四角模板 → 不得报过线。

反局部最优（不得当变好证据）：PIP/HUD 覆盖率、OCR=0、zero_steps、「有毛发/有真3D」、维分上涨但 F4 仍像 PPT。

细则见各期 `SCALE_*.md` §观感门、`PROCESS_LOOP_v3.md`。

## 评到什么水平才推给 Carl

**L2 观感门 F1–F5 全过** 才推约 15 分钟有声低清全片小样。

- 够线 → 推片（不推分数表）。
- 不够 → **内部接着改**；禁止「大半旧画风」拼片充数；禁止用加权自评冒充过线。

分数与缺陷清单不发给 Carl；他只看片，说哪里不对。

## 怎么评

**主评价 = 整段有声全片通看 + L2 勾选**；抽帧（≥1/20s）查硬伤。

1. 整段低清有声通看（或等价密抽帧审计）。
2. 勾选 F1–F5；命中 H12/H13/H14 直接失败。
3. **只修会掉线的硬伤**；每刀写根因块，禁止跳过通看勾选。
4. Carl 原话同回合升格为门禁（写入 HARD / SCALE）。

### F6 整片观感与时长感（Carl 2026-10-24 t272）
通看全片后勾选：
- [ ] 片子**没有**因局部堆料而感觉变长、变闷、变拖
- [ ] 每一镜「都像那么回事」但连起来仍像一部片，不是样片墙
- [ ] 删掉/压缩任一段不会立刻更想看完 → 说明该段在撑时长

任一项否 → **L2 不过线**。禁止用「单镜都过得去」证明成片过线。
