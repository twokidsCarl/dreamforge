## E2《光遗传学》v8 逐镜重设计：A0 · A · D 段

> 依据：`VISUAL_BIBLE_v8.md`（暮光 Goodsell、三尺度档 + 图解叠层、§4 硬标准、§5 动画标准、§5.7 取消 b 插）。旁白（vo）锁定不改字，只改画面。
> 「v7 时间」= v7 成片里的 t_film；v8 因片头标题卡（OPEN_00，约 5 s）插入，A0 之后整体后移约 5 s，以重新定时为准。
> image2 前缀：CORE = 宏观档，G = Goodsell 暮光档（`work/batch1.py`、`batch2.py`）。2D 合成 = `tools/sf.py`（浮点相机 warpAffine INTER_CUBIC、文字 2× 超采样、统一 `grade()`）。

### 段落总设计

### A0 冷开场（0:00–1:10）
- 一条主线：**一类神经元被挑出来 → 线索 → 设想 → 得主 → 开关 → 片名**。每镜都有「出处主体」：1979 配神经元群（SF02），微生物线配微生物（SF03），引文配 Crick 漫画头像（SF04），诺奖配三位得主头像（SF05），开关图解从 SF04/SF09/SF05 取元素（SF06），片名配主视觉（SF07）。v7 里的黑底纯字卡、HUD、蓝图全部取消。
- 颜色纪律：1979 和「只动一类」用**金色**选中，不用青蓝。1979 不能和光挂钩（README 钩子 1）。青蓝 470 nm 只出现在 OPEN_00 的光纤、SF03 衣藻受光、SF06 开关、SF07 光纤这几处光的事件上。
- 转场：OPEN_00 的单个亮神经元缩小，溶进 SF02 的神经元群（同一个细胞档）。A0_03a 回到同一群神经元（缩放贯穿）。A0_06a 片名之后，A0_91 从光纤尖端一路推进到膜，直接落到 A_01a 的首帧（宏观 → 细胞 → 分子）。
- 年份只放在角标或标注里（金色），不写年份差，口播和屏幕都不出现「47 年」。人名只在屏幕上出现，旁白不念。
- 5 个 b 插全部取消，A0_92 的年份翻牌也取消，换气停顿改成 a 镜尾部缓推。

### A 段 第一幕：相关 → 因果（1:12–3:02）
- 尺度路线：**分子（膜 · 锋电位）→ 宏观（记录 / 损毁）→ 细胞（一群细胞亮着）→ 细胞 + 图解（毫秒 vs 分钟）→ 分子（SF08 早期方案 → SF09 ChR2）→ 宏观（Tripo 小鼠 → 脑切面 → 下丘脑外侧细胞）→ 宏观（光纤小鼠 · 2007 实验）**。
- 神经元放电统一用暖橙 `#F0835B`。青蓝第一次作为「光打开通道」出现，是在 A_06a 的 ChR2 上。之前的 A_01a–A_05a 一律不用青蓝，这样观众会把「青蓝 = 光开关」记住。
- A_05a 到 A_06a 用同一块 Goodsell 膜做底：早期方案里那些「帮手」分子滑出画面，ChR2 留在中央（对上「不必再请一套帮手」）。v7 里白模工作台、方块通道这类画法全部废弃。
- A_07a 到 A_08a 用同一只 Tripo 小鼠（SF10）：A_07a 先从小鼠头部推进到脑切面，A_08a 拉回宏观，这时小鼠已经植入光纤。频率结论（5–30 Hz 与 1 Hz）作为图解层叠在实拍画面下沿，A_08b 的 HUD 卡不再单独成镜。
- 8 个 b 插全部取消。A_91 并进 A_92，A_92 作为 A 段的收尾和通往 B 段（微生物膜）的桥。

### D 段 尾声（13:31–14:23）
- 主线是**呼应开场**：D_01a 回到 SF02 的神经元群，用青蓝打开、琥珀关掉；D_02a 用 A 段的小鼠和 C 段的眼球（SF11）说明边界；D_03a 回到 SF04 的 Crick 头像和「相当牵强」；D_04a 回到 SF07 的主视觉和片名；D_92 推进到 SF09 的 ChR2，光灭，孔合上，结束。
- D_02a 两件「做不到」的事，不做成纯字卡，而是**长在画面上**：左边小鼠海马，右边眼球加护目镜，各自用一个「≠」引线标注。画面上的字只写名词。
- D_03a 的「相当牵强」只指 1999 那句，画面只用 SF04，不出现 1979 的神经元群和纸页，避免暗示 1979 说过光。
- 结尾淡到墨靛 `#0B1022`，不切纯黑，也不出下一期标题。4 个 b 插取消，D_91（复述能/不能）并进 D_02a。
