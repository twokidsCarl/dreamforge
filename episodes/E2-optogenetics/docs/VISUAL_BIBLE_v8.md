## 0. 一句话

**「暮光 Goodsell」**：深靛蓝底上的插画式 3D。分子用 Goodsell 的平涂和描边、按分子类型分色，宏观物体用有材质、有边缘光的电影级 3D。全片只有一种叙事光：470 nm 青蓝。

v7 的根本问题是十种画风轮换（documentary / hud / type / infographic / energy / blueprint / sem / xray / clay / photoreal），还有「不连续四镜同风格」这条规则。它让每一镜都像出自不同的片子，也让 2D 和 3D 割裂开。**v8 废除这条规则和这十种 style 标签**，改成一种画风、三个尺度档（第 2 节）。

## 1. 统一画风：2D 和 3D 怎样做到一体

| 手段 | 做法 | 为什么能统一 |
|---|---|---|
| 同一套光 | 主光暖奶油色（`#F4EFE6`，色温约 4500K）从左前上方来；边缘光冷蓝（`#7FA8FF`）从右后方来；叙事光青蓝 `#3FA9FF` 只出现在「光照到通道或神经元」的地方 | image2 的提示词、Blender 的灯位和 2D 合成时加的光，都照这一套写 |
| 同一套暗部 | 最暗处是 `#0B1022`（墨靛），**任何镜头里纯黑像素都不超过 5%**。合成阶段统一做暗部抬升（`grade()` 的 lift 参数是 0.043/0.062/0.133） | v7 里纯黑的 type 卡和灰白的 clay 镜头接在一起，是割裂感最大的来源 |
| 同一套表面 | 哑光、带细颗粒；关键物体加 1–2 px 的深色轮廓（`#2A2440`，不用纯黑）。3D 用 Principled 材质加 AO，不留白模；2D 插画用平涂再分 2–3 级明度 | 插画和渲染在「平涂 + 轮廓 + 体积光」这个交集上相遇 |
| 同一道后期 | 全片走同一套 `tools/sf.py: grade()`：抬暗部、暗角 0.25–0.35、胶片颗粒 σ≈0.015、glow 阈值 0.7 | 不同来源（image2、Blender、程序绘制）出片后再统一一遍 |
| image2 提示词前缀 | 写死成 `CORE`（宏观）和 `G`（Goodsell 暮光档）两段，见 `/workspace/e2work/v8/work/batch1.py`、`batch2.py` | 生图是统一画风的主要来源，前缀不准随镜头改 |

### 三个尺度档（取代十种 style）

| 档 | 用在哪里 | 画法 | 样张 |
|---|---|---|---|
| **宏观档** | 人、小鼠、眼球、脑、实验台 | 电影级 3D 或 image2 插画式 3D，浅景深，体积光 | SF01、SF07、SF10、SF11 |
| **细胞档** | 神经元群、组织、微生物 | 插画式 3D，Kurzgesagt 式的层次加 HHMI 式的光 | SF02、SF03 |
| **分子档** | 膜、通道、泵、离子 | **Goodsell 暮光版**：平涂、细深轮廓、按分子类型分色、拥挤；水相是深靛青，胞质是深梅紫 | SF08、SF09 |
| （叠层）**图解层** | 时间线、数据、概念关系 | 不单独成为一种画风，而是叠在以上三档的画面上：1 px 引线、圆点锚、小号无衬线，墨靛半透明底条 | SF06（全图解，但底是带漂移点阵的墨靛，不是纯蓝 blueprint） |

**档与档之间的转场用缩放（放大或缩小）贯穿**：例如从小鼠头顶的光纤推进到脑区，再推到神经元，再推到膜。不能硬切换画风。

## 3. 字体、标题与字幕

| 层级 | 字体 | 尺寸（以 1280×720 计） | 规则 |
|---|---|---|---|
| 片名 | Noto Serif CJK SC Bold | 104–118 px，字距 +18～+34 px（入场时从 +60 收拢到这个值） | 下面配英文 `OPTOGENETICS`，Noto Sans 16 px，字距 +4，用青蓝 |

## 4. 各类素材的硬标准

每条都是**检查项**，不过就退回重做。

### 4.1 分子 / 通道（Goodsell 暮光版）
- [ ] 平涂加 2–3 级明度，细深轮廓（`#1F2A44`～`#2A2440`），**禁止单色块拼成的通道**（v7 2:21 的蓝色方块柱）
- [ ] 一种分子一个色相（见第 2 节）。同一镜头里，膜、通道、离子、水相蛋白、胞质丝至少 5 类同时在场，体现拥挤（空白 ≤15%）
- [ ] 主角分子有叙事光照明，四周的配角分子降饱和、偏冷
- [ ] 结构要对：ChR2 画成二聚体，每个单体 7 次跨膜，每个单体里有一个视黄醛。泵和通道画法有区别（泵没有贯通的孔）
- [ ] 来源：image2 的 `G` 前缀生图（分子平面主图），或 Blender 按 PDB 坐标做原子球加轮廓渲染（需要转动时）。离子流**一律程序化叠加**（`sf09`：先用 inpaint 去掉烘焙在图里的离子，再按 24 fps 平滑移动）

### 4.2 细胞 / 神经元
- [ ] 胞体、树突要有体积和次表面散射，不是线框或剪影；树突逐级分叉，远处隐入雾里
- [ ] 「某一类神经元」统一这样表现：同一种形态（例如锥体神经元）点亮成金色（被选中）或青蓝（表达 ChR2 并受光），其余保持降饱和的灰紫（SF02 的做法）
- [ ] 至少 3 层景深

### 4.3 小鼠（Tripo 精模）
- [ ] 模型来源：先用 image2 生成 C57BL/6 小鼠侧视图（`mouse_ref.png`），再交给 Tripo v3.0 做 image→model，导出带 PBR 的 glb。**不再用参数化的胶囊小鼠**（v7 2:23、9:00 那种白色胶囊）
- [ ] 毛发：Geometry Nodes 毛发生成器（`/workspace/e2work/v8/blender/mouse_scene.py`）。按贴图过滤，只在深色毛区长毛，耳朵、尾巴、爪子、鼻子不长；毛长约为体长的 1%，朝向尾部，叠加噪声扰动；用 Principled Hair 的 melanin 参数化。**禁用老的粒子毛发系统**（长度参数不起作用，渲出来像湿毛团）
- [ ] 皮肤加次表面散射（耳朵透光）；眼睛要有高光
- [ ] 实验道具：陶瓷插芯、牙科水泥帽、光纤（光打开时整根导光，插芯处有青蓝辉光）、木屑垫料（Poly Haven `wood_chips`）、远处实验室的虚化光斑
- [ ] 毛色：C57 是黑褐，但不准让它糊进暗底。主光加冷边缘光，保证轮廓亮度比背景高 ≥40%
- [ ] 动作：用 Tripo 绑骨，本阶段已跑通（SF10）。步骤和踩过的坑：
  - `animate_rig` 必须同时写 `"rig_type":"quadruped"` 和 `"model_version":"v2.0-20250506"`（服务端会落到 v2.5 快照）。不写 rig_type 会默认绑成 biped，套 walk 以后小鼠翻身、悬空；v1.0 加 quadruped 直接失败
  - 动画用 `animate_retarget`，参数 `"animation":"preset:quadruped:walk"`、`animate_in_place:true`，原地走，位移在 Blender 里加
  - `preset:idle` 套在 quadruped 骨架上会失败。静止段改为：保持 walk 第一帧，用驱动器给脊柱骨加一个 ±3.5% 的呼吸缩放
  - 植入件、光纤端点、胡须都挂到 `tripo::Head_1` 骨骼上；光纤用 Hook 跟随，留出下垂的余量
  - 阶段 B 还要做：嗅探、冻结（恐惧条件反射）这两种动作。Tripo 没有对应预设，要在 Blender 里对现有骨架手调关键帧

- [ ] **本阶段的结论（独立审稿三轮）**：Tripo 精模加 GN 毛发的照片级渲染，三轮都被判为「产品截图感、和全片断裂」（68 → 69 分）。换成 image2 插画底图，同一机位出睡眠、醒来两张，用编辑接口保持一致，再做 2.5D 动画以后，画风才统一。阶段 B 的分工：

## 5. 动画标准

1. **24 fps，全部亚像素平滑**。2D 镜头一律用 `cv2.warpAffine(INTER_CUBIC)` 做浮点相机，文字图层 2× 超采样后再缩回。**禁止整数像素步进或按秒换帧**（v7 0:59 蓝图一格格跳，就是按段整帧切换）。
2. 所有出入场都要缓动（smoothstep 或 ease-out-cubic），时长 ≥ 0.5 s。连线和下划线要「画出来」。
3. 镜头总要动：推拉 ≥ 1%/s（一般 1–2%/s），或者平移 ≥ 0.3% 画宽/s。
4. **语义对应**：画面的主动作要和当下那句旁白对齐，误差 ≤ 0.5 s（例如「光一开」那一刻光纤亮）。标注出现的顺序也要跟旁白里名词出现的顺序一致。
5. **符号首次出现必须解释**：新形状、新颜色第一次出现时要有标注，或者旁白在同一句里说出来。
6. **前后关系**：每一镜都要能回答「这张图和上一句、下一句是什么关系」。做法是：要么延续同一个主体（缩放贯穿），要么画面里有承接元素（例如 SF06 里 Crick 的头像、ChR2、三位得主分别取自 SF04、SF09、SF05）。
7. b 插镜头（0.4 s 冻结帧）**取消**。需要换气停顿时，让 a 镜尾部继续做缓推，或者淡出到下一镜的首帧，不再做冻结帧。

## 7. 已知风险与边界

- **人物相似度**：第一版头像只凭姓名生成，独立审稿对照诺奖官方肖像发现两人不像（Deisseroth 画成戴眼镜、短发；Nagel 画成有头发、有胡子）。第三轮改为用文字写明可辨认的特征再生成：Deisseroth 是蓬乱深色卷发、胡茬、不戴眼镜；Hegemann 是后梳白发、细框眼镜；Nagel 是秃顶、眼镜、圆脸、无胡子。**不拿官方插画作图生图的参考**（避免二次创作他人作品）。阶段 B 发布前仍要人工核对一次。头像保持插画化，不做写实仿冒。
- **image2 的科学细节**：生图里分子的个数、螺旋圈数是示意。凡是旁白点到的结构事实（二聚体、7 次跨膜、视黄醛、孔道），生成后都要人工核一遍，不对就重新生成或局部修补（`sf09` 里的 inpaint 是先例）。
- **小鼠动作**：Tripo 模型目前是静态的，阶段 B 要绑骨（预算见 SHOT_REDESIGN_v8 末尾）。
- **工具链**：2D 合成 `/workspace/e2work/v8/tools/sf.py`、`sf_scenes.py`；生图 `tools/gen.py`（curl，按调用记账）；Tripo `tools/tripo.py`；小鼠 `blender/mouse_scene.py`。阶段 B 要把它们迁进仓库的 `shared/tools/` 和 `mograph/`。
