# 《光遗传学》v8 视觉拆解（对标 47 帧）

色值都是用 PIL 对每张图做 k-means 聚类得到的（缩到 160×90，k=6，按面积占比排序）。"暗端/亮端"指亮度最低/最高 2% 像素的均值。完整数据可以用 `python3 pal.py` 重新生成。

## 1. Kurzgesagt（r01–r05）
- **构图**：主体居中或落在三分线上，前景总会压一圈虚化或加暗的同类元素作框（r03 细菌、r04 前景细胞），所以至少有 3 层景深。r05 用分屏做 A/B 对比。
- **配色**：单帧以一个主色相为基调，再配一个互补色作高光。r04 暗紫 `#310140`/`#5B0347` 占 46%，主体暖橙 `#F0835B` 占 20%，亮端 `#F9CA5A`。r03 靛紫 `#290182` 占 34%，配橙 `#F6C374`/`#E98111`。r01 暗红地面 `#7A0C04` 对蓝紫人物 `#294176`/`#70A2CF`。平均饱和度（HSV S）198–224/255，非常高。**最暗处从不是黑**：r04 暗端 `#220034`，r03 是 `#120072`，r02 是 `#430037`，都是带色相的深色。
- **光照**：每个场景都有一个画内光源（烛光、发光体），主体带 1–2px 亮色边缘光，阴影用同色相加深一级的色块表现（不用灰色）。
- **材质**：纯平涂，加 1 层暗面和 1 层高光；用颗粒噪点或小圆点做纹理；没有描边。
- **信息密度**：每帧 1 个主体 + 5–15 个重复的小元素做环境，画面上几乎没有文字。
- **动势**：元素持续缓慢漂浮，镜头慢推，一个主动作配次级元素的跟随动画。
- **字幕/标题**：粗无衬线全大写白字，只出现在章节标题或缩略图上。

## 2. David Goodsell 分子画法（r06–r12）
- **平涂+深描边**：每个原子球平涂，只用 2–3 级明度表现体积（r12：`#85B9EB` → `#7195C2` → `#557095`），分子外轮廓是细深色线（暗端 `#435578`/`#220B1E`，不是纯黑）。
- **按分子类型分色**：一种分子一个色相，同一分子的亚基用同色系不同明度。膜磷脂偏暖黄/橄榄（r06 `#9A8F31`、r07 `#D6A440`/`#DCC66D`），胞质蛋白偏蓝紫（r08 `#5363CD`/`#334B7A`），胞外基质偏粉紫（r06 `#965881`），囊泡和内容物用亮橙（r09 `#F0AF32`）。
- **膜的画法**：场景图里，膜是两排紧密排列的头部（暖色）夹着一条浅色疏水带。单分子图（r10/r11）里，膜简化为一条中灰带（`#AFAEB0`），上下标注 Inside / Outside，蛋白（`#D6D2F7`、浅紫）贯穿灰带。**ChR2 镜头可以直接照这套模板画。**
- **拥挤度**：场景图几乎不留空白（r08 没有一个像素是"背景"），以此表现细胞内部真实的拥挤。远景分子用低饱和、偏冷的颜色。
- **背景**：单分子图用白底（`#FEFEFE`，占 35–52%）；场景图满铺。

## 3. WEHI / HHMI 分子电影（r13–r18）
- **构图**：分子特写占画面 40–60%，前景有失焦分子（景深 f/1.4 风格），背景是密集但虚化的分子场。
- **配色**：深底，但带色相。r15 深青 `#072A3E`/`#021C2E`，暗端 `#001426`。r13 深紫 `#1F0D2D`，暗端 `#18032B`。主体用 3 色编码（r14：铁锈 `#812F0B`、紫 `#7C54B8`、琥珀 `#C47615`，外加白 `#C0C7DD`）。HHMI 走浅色路线（r17 淡紫底 `#C1AEF6` 占 70%，主体是饱和的酒红 `#7E153F` 和墨绿 `#064D40`）。
- **光照**：一个主光加环境光遮蔽（AO），分子表面是哑光+次表面散射，发光元素（r15 黄线）当作引导线。
- **材质**：原子球表面有微粗糙度，**没有一个是纯白无材质的模型**。r18 的 ChR2 用了半透明蓝色螺旋+磷脂球阵列，可以作为最低基准。
- **字幕**：小号白色无衬线，放在角落，和画面同色调；比例尺写作 "x10,000"（r13）。

## 4. Nucleus 医学 3D（r19–r24）
- **光照**：暖色体积光+强次表面散射（r19/r20 主调 `#E29C50`/`#BC6F3D`/`#984B21`，亮端 `#FDED87`）。暗器官放在黑底上，靠菲涅尔边缘光勾勒轮廓（r22，暗端 `#000000`，边缘 `#D1CDD1`）。
- **材质**：组织半透明、湿润，有高光。血管壁半透明，能看见里面的血细胞（r21 `#692612`/`#E48E33`）。
- **构图**：浅景深加长焦压缩，重复结构（感光细胞）铺满画面。
- **标注**：衬线或细无衬线小字，配 1px 细引线；或者用半透明深色底条（r21）。亮背景版本用浅灰蓝渐变（r23 `#C2CEDB`→`#F3F4F6`）。

## 5. 3B1B / Primer / Nobel 科普图（r25–r29）
- **配色**：底色是近黑或深灰（3B1B 用 `#000000`/`#222222`，Primer 用 `#2E3136` 占 78%）。数据元素只用 1–2 个强调色（3B1B 青 `#57B5CA`、棕；Primer 蓝 `#3C7594`）。Nobel 科普图是中蓝 `#6090DC` 底，膜用暖灰 `#726D68`，离子用红 `#C37D7D`。
- **信息密度**：一个画面只讲一个概念，公式或数字本身就是视觉主体。用放大框（r28）连接宏观和微观。
- **字体**：3B1B 是衬线（CMU/LaTeX），Primer 是细无衬线标题 "Second trait: Size"。标题和画面元素用同色。
- **动势**：变换（transform/morph）替代切镜，元素从上一个状态生长出来，不用跳切。

## 6. 神经科技宣传片（r30–r34, r46, r47）
- **配色**：深海军蓝主调。r34 是 `#294162`/`#1A293F`/`#0F1826`，亮端 `#91B9EB`；r30 是 `#02020D`→`#16204F`，再加一处蓝色发光 `#4D69CE`。Neuralink 产品片反过来用高调白（r32 `#D0D0D7`/`#F3F3F6`，饱和度只有 13）。
- **光照**：产品片用柔光箱、大面积反光和干净的渐变。神经元场景用自发光+体积雾，暗部带蓝。
- **材质**：神经元表面有凸起的通道颗粒（r46）。植入体是金属+铜色（r47 `#452A0F`/`#664F39`）。
- **构图**：大量负空间，主体偏离中心，说明文字放在左上角，小号全大写（r33）。

## 7. 人物插画 —— Niklas Elmehed 诺奖肖像（r35–r37）
- **线条**：黑色笔刷线，粗细在 2–12px 之间变化（以 1600px 宽计）。头发和轮廓用粗的干笔触，五官用细线。
- **色数**：只有 3 个颜色：纸白 `#EDECE9`（占 63–68%），黑 `#201A16`，金 `#B8A88D`/`#AD946B`/`#9F8E72`。
- **明暗**：没有渐变，用金色平涂块表示受光或暗面，黑色块表示头发和深阴影。
- **用法**：三位得主统一用这一风格。片中如果改用深色底，可以把纸白换成 `#0F1826`，金色保留。

## 8. 片头 / 标题卡（r38–r42）
- 背景近黑，带青或蓝色相：Our Planet II 是 `#040506`+`#102D36`，3BP 是 `#0E0E0E`+`#1F2627`，Kurzgesagt 是 `#0C1339`/`#293A44`。
- 字标：宽字距（tracking +200 以上）的细体大写（Our Planet），或大号衬线句子（Veritasium "This is it."）。字的面积不超过画面的 15%。
- 画面里有一个发光主体（地球、光纤），标题叠在主体上或与主体并置。光纤镜头（r42 绿光 `#83D3AE`）可以直接借鉴到我们的蓝光光纤开场。

## 9. 实验室小鼠（r43–r45）
- 写实 3D（r43）：白毛有毛发系统和皮下散射，耳朵、鼻子、爪子是粉色，眼睛有高光。头顶有植入座和光纤，光纤末端发蓝光。背景是蓝色实验室虚化（`#182C40`/`#264461`）。
- 实拍基准（r44）：毛色是 `#D8CBC6`/`#A49B9E` 的暖灰白，**不是纯白**；蓝紫光 `#AF94ED` 照亮头顶。
- 扁平示意（r45）：白底细线小鼠和分子图标同处一画面，最多 4 种颜色。

## 10 条可量化规则
1. **背景永不纯黑**：最暗处亮度 ≥ 3%，并且带色相（例：`#0B1020` 深蓝、`#1F0D2D` 深紫、`#072A3E` 深青）。纯黑像素（RGB 全部 < 6）不超过画面的 5%，片头除外。
2. **每帧至少 3 个景深层**（虚化前景、清晰主体、虚化或低对比的背景），3D 镜头要开景深，2D 镜头前景要做模糊或加暗。
3. **禁止白模**：任何 3D 物体都必须有材质（粗糙度、次表面散射、颜色或纹理之一以上）。无纹理的纯白或纯灰模型一律退回。小鼠毛色用 `#D8CBC6` 一类的暖灰白，不用 `#FFFFFF`。
4. **蛋白、通道一律用 Goodsell 画法**：原子球平涂，每种分子 2–3 级明度，深色轮廓（`#2A2440` 左右，非纯黑），一种分子一个色相。ChR2 定为浅紫蓝系（`#D6D2F7`→`#7897C6`），膜头部用暖黄（`#D6A440`），疏水带用浅灰。禁止使用单色方块拼成的通道。
5. **一帧一个主色相加一个互补强调色**：强调色面积 ≤ 20%，主色系 ≥ 50%。光遗传的"光"统一用蓝 `#4D9BFF` 到青 `#7FD8FF`，"放电"统一用暖橙 `#F0835B`。
6. **主体必须有边缘光或自发光**：用亮度差体现，主体边缘的亮度比背景高 ≥ 40%（L 值）。
7. **画面里一直有东西在动**：任何镜头都不允许完全静止。至少要有粒子或分子漂移、镜头缓推（≥ 3%/秒的缩放），加上主动作。纯文字静帧最长 2 秒。
8. **字少且克制**：一帧最多 1 个标题加 3 个标注，标注用 1px 引线和小号无衬线，正文字面积 ≤ 画面 8%。中文标题统一用一套字体，标题字号 ≥ 画高的 6%。
9. **片头标题卡必须有**：近黑带色相的底、一个发光主体（光纤蓝光或神经元）、宽字距标题（字距 +200），时长 4–6 秒。三位得主的肖像统一用"纸白、黑、金"三色线描（金 `#B8A88D`），不用照片拼贴。
10. **信息密度分级**：细胞、分子场景要拥挤（空白 ≤ 15%，参照 Goodsell）；概念或图表镜头要留白（负空间 ≥ 50%，参照 3B1B 和 Primer）。同一镜头只能二选一。
