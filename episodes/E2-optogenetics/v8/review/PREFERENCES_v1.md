## 由此推出的统一画风（偏好层，优先于宪法旧条款）
- 全片主语言 = **电影级写实 3D**：真实材质（SSS、半透明膜、菲涅尔边缘光）、浅景深、体积光/雾、暗底（深紫/深青/近黑）里主体发光。
- 分子/通道：走 **WEHI/HHMI 电影分子**（r13–r16、r18），不再以 Goodsell 平涂为主；Goodsell 只作结构正确性参考。
- 器官/眼/脑：走 **Nucleus**（r19–r22）。神经元/脑：走 **G**（r30、r31、r33、r46）。
- 小鼠：随主语言走**写实 3D**（r43/r44 方向），不走扁平插画（r45）。
- 图解与标注：作为**叠层**放在 3D 画面上（细引线、半透明底条，见 r21/r23），不做独立平面图解镜。
- 2D 扁平/插画只允许少量用于：诺奖人物肖像（待 Carl 对 J 表态）、片头字标。
- 运动：持续缓推/环绕、景深拉焦、粒子与光的流动；禁止静帧。

### 全片美学原则（Carl 2026-10-23 原意）
「这么好看应该有个全片的美学，美学这件事情是很复杂的，但是它有量化的标准，如果全片都是一种风格，肯定在美学上不好看。」

落成可执行条文：
1. **全片美学 = 有设计的多风格编排**（微观插画 / 宏观写实或干净非颗粒 / 图解叠层等），不是单一画法铺满。
2. **「全片一种风格」本身记为美学失败**：同一期里宏观镜仍用微观颗粒插画，或整片无尺度切换 → **B ≤ 70**（见 SCALE_v2 H11）。
3. 美学复杂但可量化；**单风格铺满 ≠ 好看**。

### 核心规则（现行）

| 尺度 | 画法 | 禁止 |
|---|---|---|
| **微观**（蛋白、通道、视黄醛、离子、膜剖面、拥挤胞质、微生物内部结构等） | **主语言 = Goodsell / SF08e·SF09e good-feel 插画**（平涂明度、深轮廓、拥挤珠粒）；同一段内一致 | **禁止**把真 3D CG 剖视（如 Cut7 `mol_retina_3d` / `chr2_3d`）当分子局部主画面；Carl 2026-10-22「不用 3D 渲染真实的」+ 2026-10-24 t270 |
| **宏观**（人物全身与脸、小鼠、笼具台面、光纤插芯外观、组织/眼的器官外观、纪实场景） | **必须写实或干净非颗粒风格** | 禁止把球团/珠粒颗粒感画在脸、毛皮、地面上 |
| **图解 / 信息图** | 可作叠层（细引线、半透明底条），压在微观或宏观画面上 | 不做纯色底 PPT 方框箭头 |
| **跨尺度** | 用放大框或推镜过渡 | 同一画面不混用两种主体画法 |

- **人物**：可用干净插画（墨线 + 平涂色阶）或写实，但脸和皮肤**不得**有颗粒 / 爆米花 / 球团疙瘩。头发、衣服可保留适度质感。
- **小鼠**：写实毛发 / 写实 3D（回 v1 / v1.1 的 r43/r44 方向）；**球团小鼠作废**。
- **B 维判定（改）**：判的是「尺度选用是否正确、过渡是否清楚」，**不是**「是否同一画法」。宏观镜用了颗粒插画、或微观镜硬套照片写实、或跨尺度无过渡 → B 硬扣（见 SCALE_v2 H8）。
- **预览交付硬规则**：给 Carl 看的成片 / 串片必须带旁白与声音（可用 v7 音轨对齐）；**无声预览不算有效交付**。
- **运动质量红线**：主体脚下 / 周围地面、台面不得局部蠕动、沸腾、光流滑动；应用静态底板或整幅统一运镜（见 SCALE_v2 H9）。

### 生产路线 / 生图（Carl 2026-10-23 认可：「生图只做补丁、不作全片主引擎」）

样张阶段已证明：把 image2 等生图当全片主引擎会贵、迭代次数多、风格易漂，宏观还容易留下颗粒感和地面沸腾，难收。

- **生图不是全片主引擎。**
- **允许**：缺参考时的静帧；微观定稿后的少量补图；纪实底板（仅在 Carl 已授权时，如 E1 纪实可改 image2+Wan）。
- **禁止**：用生图逐镜刷分；用生图做宏观人物/小鼠主资产并反复重抽；把无声、无旁白的生图串片当交付。
- **全片主路径**：宏观 = 写实 3D / 实拍或可控分层；微观 = 程序化或已定稿插画资产复用；时间线以旁白锁定的成片骨架装配（先骨架，再生图补洞）。

### 宏观英雄资产生产心法（效果优先 · Carl 2026-10-23）

Carl 原意：方法和心法是**怎么出效果，又快又好又省**；当前痛点是效果不好，不是教条跟某个方法名。「小王子」只是调研例子。

- **默认候选**（可复用宏观英雄：人物/小鼠等）：锁参考图+三视图 → Tripo/Blender → 渲染与参考对比迭代 → **一个**可复用 3D 模型定稿 → 再渲镜头 → 微修。生图只作定稿前参考补丁，不作主引擎反复重抽。
- **ROI**：一次定模、全片复用、可控光影运镜；通常优于「生图逐镜刷」。
- **验收**：脸/毛皮无颗粒、地面不蠕动、可复用、镜头一致。达不到就改流程，不刷分凑合。
- **配方是候选**：某镜上分层/2.5D/实拍若更快更好则用那条并记试验记录；**禁止把配方名当验收标准**。完整步骤见 [`docs/aesthetics/SHOT_ROUTING.md`](../../../../docs/aesthetics/SHOT_ROUTING.md)。
