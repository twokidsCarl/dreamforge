## A. 标准拆成三层（互不顶替）

| 层 | 管什么 | 产物 | 能抬「过线」吗 |

## B. 迭代环（每刀固定四步，禁止跳步）

```
1 根因块（观众语言，3–6 条）
    ↓
2 改资产 / 动画 / 合成开关（每条根因 1:1 映射）
    ↓
3 双审：L0 QA + L2 通看勾选（抽帧≥1/20s 或密采样英雄段）
    ↓
4 仅当 L2 全过 → 才进入下方 Checkpoint 交付门；否则只内部改，开下一刀。L2 勾选本身不授权推送。诚实再通看分低于认可线，也不得走出这个门（t334）
```

硬规则：
- **禁止**用「加权总分 ≥95」代替 L2 勾选。
- **禁止**制作方读自己的「已改清单」打 L2；L2 由独立通看（或抽帧审计脚本 + 人工/独立 agent）完成。
- 每刀必须写：`本刀优化了什么` / `本刀故意不优化什么（防局部最优）`。
- Carl 一票否决的观感（吓人、晃、PPT）→ 立刻升格为 H 封顶或 F 门，写入量表，下刀强制查。

## D. 反「讨好评估」（Carl 2026-10-24 t271）

根因：评估把「真实感 / 真 3D / 技术项」权重抬高后，迭代会反复讨好评分区——例如 Cut7 把已锁的 Goodsell 分子插图换成 `mol_retina_3d` 真 3D CG，分数涨了但风格漂了。

硬规则：
1. **评估不得奖励偏离已锁画法**。微观主画面偏离 Goodsell/SF08e·09e → H15 封顶，不得用「更真实」加分。
2. **禁止为冲维分改画法**。毛发/真3D/PIP/OCR=0 等技术项只作 L0/L1，不得驱动 L2 过线叙事。
3. 每刀自检必问：`本刀是否在讨好某条评分，而不是讨好观众与已锁美学？` 是 → 回滚该改动。

4. **禁止「样片墙」过线**：每镜局部都像那么回事，但**整片画面观感**沉闷/像展览/像样片连播（Carl t272）→ F6 否。用**叙事节奏与镜头变化**修，不得报过线。与频道文件一致。禁止把 F6 读成片长门。
5. 每刀自检必问：`通看完整故事线后，画面叙事方式是否仍像样片墙？` 是 → 改审美叙事方式，**不是**先砍章节时长。
