## 1. 方法与测量

### 1.1 方法
1. 逐张看 png，与 sf08e / sf09e 两张锚图比较画法：原子球团簇、深色轮廓、2–3 级明暗、发光、暗紫/深青底。
2. 每条 mp4 抽 0.0/0.4/1.2/2.2/3.2/4.2 s 和末帧拼成 contact 图；SF08、SF10 另外每 0.5 s 抽一帧。可疑段再逐帧看：SF02 f88–97、f108–115；SF08 f78–106；SF10 f90–124、f160–199，以及 f97/99/101/103 的全分辨率帧；SF09 f0 与 f30 并排。临时文件在 `/tmp/claude-1000/r11rev/`。
3. 运动测量：灰度 → 缩到 480×270 → σ=3 高斯模糊；计算相邻帧差均值的中位数和最大值、d05（t 与 t+12 帧的平均绝对差）；尖峰阈值取 >4×中位数且 >1.0。ECC 缩放和 d05 均值/最小值用 `measure_push.py` 得到。
4. 文字：在 1280×720 png 上，每张取 2–4 处最小一级标注，按亮度阈值测字形行高；WCAG 对比度 = (L字 98 分位 + 0.05)/(L底 25 分位 + 0.05)。

## 4. 共性问题

1. **人物镜脱离插画家族**（SF04、SF05，部分波及 SF10 的小鼠）：球团马赛克纹理叠在近照片级明暗上，没有深色轮廓。这几张既不是 Elmehed 式版画，也不是 SF08/09 那种画法，是本轮 B 维被拉低的主要来源。
2. **字偏多**（SF04、SF11，以及 SF08 的时间轴面板）：信息都对，但这几张一帧超过「1 标题 + 3 标注」，C 因此停在 88–90。
3. **运动大多只是「推镜 + 出字」**：ECC 推镜大多在 3.3–4.2%/s，达标，但主体自身的动画少（SF04 人像、SF05 头像、SF07 脑基本不动）。只有 SF08、SF09、SF10 有真正的主体动作。
4. **生成式形变痕迹**：SF10 有溶解式起身、尾巴重影、缆线时隐时现，是目前唯一明显的「不连续」观感。
5. **小瑕疵**：SF05 底边暗带；SF08 背景暗污块；SF03 H⁺ 标注出现后又撤掉，末帧绿点没有说明。

优点（不扣分，记录在案）：没有任何硬封顶；科学事实与出处全部核对无误；对比度全部 ≥ 6.8:1；分子镜（SF06、SF08、SF09）已达到锚图水平。
