## 3. 硬封顶规则（命中任一条即封顶；可叠加取更严）

打分时先按画面给维分，再套本表。硬封顶**不是**建议，是强制。

| # | 触发条件（可检查） | 封顶 |
|---|---|---|
| H1 | 旁白中的**关键概念**在画面中缺失（例：说「膜蛋白」却只有整颗细胞、无线头指到蛋白） | **C ≤ 60** |
| H2 | **纯字卡**或**近静帧**（相邻 0.5 s 均值差 ≈ 胶片颗粒级、累计漂移平台）超过该镜头时长的一半 | **D ≤ 55** |
| H3 | **跳帧 / 步进动画**（蓝图分段跳、姿态瞬移、无插值形变） | **D ≤ 50** |
| H4 | **白模 / 玩具感小鼠 / 胶囊道具**（与 `r43`–`r45` 并排一眼业余） | **A ≤ 55** |
| H5 | **分子结构明显画错**且易误导（例：视黄醛画成两端芳香环≈偶氮苯；通道画成无孔方块） | **F ≤ 50** |
| H6 | **新符号首次出现**无标注/解释（观众无法从画面读出那是什么） | **C ≤ 70** |
| H7 | **片头无片名/主题**（开场一段时间观众不知道本期讲什么） | **E ≤ 50**，且**总分封顶 75** |

症状来源（抽查样本，不是穷尽清单）：片头无标题；图与旁白无关；示意图丑；打字机停半句；诺奖无漫画头像；蓝图跳帧；纯字静帧；白模；shape 无含义；蛋白丑；小鼠玩具感。原则：**头疼医头不够，硬封顶抬的是底线。**

## 4. 打分流程（HARD）

1. **材料**：只给审稿方 `refs/r01`–`r47`、本量表、`BRIEF`（旁白用途）、待评 png/mp4。  
2. **独立审**：审稿 agent **不得**读制作说明、PROMPT、前几轮 REVIEW 的「已改清单」。可对照 BRIEF 做语义检查。  
3. **同回合结账**：样张/渲染一更新，**同一回合**必须写出新 REVIEW 与分数。旧分年龄 >30 分钟且资产 mtime 已新 = **流程失败**（记入 STATUS/工单，不算有效分）。  
4. **禁止**用 sleep 轮询等子代理出分；等不到就本回合按量表自打并标明「主笔暂评，待独立复核」。  
5. 自评与独立分相差 **>5**（总分或任一关键维）：以独立分为准，并写分歧原因。  
6. **工程 QA**（黑帧、红牌、ASR、事实 yaml）与**审美分**分开报：QA 只给通过/不通过；审美分只按本量表。
