## 1. 方法

1. **静帧**：逐张看 png，与风格锚 `sf08e_relay` / `sf09e_chr2` 并排比较画法、轮廓、明暗与发光；结构对照 r06–r12。
2. **抽帧**：每条 mp4 抽 0.0 / 0.4 / 1.2 / 2.2 / 3.2 / 4.2 s 加末帧；SF08、SF10 另外每 0.5 s 抽一帧（SF08 共 20 帧，SF10 共 25 帧），拼成 contact 逐帧看。
3. **运动测量**（灰度，缩到 480×270，σ=3 高斯模糊以去掉颗粒）：
   - 相邻帧差 adj（中位数 ≈ 颗粒底噪）；0.5 s 漂移 d05（t 与 t+12 帧的均值差）；
   - 从 1.5 s 起的累计漂移（+0.5/+1/+2/+3 s），用来区分「慢动」和「平台」；
   - 1 s→末帧 ECC 仿射：缩放 %/s 与平移；
   - 尖峰：adj > max(4×中位数, 1.5)，出现尖峰时定位画面热区，区分跳帧和有意的闪光。
4. **字号/对比度**：在 1280×720 png 上截取各镜最小一级标注，按阈值求字高（占画高 %）和 WCAG 亮度对比度（字 98 分位亮度对底 40 分位亮度）。

### 逐镜说明

**SF01 片头（91.4）**：先暗场，再由右上光纤打出蓝光，被照到的一类神经元转成青色发光，片名「光遗传学」宽字距，副题「用一束光，只拨动一类神经元」，一画就讲清本期主题，对标 r42 光纤开场。扣分：神经元是柔焦的绘画笔触，原子球颗粒感和深色轮廓都弱于锚帧（A/B）；OPTOGENETICS 字高只有 2.1 %。

**SF02 1979（90.6）**：Goodsell 气泡质感的神经元网，一类亮橙、其余蓝紫压暗，两条引线各指一类，语义对得准。扣分：1.75–2.0 s 的点亮过渡太猛（d05 = 22，一下子跳亮），节奏偏急（D）；出处卡写「Francis Crick · 1979」，但旁白是「有人写下」，名字提前给了，问题不大。

**SF03 微生物线索（90.3）**：盐晶上的嗜盐古菌、带鞭毛和橙色眼点的衣藻，各配一个膜蛋白放大圈，两个年代标签，信息组织好。扣分：两个放大圈画法相近，「泵」和「通道」的差别要靠字读出来（C）；H⁺ 标注只闪现一下；画面里同时有 4 组文字，偏挤（E）。

**SF04 Crick 引文（89.3）**：金蓝版画肖像加引文排版，「理想的信号会是光 / 这个想法相当牵强」，原文 rather far-fetched 和 Phil. Trans. R. Soc. Lond. B 1999 出处都给了（F 高）。扣分：肖像是版画家族，旁边的神经元放大圈是 Goodsell 家族，两种画法同框，v1.2 允许肖像暂留，所以 B 不封顶，只扣分；前 1.2 s 只有年份在淡入（D）。

**SF05 诺奖肖像（87.5，未过单张线）**：三位得主版画头像、名字、各自贡献图标，「据诺贝尔奖官方新闻稿 · 头像为插画」写明了，诚实度好。主要缺口是 **D**：1.2 s 以后镜头缩放 0.02 %/s、平移约 1 px，整整 3.8 s 只有小图标逐个弹出，观感接近静帧（规则 7 要求 ≥ 3 %/s 缓推或可见漂移）。A/B：头像精致，但和片子主语言（Goodsell 分子插画）距离最远，靠背景同色调撑统一；顶部的 ChR2 小圆标太小，读不出是什么。

**SF06 开关（90.3）**：先抛问题「从设想到方法，中间缺什么？」，问号圈揭示成 ChR2 放大圈，再用引线连到神经元膜，「视黄醛：吸收光」「孔道：离子通过」两条标注，一画一概念。扣分：神经元是偏光泽的 3D 气泡质感，比锚帧更「渲染」（B 88）；放大框连到胞体的引线细，指向位置不够明确。

**SF07 主片名（89.6）**：分子拼成的鼠脑，顶部光纤打进蓝光，ChR2 放大圈加「这一期，就讲这枚开关」，片名居下，排版好（E 93）。扣分：脑的形状只是大致像鼠脑，左下嗅球与右上小脑的比例和位置偏怪（F）；1.2 s 时放大圈里先出现一团蓝色细胞，再切换成通道，语义上多了一步（C）。

**SF08 早期尝试（91.9）**：就是锚帧家族。路线一按步骤演示：感光蛋白接光、中间几步接力、通道最后打开、离子流入；横移转场到路线二：偶氮苯光开关、受紫光弯折、通道打开；底部时间轴对比「需要：毫秒级」和「多步接力：秒级」，把旁白讲透了。扣分：**E 87**，刻度字 1.9 % 画高（540p 约 10 px），而且全片文字最多（路线标题、2 条标注、时间轴框里 7 段字），超过规则 8 的「1 标题 + 3 标注」；5.0–5.5 s 偏静（d05 0.9）。

**SF09 ChR2（91.7）**：锚帧本身的动态版。蓝光约 470 nm 斜射，二聚体每个亚基各有一条发光孔道，视黄醛从直变弯，阳离子顺梯度流入。扣分：两条视黄醛的环端伸到螺旋束外缘、贴着脂质，实际应该埋在 7 次跨膜束中央（F 89）；「蓝光 约 470 nm」标注在 2.2–3.2 s 间被推出画外（C/E）；镜头只有 1.5 %/s（D）。

**SF10 小鼠（89.7）**：睡眠中，蓝光一串串短脉冲，放大圈里是「下丘脑外侧 · 食欲素神经元，膜上装了光控通道，随光放电」，「几十秒后」，小鼠睁眼、起身、走动，状态标签从「睡眠中」变成「醒来」再到「醒来后走动」。叙事完整，运动连续（D 91），和 Adamantidis 2007 的设定一致。扣分：毛发是颗粒笔触，背景笼舍偏糊，和 Goodsell 锚的清晰深色轮廓差一截（A 87 / B 88）；放大圈里的细胞读不出「这是神经元」，要靠字。

**SF11 眼与护目镜（89.9）**：眼球剖面，琥珀色光线经角膜、晶状体聚到中央凹；左上护目镜放大圈，右下视网膜放大圈：神经节细胞在最内层，AAV 紫色颗粒，感光细胞层灰化。光的入射方向和层序都对（F 91）。扣分：左上角有一块残缺的蓝橙月牙形，像另一只眼的边缘，是生成残留（A）；「感光细胞：已大量丢失」只停留约 1 s 就被推出画外；同时有 3 条标注加 2 个放大圈，偏满（E）。

## 4. 共性

1. **画法家族基本统一**：分子与细胞镜（SF02、03、06、08、09）稳定落在 Goodsell 锚家族；最弱的是两张版画肖像（SF04、SF05）和小鼠（SF10），与主语言距离最大。
2. **没有硬伤**：H1–H7 全部未命中，科学和标注诚实度普遍在 89–93。
3. **分数被 D 和 E 压在 90 上下**：多数镜头缩放 1.2–2.4 %/s，低于 BREAKDOWN 规则 7 的 3 %/s；关键标注常常在镜头推进中途被推出画外（SF09 的 470 nm、SF11 的感光细胞、SF03 的 H⁺）。
4. **字号**：主标题合格；最小一级标注在 2.5–2.6 % 画高，540p 样张上只有约 14 px，SF08 刻度更小。
5. 样张 mp4 是 960×540，png 是 1280×720，细节判断以 png 为准；成片需要按 1080p 复核。

## 5. Top-5 缺口（按对过线的贡献排序）

1. **SF05 运动（D 80 → 目标 ≥ 88）**：1.2 s 后给持续缓推（≥ 3 %/s），或者让三幅头像依次被光扫亮、加景深视差；图标弹出不能算镜头运动。SF05 只要 D 到 88，加权就能到 88.7，过单张线。
2. **全片缓推力度和标注留屏**：把 SF04、SF07、SF09、SF11 的缩放提到 ≥ 3 %/s，同时保证关键标注推进后仍在安全框内（470 nm、感光细胞丢失、H⁺）。这是均分从 90 到 92 最便宜的一步（D、C 各 +2～3）。
3. **SF08 字量和刻度字号**：时间轴刻度 ≥ 2.5 % 画高，并把 1 ms / 10 ms / 100 ms / 1 s / 10 s 精简成 3 个刻度；路线标题与时间轴二选一常驻。E 87 → 91，SF08 就能过 92。
4. **SF04、SF05 肖像向家族靠拢**：保留版画线，但加本家族的深色轮廓和柔和发光边，背景加一层 Goodsell 分子虚化底，B 86–87 → 90。
5. **小细节清理**：SF11 左上月牙残留；SF09 视黄醛埋进螺旋束；SF07 鼠脑比例（嗅球、小脑）；SF10 放大圈里的神经元形态要读得出来。

按上面 1–3 改完，预估均分约 92–93，最低 ≥ 88.5。
