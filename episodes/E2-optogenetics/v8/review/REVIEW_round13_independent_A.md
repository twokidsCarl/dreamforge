### 3.2 逐镜说明

**SF01 片头（87.8）** 片名衬线字、细线、副标、英文字距、期号层级清楚，点题准（蓝光束照出的青色神经元 vs 橙/紫其他神经元 = “只拨动一类”）。扣分：神经元画法是偏雾化的数字绘画，原子球团颗粒感、深色轮廓都比锚图弱，左侧半画面只是糊掉的底纹；光纤头被裁在右上角，读不出是什么器件。

**SF02 1979（89.3）** 神经元用球团堆成，深轮廓 + 亮橙发光，跟锚图是一个家族；“同一类 / 其余”两条引线标注正好对应旁白。扣分：亮度脉冲 2–3 帧就到峰值（帧 92–96、111–115 帧差 8–11），观感接近频闪；暗神经元团块密度高、偏糊，“其余神经元”与底纹区分度一般。

**SF03 微生物（88.4）** 嗜盐古菌 + 盐晶、衣藻 + 眼点，各配一枚膜蛋白放大圈，旁白“能被光推动的膜蛋白”直接画出来了；画法统一。扣分：衣藻放大圈里画的是 ChR 二聚体结构，1991–96 时这蛋白还没被认出来，有点时代错位（标签只写“感光蛋白”，算半诚实）；盐晶占左半画面，视觉重量压过了主题蛋白；底部两条字幕 + 两枚圈 + 两条引线，信息偏满。

**SF04 Crick 引文（87.6）** 引文、“相当牵强”、原文、出处都写准了（Phil. Trans. R. Soc. B 1999，“rather far-fetched”），F 高。脉冲序列 + 放电神经元小圈把“光一照神经元放电”补成了画面。扣分：球团拼成的肖像近于马赛克/像素画，和锚图那种有体积的分子团不是一回事；运动全组最弱（帧差中位 0.50，d05 最小 1.8），主体静止，全靠文字逐行出现撑节奏。

**SF05 诺奖肖像（86.5）** 日期、奖项、获奖理由、三人各自贡献 + 图标都齐，“头像为插画”诚实。扣分：三张肖像分辨率低、像素化，近看是拼贴马赛克，A/B 都受影响；开场 ChR2 圆图标一帧弹出（帧 1→2，差 5.5）；三栏对称排版偏“PPT 名片”，人物不动，只靠淡入。

**SF06 开关（88.7）** 先抛问号再揭晓 ChR2，视黄醛、孔道两条标注 + “装在神经元膜上”，概念链完整。扣分：神经元本体是偏 3D 光泽渲染 + 景深虚化，与放大圈里锚图式插画放在同一画面，家族一致性弱于 SF08/09；放大圈到胞体的引线是三条发散细线，指不出“膜上哪一点”；标题衬线字压在树突上。

**SF07 片名（85.7）** 片名和 SF01 呼应，“这一期就讲这枚开关”配 ChR2 圈，语义准。扣分：小鼠脑用均匀细珠点堆成，几乎没有深色轮廓和 2–3 级明暗，像珠子贴图，是全组离锚图最远的一张；解剖简化得有些怪（中线一个紫色团块，两半球形状不对称，中脑/小脑过渡含糊）；光纤插在皮层上，蓝色发光“神经网”没交代是什么。

**SF08 早期尝试（90.3）** 直接从锚图出来，画法满分档；两条路线标注、偶氮苯“受紫光弯折→通道打开”、接力光点依次传递，都能读。扣分：底部时间轴面板是半透明 PPT 式图表叠层，信息密度大（标题 + 两行图例 + 五个刻度 + 一行粉字）；路线二“几分钟”在 1 ms–10 s 轴上没有条，只能写成字，图表不完整；3.8–4.5 s 平移期间标签全部淡出，留下 ~1 s 无信息空档。

## 4 共性问题

1. **家族一致性呈梯度**：SF08/09（锚）> SF02/03/11 > SF06（3D 光泽神经元）、SF01（雾化数字绘画）> SF04/05（像素马赛克肖像）、SF07（珠点脑）、SF10（绘本鼠）。没有哪张触发 B≤75，但非膜镜头普遍缺深色轮廓 + 2–3 级明暗，B 卡在 84–90。
2. **人物/宏观物体的“球团化”做成了马赛克**：SF04/05/07 用小颗粒均匀铺满轮廓，缺锚图那种“大团块 + 团内细分 + 边缘描深”的结构层次，近看像像素画。
3. **运动在文字卡上偏弱**：SF04/05 主体静止，只有推镜（3.1–4.2 %/s）和文字淡入；SF05 有 UI 一帧弹出；SF02 有亮度频闪。
4. **信息密度偏高的叠层**：SF08 时间轴面板、SF11 中部标签、SF03 双圈双字幕，接近“标注打架”；字高下限 2.1–2.5% H，在 960×540 上约 12–13 px。
5. **拼接痕迹**：SF10 生成视频两段接缝没有做姿态衔接。
