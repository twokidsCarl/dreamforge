## 1. 方法与测量

- 抽帧：每条 mp4 抽 0.0 / 0.4 / 1.2 / 2.2 / 3.2 / 4.2 s 和末帧；SF08、SF10 另外每 0.5 s 抽一帧，拼成 contact 逐帧看。对尖峰附近（SF02 f92–99，SF08 f82–100，SF10 f96–150 / f210–225，SF03 f70–119）逐帧或隔帧放大看。
- 运动：灰度 → 缩到 480×270 → σ=3 高斯模糊。算相邻帧差的中位数、0.5 s 漂移 d05（第 t 帧与第 t+12 帧的平均绝对差）、尖峰（大于 4 倍中位数且大于 1.0）。ECC 仿射缩放用 `measure_push.py` 测（1 s 到末帧）。
- 字：在 1280×720 png 上，每张取最小一级标注的一行，用亮度阈值测字形高度（占画高 %），用 WCAG 相对亮度测对比度（字取 97 百分位亮度，底取中位数）。这是近似测法，字高会多算 1–2 px 的抗锯齿。

### 3.2 逐镜说明

**SF01 片头（91.9）**：Goodsell 式神经元网，光纤一束蓝光点亮一类青色神经元，橙色和紫色的没被点亮，“用一束光只拨动一类神经元”这层意思画面自己就讲清了。片名用衬线大字，下面有副题和英文。扣分点：左侧三分之一是偏暗、偏糊的底，密度和光影层次比不上 SF08/09 锚；页脚字偏小。运动是淡入加缓推，前 1 s 变化大，后段 d05 ~5–9。

**SF02 1979 请求（91.8）**：最接近锚帧的一张。颗粒化神经元，橙黄发光的和蓝紫不亮的对比清楚，两条引线标注“同一类神经元一起被点亮 / 其余神经元大体不动”，左上有出处条 Francis Crick · 1979 · Thinking about the Brain（与史实相符）。扣分点：闪光脉冲在 f95→96 一帧熄灭（diff 8.8），观感偏硬；被点亮和没被点亮的神经元形态一样，“一类”只靠颜色区分（可以接受，但 F/C 不给满）。

**SF03 微生物线索（89.3）**：左边嗜盐古菌趴在盐晶上，右边衣藻，各配一个放大框（泵 H⁺；眼点膜上的感光蛋白），底部两条年代说明。配色和轮廓都在家族内。扣分点：(1) 鞭毛有生成视频式的软形变，f101 左鞭毛末端多出一截断开的灰白残段，是看得见的瑕疵（D）；(2) 画面信息多，有两个放大框和 4 条标签，左上放大框的标签和 H⁺ 标签前后交替淡入淡出，中段有残影叠字（f77、f101 能看到半透明旧标签）；(3) 衣藻眼点画在鞭毛基部附近，实际眼点在细胞赤道附近，属于小的科学偏差（F）。

**SF04 Crick 引文（88.6）**：金线版画肖像加引文排版，层级清楚（1999 → 引文 → “他也承认” → “相当牵强” → 原文 rather far-fetched 和出处 Phil. Trans. R. Soc. Lond. **SF07 主片名（90.1）**：Goodsell 式全脑，光纤从顶部插入，脑里蓝色神经网络被点亮，右边放大框从细胞层推进到 ChR2 通道（1.2 s 到 2.2 s 两级放大），片名排版好。扣分点：脑的解剖说不清是哪个物种，外形像人脑半球，下面又粘了两个球状结构，看不出是小脑还是嗅球（F 87）；开头 0.5 s 偏慢。

**SF08 早期尝试（91.5）**：与锚帧同源。前半段用 ①②③ 三步标注多级接力，3.5–4.2 s 缓入缓出横摇到第二条路线：偶氮苯光开关拴在通道上，“受紫光弯折→通道打开”，离子穿过；底部时间轴对比“需要毫秒级 / 多步接力秒级”。科学上正确（偶氮苯 trans→cis 由紫/UV 光驱动）。扣分点：横摇峰值帧差 10.8，速度对 7 s 的镜头偏快；横摇后 ①②③ 标签消失，末帧（也就是 png）只剩“多步接力：秒级”这一行文字代表第一条路线；尾段 1.5 s 运动偏弱（d05 1.3–2.0）。

## 4. 共性问题

1. **整体在 90 档，不在 95 档**：Goodsell 家族已经贯穿 9/11 张，没有硬伤，也没有触发任何硬封顶。但除 SF08/09 外，细节密度和光影层次都比锚低一截。
2. **肖像两张（SF04/SF05）拉低均分**：版画肖像是允许暂留的 J 项，但在 B 维度上和家族不一致，运动又最弱，两张都只在 88 上下。
3. **运动多靠“缓推 + 出字”**：ECC 缩放几乎全是 +3.5%/s 的同一种推镜，镜头语言单一；画面内部的主体动作只有 SF08、SF09、SF10、SF11 有。
4. **生成视频的形变瑕疵**：SF03 鞭毛、SF10 眯眼和腿部重影。
5. **标签只是阶段性出现**：SF08、SF09、SF11 的关键标签在末帧消失，png 和末帧上的信息就不完整。
6. 字号统一，约 2.4–2.6% 画高，属于偏小但可读的档；SF05 页脚对比度 4.5:1 偏低。
