## 4. E1 视觉系统（B 维的依据）—— 双层统一视觉系统

| 层 | 管什么 | 画法 | 锚 |
|---|---|---|---|
| Macro | 整机、剖视光路、光源腔、镜座、pellicle、3D 实物尺度、货机、洁净室、洁净服人物 | 工业产品级高精度 CG + 实拍级材质灯光；2A 棚光；2B 极细致剖视 | k1C k2A k2B k3A k4A k5A k6C k7A k8A k8C k9A k9B |
| Micro | 等离子体跃迁、40 对 Mo/Si 截面、10 nm 线条、多层互连放大、光子计数 | 圆形 / 局部放大框里的科学插画，或真实感 SEM / TEM 截面；嵌在 Macro 画面上 | k3D k4D k6D |
| 标注层 | 数字、公式、谱线、标签 | 细引线 + 圆点锚 + 深色半透明底条 + 计量青尺寸线；叠在 Macro / Micro 上，不做纯深底整屏 | k7A（数字压在实物上） |

| 项 | 规定 |
|---|---|
| 底色 | 暗场：近黑冷蓝（#070B14 – #0E1424）；棚拍：中灰 / 冷白棚（2A），不用纯白 |
| 强调色 | EUV 紫 #8A5CFF ＝ EUV 光；激光橙 #FF8A3D ＝ CO₂ 激光；计量青 #3FD6E0 ＝ 测量 / HUD / 对准；线稿白 #E8ECF4 ＝ 标注 |
| 光比 | 主体亮部与背景 ≥ 8:1；轮廓光把主体从底里分出来；bloom 强度 0.25、阈值 2.0 |
| 字体 | 片名白色衬线（Noto Serif CJK SC Bold）；正文黑体（Noto Sans CJK SC）；数字等宽 DejaVu Sans Mono；上下标用 `shared/tools/richtext.py` |
| 标注 | 右上角，最多 3 行，≤5 s |
| 字幕 | 底部居中，字高约 4.3 % 画面高，**一律深色底条** |

## 5. 打分流程（HARD，同 SCALE_v2 第 4 节）

1. 审稿方只拿：本量表、`BRIEF`（每镜旁白和要讲的机理）、`refs/`（含 k* 锚与 x* 反例）、待评图片。**不读**制作说明、PLAN、GAP、改动记录。
2. 同回合结账：帧一更新，同一回合出 REVIEW 和分数。
3. 不用 sleep 轮询等子代理；等不到就主笔自打并标「暂评」。
4. 自评与独立分差 >5，以独立分为准并写原因。
5. 工程 QA（黑帧、ASR、事实 yaml）与审美分分开报。
6. 每轮出分后更新 `handoff/p1/score_timeline.png`，随汇报附上；交 Carl 时附 `calib_vs_roundN_comparison.jpg`（选中参考与新帧并排）。
