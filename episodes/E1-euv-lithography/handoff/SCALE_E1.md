# E1 评分量表 · SCALE_E1 v1（2026-10-23 生效）

E1《一台光刻机里发生了什么》风格帧、样片和成片的审美分一律按本文打。维度、权重、档位和打分流程沿用 E2 的 `SCALE_v2`（`/workspace/e2work/v8/review/SCALE_v2.md`），**锚换成 E1 的**，并加 E1 专属硬封顶 H8–H12。

**门槛**：风格帧轮和样片轮都是 **加权均分 ≥92 且单张/单段 ≥88**；低清全片推 Carl 前还要自评 ≥95（见 `E1_ACCEPTANCE.md` G3）。门槛是「可交 Carl 验收」，不是审美定稿。

**风格前提（Carl 2026-10-23 拍板）**：E1 保留「按问题选画面语言」（真实 / 剖视 / 蓝图 / 能量 / 显微 / 白模 / HUD / 信息图 / 排版 / 纪实），**不**改成 E2 的单一插画家族；统一靠一套色板和光比（见第 4 节）。所以 B 维看的是「多种语言是否同属一套视觉系统」，不是「是否同一画法」。

## 4. E1 视觉系统（B 维的依据）

| 项 | 规定 |
|---|---|
| 底色 | 暗色 HUD：近黑冷蓝（约 #070B14 – #0E1424）；白模/棚拍镜头用中灰棚，不用纯白 |
| 强调色 | **EUV 紫**（饱和，约 #8A5CFF）＝ EUV 光，片中说明一次「紫色是约定」；**激光橙**（约 #FF8A3D）＝ CO₂ 激光；**计量青**（约 #3FD6E0）＝ 测量、HUD、对准；**线稿白**（约 #E8ECF4）＝ 蓝图线和标注 |
| 光比 | 主体亮部与背景约 8:1 以上；轮廓光把主体从暗底分出来；bloom 强度 0.25、阈值 2.0（全片默认，逐镜覆盖要写理由） |
| 线宽 | xray / blueprint / energy 的线按 1080p 约 2 px 统一（`line_px = 1.3 × 高/540`） |
| 字体 | 黑体（Noto Sans CJK SC / Heiti），数字等宽用 DejaVu Sans Mono；上下标用 `shared/tools/richtext.py` 排 |
| 标注 | 右上角，最多 3 行，≤5 s，只在 3D 镜头上用；2D 图自带文字 |
| 字幕 | 底部居中，字高约 4.3 % 画面高，深色底条 |

## 5. 打分流程（HARD，同 SCALE_v2 第 4 节）

1. 审稿方只拿：本量表、`BRIEF`（每镜旁白和要讲的机理）、`refs/`、待评图片。**不读**制作说明、PLAN、GAP、改动记录。
2. 同回合结账：帧一更新，同一回合出 REVIEW 和分数。
3. 不用 sleep 轮询等子代理；等不到就主笔自打并标「暂评」。
4. 自评与独立分差 >5，以独立分为准并写原因。
5. 工程 QA（黑帧、ASR、事实 yaml）与审美分分开报。
6. 每轮出分后更新 `handoff/p1/score_timeline.png`，随汇报附上。
