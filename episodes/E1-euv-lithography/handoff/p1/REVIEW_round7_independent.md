## 三、逐镜评语

**A0_10 片名卡** — 冷白棚光，去壳的白色长机箱分成光源腔、照明、投影三格，紫光贯穿；两个白色洁净服人形加“人≈1.8 m”尺寸线；白衬线标题加英文副题。封顶：无（2B 组，见第五节）。
- 舱内模块是程序化散布的小方块和彩色线束，近看像随机堆出来的，离 k2B 的“每个件都能叫出名字”差一截。改法：换成 8–12 个可辨认的大件（真空泵、镜座框、工件台、线缆桥架），层层压出景深。
- 人形是光滑白模，接近玩具感。改法：换成有褶皱、头罩、面罩的洁净服人物（逆光，不露脸）。
- 机器是横排的单层，不是 EXE 的“掩模顶、光学中、晶圆底”纵向分层。改法：把投影格改成上下三层，掩模台在顶。
- 对应的 Carl 点选：1C + 2A/2B。离锚还差：k1C 的机器是高密度银色真机感，这里是白框加小方块。

**A0_01 冷开场锡滴** — 橙色激光打中锡滴 → 银色液态薄饼铺满画面 → 紫白等离子球，配 Sn⁸⁺–Sn¹⁴⁺ 圆形放大框。无封顶。
- 放大框里的离子标签被原子球压住（Sn⁸⁺、Sn¹²⁺ 看不全）。改法：标签挪到原子外侧，加深色底。
- 第三帧的等离子体只是一团发白的球，没有腔体的金属反光和喷嘴可读。改法：参考 k3A，让等离子辉光照亮收集镜边缘和锡滴喷嘴。
- 对应：3A + 3D。离锚还差：腔体硬件在虚焦里几乎消失，“真东西”的感觉不足。

**A0_02 货机夜装** — 雨夜机场，747 货机机头开着，升降平台在装白色铝框箱，地勤穿反光背心，地面湿反光。无封顶。
- 三帧只是慢推近加雨丝，运动偏弱（D 78）。改法：加升降台上升或叉车推进，机位做横移产生视差。
- 机身右上方有一个不明的小圆形 HUD 点，没有含义。改法：删掉或解释。
- 对应：8A。离锚还差：基本到位；只缺纪实感的手持微晃和人物动作。

**A0_03 数量链** — 湿停机坪上一排白色铝框箱，背后是货机和一排白色厢式卡车；标签逐个出现：250+ 箱 → 几架货机 → 20 辆卡车。无封顶。
- “43 个集装箱”只出现在文字里，画面上没有集装箱。改法：让一组箱子装进带货网的集装箱或托盘。
- 标签在左侧、同屏最多 3 个，违反“右上、≤3 行”的规定。改法：改成按顺序替换的右上计数器（等宽数字）。
- 对应：7A + 8A。离锚还差：数字没有落在可数的实物上（k7A 是数字压在实物上）。

**B1_10 预脉冲薄饼** — 激光打中锡滴后变成液态金属薄饼，侧视放大框里 25 µm 球 → 300 µm 薄片。无封顶。
- 同屏标签太多（右上标题 + 放大框里 2 个 + 框下 1 个）。改法：框下那条删掉，信息并进框内。
- 薄饼正面是平涂灰，缺液态锡的边缘张力高光和波纹。改法：加各向异性高光和边缘飞溅的细丝。
- 对应：3A + 3D。离锚还差：腔体背景太单一，看不出“光源腔里”。

**B1_15 镜面旁的等离子体** — 正面透过带螺栓的法兰看收集镜，镜面带中心孔，等离子体在中心孔右侧，周围飞橙色碎屑。无封顶（H1 已查：镜面可辨、有标注）。
- 等离子体明显偏在中心孔之外，不在光轴上的第一焦点，示意会误导（F 78）。改法：把等离子体放到中心孔正前方的光轴上，并带一点透视纵深。
- 镜面读起来像哑光蓝灰金属碗，不是“原子级光滑”。改法：加清晰的环境反射（法兰和孔的倒影），粗糙度压到接近 0。
- 三帧差异小（D 78）。改法：加缓慢推近和碎屑飞行的拖尾。
- 对应：3A。离锚还差：k3A 的腔体有大量管线和紫色辉光照亮的金属；这里只有一张镜面。

**B3_02 椭球收集镜** — 剖开的圆柱真空腔，左侧是金色背板的收集镜，标出中心孔、第一焦点、中间焦点 IF。无封顶（2B 组，见第五节）。
- 收集镜读起来像透明玻璃罩加金边，不像实心多层膜镜。改法：做成实心深色抛光镜面，背面是厚基底和冷却水道。
- 反射光被画成一个方柱形的紫色体积，而不是向 IF 会聚的光锥（F 80）。改法：从镜面边缘拉出会聚光锥，尖端落在 IF 上。
- 第一焦点上没有等离子体。改法：在焦点放一个小紫白辉光。
- 对应：2B + 3A。离锚还差：腔体结构偏空，k2B 的密度大约是这里的 3 倍。

**B4_10 地月高尔夫球** — 写实地球射出橙色激光到月球，最后落到月面上的高尔夫球。无封顶。
- 背景是纯深蓝空场，星空和尺度感偏弱。改法：加淡星场，地月之间加一条虚线距离尺。
- 高尔夫球的凹坑太浅，像白色乒乓球。改法：加法线细节和掠射光。
- 对应：7A。离锚还差：基本到位，材质细节差一截。

**B5_01 照明系统** — 剖视舱里粗紫光束经场分面镜（方形小镜阵）→ 光瞳分面镜（圆盘分面）→ 聚光镜 → 掩模，三个标注。无封顶（2B 组，见第五节）。
- 背景机械件还是重复的方盒和线缆。改法：换成镜座调节机构、真空法兰、冷却管等能认出来的件。
- 镜头运动偏小（D 84）。改法：沿光束方向缓推，让前景立柱产生视差。
- 光瞳面上的形状没有体现（环形 / 两极）。改法：在光瞳分面镜上点亮环形图案。
- 对应：2B + 4A。离锚还差：最接近 k4A 的一镜，主要差在背景密度和金属质感。

**C_03 长镜头** — IF → 照明（Z 字折返）→ 掩模（顶部斜入斜出）→ 投影，机位一路穿行。无封顶（2B 组，见第五节；画面上没有角度或倍率标注，H9 无）。
- 掩模画成黑色格栅风口，不像掩模版。改法：做成带图形面反光的方形掩模，装在掩模台夹具上。
- BRIEF 要求的扫描光带、实墙变成幽灵玻璃这次风格变化，三帧里看不到。改法：在中段加墙面溶解成半透明的过渡。
- 对应：2B + 4A。离锚还差：背景大面积是重复格板。

**B6_12 pellicle** — 灰色棚光里，掩模上方的黑框张着近透明的膜，上面落着颗粒，标出膜厚和间距示意。无封顶（无彩虹，H8 无）。
- 膜本身几乎看不见，只能靠颗粒推断。改法：加掠射高光带（参考 k5A），让膜有一层微微的灰透。
- 左侧 2 个标签加右上一个，信息偏多。改法：右上标题框合并进去，只留 2 条引线。
- 对应：5A。离锚还差：k5A 有手和边框尺度，这里缺尺度参照（可以加一只戴手套的手或一把尺）。

**B1_22 CO₂ 激光放大链** — 一排银色散热环状的放大器，橙色光束穿过，顶部的进度条从种子 ~W 亮到放大 4 数十 kW。无封顶。
- 放大器像弹簧或散热片，不像真实的 CO₂ 放大器（虽然标了“示意”）。改法：做成长方体机柜，配管路和观察窗，光束在机柜之间走。
- 左上进度条和右上标题框同时占满顶部。改法：进度条挪到底部字幕上方。
- 对应：3A（硬件）。离锚还差：设备工业感不足，台面太空。

**A2_08 193 vs 13.5 nm** — 虚焦的机内实景上，白色长波和紫色短波对比，标出 1 个 193 nm 波长 = 14 个 13.5 nm。无封顶（H14 已查：背景是实物虚焦）。
- 波形是平面 2D 线，没有和场景光照融合。改法：给紫色波加轻微 bloom，并让背景焦点慢慢推移。
- 右上第三帧又多出一个标签框，同屏 4 处文字。改法：只留两组。
- 对应：7A + 标注层。离锚还差：主要是标注层的精致度。

**B9_05 光子雨** — 晶圆光刻胶线条上落下紫色光子，圆形放大框里 1 nm² 网格中心格计数 3 → 16 → 20。无封顶（H15：有放大框和宏观锚）。

- 上方大面积是空的深底。改法：把投影镜底部或狭缝虚焦放进上方。
- 没有展示线边粗糙。改法：最后一帧让放大框里的线条边缘出现起伏。
- 对应：6D + 3D。离锚还差：k6D 的晶圆色彩和材质更丰富。

**B2_08 氢自由基清洗** — 收集镜表面 + 圆形放大框：H· → 抓住 Sn → SnH₄ 被泵抽走；左下是方程式，右上标注“深色斑点 = 镜面上的锡沉积”。无封顶（H6 已查：颗粒有说明；H10：H₂、SnH₄ 的下标正确）。
- 同屏 5 处文字（右上、框内、框下、方程两行），太挤。改法：方程只在框内出现，删掉左下的方程。
- 镜面上有多个孔洞，容易被误读成收集镜有多个孔。改法：只保留中心孔，其他泵口移到腔壁。
- 对应：3D + 4A。离锚还差：放大框的插画质感接近 k3D，宏观镜面材质偏灰平。

**B4_07 多层膜** — 镜子切出一块楔形，放大框指向镜面顶层的剖面，像 TEM 截面那样能数出约 40 对灰阶条纹，标注 Mo/Si ×40 对、每对约 7 nm、总厚约 0.3 µm。无封顶（放大框确实指向顶层膜）。

- 对应：4A + 4D。离锚还差：放大框达到 k4D；宏观材质差一截。

**B8_03 双台扫描** — 灰色立柱的空间里，两个开口箱体（照明、投影）里紫光折返，上方掩模台带刻度尺 2.0 → 4.4 → 6.8 格，晶圆台 0.2 → 0.5 → 0.9 格，标注 High-NA 约 5.4° 斜射、扫描方向 8×。**H13**。

- 读数比是 10 : 8.8 : 7.6，不是稳定的 8:1；晶圆台的位移在画面上几乎看不到（F 82）。改法：读数改成严格 8:1（例如 1.6/0.2、4.0/0.5、7.2/0.9），并给晶圆台加明显的反向箭头和位移。
- 掩模处的入射和反射在同一条竖线上，分不开。改法：把入射束和反射束各画成一条，夹角放大示意并标“示意”。
- 对应：2B + 4A。离锚还差：模块密度和机电件真实度远低于 k2B。

**B7_06 投影物镜棚拍** — 白棚转台上一个前盖拆开的立柜，紫光在 6 面镜间折返（放大计数确认是 6 次），旁边一个人形和“人≈1.8 m”。无封顶（2B 组，见第五节）。

- 对应：2A + 9B。离锚还差：k2A 的棚光更讲究轮廓光；k9B 是真人站在真机器旁边。

**B1_08 锡滴瞄准** — 腔壁前下落的锡滴，被青色 HUD 十字框逐个锁定。无封顶。

**D_07 洁净室** — 写实洁净室的长廊，左侧是高密度设备，两个洁净服人物走向黄光区，右上标“5100 家供应商”。无封顶（没有露脸、没有标志）。

**A0_06 供应商地球** — 半透明蓝色玻璃地球，从荷兰放射出光弧和光点，计数器 957 → 3,605 → 5,100（等宽字体）。无封顶（不属于 7C 线框：是 3D 球体，但贴近边缘）。

**A2_03 公式** — 虚焦的投影镜实景上，CD = k₁·λ/NA，λ 紫色、NA 青色，各项中文名，补充“k₁ 物理极限 0.25”和“镜子收光的锥角 → NA”的引线。无封顶（公式和中文名正确；k₁ 下标正确）。

- 对应：标注层 + 4A。离锚还差：轻微。

**B1_18 谱线** — 虚焦的光源腔和等离子体前，半透明面板里谱线逐渐堆成 13.5 nm 的峰，图例 Sn⁸⁺–Sn¹⁴⁺，标出“镜子反射窗口 ±1 %”。无封顶（H14：背景是实物）。
