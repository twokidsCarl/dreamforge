## 3. 逐镜意见

### A0_01（86.20）
画面：真空腔里一颗反光锡滴，标签「25 µm（头发丝约 80 µm）」。接着橙色激光锥打来，锡滴变成带 300 µm 尺寸线的波纹薄饼。最后是紫色等离子辉光，圆形放大框里有 Sn⁸⁺–Sn¹⁴⁺ 离子。
- 封顶：无。腔体能叫出名字的零件：观察窗法兰、气路接头、电缆、喷嘴管、紧固件块，约 5 种。
- 要改：
  1. 25 % 帧的锡滴是透明玻璃珠式反射，读起来像玻璃弹珠。改成不透明的液态金属：高 metallic、低 roughness，只反射环境。
  2. 「比头发丝还细」只有文字。在锡滴旁边放一根虚焦的头发丝做实物尺度（k7A 的读法）。
  3. 放大框里的「Sn⁸⁺」压在离子球上。把标签挪到球外，用细引线连回去。

### A0_02（89.90）
画面：和金控同一个场景，机位缓推，有视差，雨丝在动。字幕在 85 % 帧切到「运往美国俄勒冈」。
- 封顶：无。H2 不触发，三帧之间有真实推镜。
- 要改：
  1. 左下角的黑色人形剪影在三帧里都是一团糊。要么移走，要么加轮廓光，让它读得出是人。
  2. 主体机身亮部和夜空的光比可以再拉开一点，靠机鼻内的暖光做主光。

### A0_03（66.05）⚠ 本路最低
画面：真实感货机装货场景做背景。前景是米色纸箱堆、白方块、白卡车尾，上面贴三块数字卡「250+ / 43 / 20」。
- 封顶：**H4**。前景纸箱、白块和卡车尾都是默认材质的方盒，一眼就是道具，A ≤ 55。
- **硬伤**：三块数字卡下面的中文说明全是**豆腐块（□□□□）**，缺字形。E 按损坏档给 40，C 因单位或名词读不出也被拉低。
- 要改：
  1. **先修字体**：说明文字换成 Noto Sans CJK SC 渲染，应为「板条箱 / 集装箱 / 辆卡车」。这条修完 E 和 C 能各回升约 40 分和 15 分。
  2. 前景纸箱换成 F17 要求的白色铝框板条箱，带货网托盘；「20」换成真正的平板挂车模型，有轮子、挂车架和反光条。白块换成有波纹板和门锁杆的集装箱。
  3. 黄色「43」卡是高饱和柠檬黄，在系统色板之外。改成深色半透明底条加白字，数字可以用计量青强调。

### B1_08（86.70）
画面：俯视的锡滴流从喷嘴落下，青色瞄准圈逐颗跟踪，背景是虚焦的相机镜头和 LED 环，橙色虚线代表激光路径。
- 封顶：无。可叫出名字的零件：喷嘴、相机镜头、LED 照明环、法兰、线缆接头，约 5 种。背景没有重复铺格子。
- 要改：
  1. 「单独拍照」没有事件感。每颗锡滴进圈时给一次短促的青色闪光或快门框，再加一行很小的「t = … µs」读数。
  2. 锡滴同样有玻璃珠感，改成不透明的液态金属，同 A0_01。
  3. 两侧相机打出的青色视锥偏粗、偏亮，和瞄准圈抢戏。透明度降一半，并把两条锥收到瞄准点上，让观众看出相机对准的是锡滴。

### B1_10（86.40）
画面：橙色预脉冲打中锡滴，锡滴变成一张亮面圆片，配 300 µm 尺寸线；左边圆形放大框里并排放着 25 µm 点和薄饼侧影。
- 封顶：无。尺度对比做得清楚，放大框的用法对路（k6D）。
- 要改：
  1. 薄饼画成了厚实的凸面锅盖或轮毂盖，量表 §2.1 里「薄饼像玻璃片」那一条也适用于这种情况。改成极薄的扇出液膜：边缘破碎成细丝和微滴，中间半透着腔内的光（参照 A0_01 那张薄饼的边缘细节）。
  2. 薄饼法线应当正对激光来向（画面左侧），现在偏向镜头，读不出是被激光「拍」扁的。转 30–40°，在边缘留一点橙色余辉作因果提示。
  3. 55 % 帧的放大框里薄饼还没有标签，标签只在 85 % 帧出现。让「薄饼 300 µm」在形变完成的同一刻出现。

### B1_15（84.90）
画面：仰视收集镜内腔，镜缘有法兰和螺栓，橙色激光从中心孔射下，等离子点在腔内发光并有锡屑飞溅，下方是一大片紫色光雾。标签「收集镜」。
- 封顶：无。H1 已看：等离子体在镜面轴线附近，镜面有反射、看得出来，不触发。可叫出名字的零件：收集镜、中心孔、法兰螺栓、锡滴发生器喷嘴、观察窗或接头，约 5 种。
- 要改：
  1. 出射的紫光是一团没有边界的光雾，读起来像实心光柱或花瓶，看不出光锥向 IF 会聚。改成软边锥体，从镜缘收到画外一点，锥面亮、锥心稍暗，并加一个小「IF」锚点。

  3. 三帧几乎只有火花在变，机位位移很小，D 被拉低。1.5 s 内给一个明显的推镜或焦点从等离子拉到镜面。

- **D_07**：洁净室实拍质感，裸露的模块化机械排开，两名洁净服人物背影，黄光区做纵深，相当于 k8C+k9A。标签框中间空一行，像缺了一行字。

> 像素核对：`B9_05_0059` 与 `ctrl_B9_05_r22`、`D_07_0085` 与 `ctrl_D_07_r22` 只有噪点级差异（平均差 <1e-4），也就是同一画面。下面两镜的整镜分只因 25 % / 85 % 两帧和运动而与金控不同，单帧画质给的是同一档。

## 3. 逐镜意见

**A0_06**（infographic）：写实地球自转，荷兰节点放射连线到北美和欧洲的供应商光点，右上计数器 957 → 3,605 → 5,100。
- 55 % 帧的连线是贯穿球体的直弦，看着像从太空射出的直线（光在空中走直线，和球面没有关系）。**改法：所有连线改成贴着球面的大圆弧，抬高 3–5 %，末端落点加小圆点。**
- 光点是噪点状的一团，亚洲（日本、韩国、台湾）几乎没有点，地理分布容易误读。**改法：按区域分簇（欧洲最密、北美、东亚），点做成有大小层级的发光点，不要做成均匀噪点。**
- 地球贴图偏低清偏平，晨昏线和大气散射弱。**改法：加晨昏线一侧的轮廓光和城市夜光，让球体从底色里分出来（光比 ≥8:1）。**

**A2_03**（type）：公式 CD = k₁·λ/NA 叠在去壳机舱上（hexapod 镜座、线槽、管线、晶圆台环）。紫色光锥经两面镜会聚到晶圆，NA 锥角有标注，85 % 帧补「k₁ 物理极限 0.25」。背景是实物，不落 H14。
- 公式底板占了上部 1/3，盖住机舱上层结构，k₁ 在 25 % 帧半透明，像没渲染完。**改法：底板高度压到 ~18 %、透明度提高，k₁ 改成正常淡入，不要半透明残影。**
- 白色 X 形支撑件是平板片，有玩具感。**改法：换成带倒角和螺栓的阳极氧化支架。**
- 85 % 帧光束在上镜下沿折返，落点不够清楚。**改法：在折返镜面上加一个明确的高光落点。**

**A2_08**（energy）：虚焦的实物机舱前，白色 193 nm 波（2 个周期）和紫色 13.5 nm 波（约 29 个周期，比例对）逐笔画出，85 % 帧标「1 个 193 nm 波长 = 14 个 13.5 nm」。
- 三处标签分散在左上、右下、左下，眼睛要跳三次。**改法：193/13.5 两个标签贴在各自波形右端，比较句放到右上一处，总共 ≤3 行。**
- 波形是纯 2D 线，与 Macro 背景缺少联系。**改法：给紫线加 bloom 和极轻的景深，或让它投微光到背景镜座上。**

**B4_07**（sem）：一面切了扇形缺口的反射镜，紫光入射 / 反射落在镜面一点，放大框引线点在**镜面顶层的白色膜层**（符合检查点），框里是 TEM 风格的 Mo/Si 截面，85 % 帧标「钼/硅 × 40 对 · 每对约 7 nm · 总厚约 0.3 μm」（40×7=280 nm，自洽）。
- 镜体是平盘，不像曲面镜；剖切面是均匀灰（中性灰，配色合规），但没有材料感。**改法：镜面加轻微曲率，切面加基底（微晶玻璃）的细磨质感和倒角。**
- 光束是等宽管，入射点只是一团光晕。**改法：入射和反射改成锥形收放、软边，落点做成椭圆光斑。**
- 放大框刻度数字太小，读不出。**改法：刻度只留 2–3 个，字高 ≥14 px。**

**B4_10**（photoreal）：地球 → 月球 → 月面上的高尔夫球，白色激光一路追到球上；右上「< 0.1 nrad · 蔡司比喻」，85 % 帧标「直径约 4 cm · 尺寸示意」。
- 85 % 帧月面是程序化噪声地形：拉丝纹、浮空的石块、长条阴影，一眼 CG，是本镜 A 维的主要扣分。**改法：换真实月面 DEM 或摄影测量地块，石块落地贴地，太阳角压低，阴影边缘做实。**
- 高尔夫球的凹坑偏少偏大。**改法：换标准凹坑法线贴图，加一点次表面和接触阴影。**
- 25 % 帧的「地球」标签压在非洲中部，读法上没问题，但字号和「月球」不统一。**改法：统一标签样式。**

**B6_12**（xray）：仰视掩模台，蓝色冷却管和铜接头供到卡盘，图形面朝下的反射掩模，下方是带框的 pellicle，膜上有一道掠射高光（接近 k5A）。85 % 帧放大框给出「掩模图形面 / 间隙（几毫米）/ 13 nm 膜 · 间距不按比例」。
- 两条标签引线互相交叉，两个落点又都在同一片近乎透明的平面上，外行分不出哪层是膜、哪层是掩模。**改法：引线改成不交叉（掩模标签放左上），膜的落点放在掠射高光上，掩模的落点放在膜框之外露出的图形区。**
- 25 % / 55 % 帧膜与掩模之间看不出间隙。**改法：机位稍微侧一点，让膜框侧面和几毫米间隙露出来，膜边缘加一道细亮边。**
- 85 % 帧连框内一共 5 个标签，超过「≤3 行」。**改法：放大框出现时淡出上方两个标签。**

**B8_17**（infographic → CG）：投影镜筒下，紫色光锥会聚成狭缝落在晶圆上逐场曝光，右侧是晶圆片架，计数器 43 → 143/124 → 188 / 185+ / 3.4 万+。场格约 12–13 列 × 18–19 行，扣掉边缘约 190，和 188 相符。
- **零件辨识**：投影镜筒、晶圆盒 / 片架、线束 / 气路管、电源箱（三个圆形接口）、阀 / 气路面板、吸盘台，共 6 种；墙面没有同一种格子铺满。
- 晶圆是平涂浅灰网格，没有硅片的镜面感和场内图形；工件台是一块素方盒。**改法：晶圆换成镜面硅加细图形，已曝光的场微微变色；工件台加直线电机导轨、干涉仪反射镜条和线缆拖链。**
- 85 % 帧光锥消失、晶圆复位成全新，观众会以为结果被清空了。**改法：保留已曝光的晶圆移到片架，换新片时让光锥重新亮起。**

**B9_05**（energy）：光子雨落在紫色抗蚀剂线条上，放大框里 3×3 nm² 计数从个位数累积到约 20（14/23/19/20/26/22/15/18），85 % 帧补「剂量 ≈ 20 光子/nm²（示意）· 落点随机 → 线条边缘起伏」。数字和事实对上了。
- 光子画成拖尾的彗星 / 精子形，有点卡通。**改法：改成短促的点状闪光加极短拖尾，落地时出现一个小的吸收闪点。**
- 线条边缘起伏（LER）在宏观画面里看不出来。**改法：85 % 帧让放大框附近的一条线做出明显的粗糙边，和计数差异对上。**
- 背景的托盘边沿是单一灰色平面。**改法：加金属质感和轮廓光。**

**D_07**（documentary）：同金控画面，加缓推镜和人物行走，85 % 帧标签退场。
- BRIEF 要的「灯光一亮」三帧里看不出来。**改法：25 % → 55 % 之间让顶灯一排排亮起，或者从黄光区方向渐亮。**
- 标签框中间空了一行。**改法：删掉空行，或补一行「从光学到真空泵」之类的子说明。**

## 4. 本路最值钱的改法

1. **B4_10 月面重做**（A 78 → 约 88）：换真实月面地块，石块贴地，阴影做实。这是本路单项涨分最多的地方。
2. **光束统一成锥形收放 + 软边 + 镜面椭圆落点**（B4_07、A2_03、B8_17）：把剩下的等宽管和光在空中折返的读法去掉。
3. **标注卫生**：B6_12 交叉引线、B6_12 和 A2_08 标签超过 3 处、D_07 标签空行、B4_07 刻度太小。全部是小改动，每镜 E 维约可加 3–5 分。
4. **A0_06 连线改成大圆弧 + 光点分区成簇**：去掉「直线穿球」的错觉，C、F 维各加约 3 分。
5. **B8_17 晶圆和工件台加细**（镜面硅、已曝光的场变色、导轨 / 干涉仪 / 拖链），再保留曝光结果，A、C 维各加约 3 分。
