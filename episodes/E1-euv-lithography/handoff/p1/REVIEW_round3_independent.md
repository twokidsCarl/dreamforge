## 结论

- **加权均分 82.18**，**最低 B8_03 = 72.2**；只有 D_07（88.5）一镜够得着单张 88。

- 命中硬封顶：H13 ×4（A0_10、C_03、B8_03、B7_06），H1 ×1（B1_15），H6 ×1（B2_08），H14 ×1（B1_18）。H2、H3、H4、H5、H7、H8、H9、H10、H12、H15 都没有命中。

## 逐镜

**A0_10 片名卡**：白色框架整机去壳，从左到右是光源腔、中段光学舱、右侧光学舱，舱内有紫色光束；地面反光，两名白色洁净服人物站在机前；上方是白色衬线片名、紫色下划线和英文副题。
- 封顶：H13，A ≤ 75。中段和右舱的紫光是几块散乱的半透明板，拐点处看不出镜子；右舱只是一团紫雾，读不出连续的一条光路。
- 改法：① 全机只走一条连续紫色光路（光源 → IF → 照明 → 掩模 → 投影 → 晶圆），每个拐点放实心镜加镜座；② 把舱内模块密度提到 k1C 那种管线、法兰、线缆的水平，减少空白隔板；③「人 ≈ 1.8 m」标签从画面中央挪到右上角或人物旁的小引线，现在它压在机器上；人物换成逆光剪影，去掉白模人偶感。
- 对应点选 k1C + k2B。离锚差在：k1C 的机身满是可信细节、人物是剪影，本片舱体偏「娃娃屋」，光路散。

**A0_01 冷开场锡滴**：橙色激光打中锡滴，锡滴被拍成带飞溅的薄饼，最后成为紫白色等离子体，并弹出 Micro 圆框（Sn⁸⁺–Sn¹⁴⁺）；背景是虚焦的金属腔体。
- 封顶：无。
- 改法：① 薄饼现在是黑色塑料感，改成液态锡的银色高反金属，带菲涅尔高光；② 放大框里的离子插画细化到 k3D 的绘制密度（加电子轨道和跃迁光子），现在是简单圆球；③ 第一帧锡滴已经在发光，应先给一帧干净、银亮的完整锡滴作谜面。
- 对应点选 k3A + k3D。离锚差在：腔体金属细节和等离子辉光层次不如 k3A。

**A0_02 夜间货机**：雨夜停机坪，747 货机机头打开，升降平台上装着铝框箱，有地勤人员、湿地反光，右上角是标注卡。
- 封顶：无。
- 改法：① 三帧几乎只靠极慢推镜和雨丝在动，应加明确的推轨或横移视差，并让升降平台或地勤动起来；② 雨丝是平面叠加，换成带景深的雨；③ 左下角黑色人影剪影被字幕条切掉一半，挪开或删掉。
- 对应点选 k8A。照片感接近 k8A，差在运动和雨的合成感。

**A0_03 数量链条**：一排白色铝框箱延伸到画面深处，背景是货机和卡车；标签依次出现「250+ 个」「几架货机」「20 辆卡车」，右上角有链条汇总。
- 封顶：无。
- 改法：① 画面里看不到「43 个集装箱」，补一排集装箱或货网托盘，让每一级都有实物；② 标签有 4–5 块，太散，改成随旁白依次亮起，旧的淡出，同屏 ≤3 块；③ 机位基本不动，加慢横移。
- 对应点选 k7A + k8A。差在「数字压在实物上」只做到一半，集装箱这一级缺实物。

**B1_10 预脉冲薄饼**：左侧圆框里锡滴从 25 μm 变成 300 μm 侧视薄饼，带计量青尺寸线；背景是被拍开的金属薄片。
- 封顶：无。
- 改法：① 中帧放大框读数是「≈199 μm」，读起来像一个事实数字，改成连续滚动的计数，或只在终值时显示；② 背景薄饼是有褶皱的皇冠飞溅，真实的预脉冲薄饼是平滑扩展的圆盘，改形状；③ 300 μm 文字被圆框裁掉（「300 µr」），挪进框内。
- 对应点选 k3A + k3D。框与宏观同色板，做得对；材质和腔体密度不如 k3A。

**B1_15 暴力与温柔**：暗蓝腔内一团白紫等离子体，橙白火花四溅，周围是若干金属环和管线。
- 封顶：H1，C ≤ 60。这一镜要讲「等离子体旁边就是原子级精度的镜面」，可画面里认不出任何镜面。
- 改法：① 前景或侧面放一块大面积、高反、能映出等离子体辉光的收集镜曲面，形成冷硬与炽热的对照；② 腔体从抽象圆环换成 k3A 那种实体腔壁加法兰；③ 火花减量，避免读成烟花。
- 对应点选 k3A。差距很大，现在是抽象圆环 + 粒子。

**B3_02 椭球收集镜**：剖开的圆筒真空腔内，左侧是带金色背部、外圈有镜座的收集镜盘，紫光从第一焦点射向右侧 IF；有中心孔、第一焦点、IF 三处标注。
- 封顶：无。H13 逐项看：实心镜和镜座有，体积光有，景深 ≥3 层，腔壁有壳厚，只讲一条光路。

- 对应点选 k3A + k4A。差在镜子的形体和光锥几何。

**B4_10 地月高尔夫**：地球射出橙色激光到月球，最后特写高尔夫球；标注写 < 0.1 nrad。

- 对应点选 k7A。差在地球的材质。

**B5_01 照明系统**：照明舱剖视，紫光从左侧 IF 管口射到上方场分面镜，再到左下光瞳分面镜，经中部聚光镜去往掩模；背景是线缆、模块和导轨。

- F 74：标注写 6°，画面看起来接近正入射，入射角与标注不一致。
- 对应点选 k4A + k2B。差在折返清晰度和掩模细节。

**离 k2B / k4A 还差什么**
1. **模块可信度**：k2B 的背景是能叫出名字的东西（接线端子排、气管、线束、电机），本片背景多是随机方盒、圆柱、小色块的「greeble 墙」，近看就是简陋几何。
2. **光束质感**：k4A 的紫光是带内部射线纹理的锥形束，粗细随会聚或发散变化，端点精确落在镜面圆上；本片多是等宽的半透明平板，端点常常糊在镜外。
3. **镜子与镜座**：k4A 每个拐点都是厚实的镜片加金属镜框，倒角清晰；本片除 B5_01 外，镜子要么太小（B8_03），要么藏在雾里（B7_06），要么像玻璃（B3_02）。

5. **金属材质**：k2B / k3A 有拉丝、阳极氧化、喷砂的区分；本片舱壁多是统一的浅灰漫反射，缺少粗糙度变化和轮廓光。
