## A. 改结构（压缩 · 根因驱动）

不再把「只碰审稿点名的少数镜头」当成默认，也不再为了收束镜头数而停在大约 6 镜。共享模块上的根因必须铺开。加速其余条款不变。

### A0. 根因块（每轮开工第一件事，写入本轮 WORK_ORDER）

从上轮 `REVIEW_roundN_independent.md` 聚类成 **3–6 条根因**（不是镜头洗衣清单）。形状示例：「光路读法错误」「机理主角件不可辨」「材质灰盘子」「箱体平板」。

每条根因写清：
- **一条**结构性改法（配方）
- **受影响镜头清单**
  - 根因在共用模块（beam / material / kit）：清单 = 该模块**全部**导入镜，减去固定金控（R13 起 `A0_02` / `D_07` / `B9_05` / `B1_22`，这些镜不改像素）
  - 根因只在单镜结构：清单 = 审稿里真正中招的那些镜

**禁**：根因块还没写进本轮工单就开改代码。

### A1. 对症改

- 只实现能 1:1 映射到已写根因的改法。没进任何根因「受影响镜头」清单的镜头不动。
- 根因落在共用模块（beam / material / kit）→ **本轮重渲每一个非金控导入镜**，让新像素真正进帧。没有「大约只改 6 镜」的上限。
- STATUS 成功指标写 `changed_vs_prev / 24`（与上轮对应帧 mean abs diff > 0 的镜数；R15 起阈值 **> 1e-3**，排除未改场景的 GPU 采样噪声 ≈5e-5；审稿包金控帧一律复制上轮文件）。存在共享根因时，目标 **≥12**，不是 ~6。
- **仍禁**：单镜 glow / HUD / 标签 polish、噪点修补当本轮主活。
- **仍禁**：为「好看一点」去改**没有写进任何根因清单**的镜头。共享根因的导入镜必须进清单、必须改，不算「未点名的镜头」。
- **优先扩**共用可命名零件库（`hero_kit_rN.py` / `build_cutaway_r2.py`），一次做厚、多镜复用；**少整库重写**。
- 验收语言：零件要过「评审能用一个词叫出它吗？」；种类数是验收项。

### A2. 反鬼打墙

改代码前先读：上一轮 `PIPELINE_RETRO.md`，以及上轮 REVIEW 里的「新负向读法」（分数下降，或审稿新出现、上轮没有的误读）。

若上轮试了旋钮 X，结果分数下降或冒出新误读（例：束腰辉光珠 → 悬空白点），本轮对这条根因必须换**另一条路**，不准再拧同一个参数。

STATUS 必须列出：
- 根因 → 本轮试的改法 → 预期外行读法
- 明确一句「not repeating: …」（点名上轮已失败的旋钮，本轮不用）

输出：根因块已写入本轮 `WORK_ORDER`「第 N 轮工单」+ 对症代码改动。

## E2. 评分漂移：金控校准（Carl 2026-10-23 批准 · HARD）

R11 教训：未动 14 镜平均 +3.42，raw 均分 89.14 被尺度放宽淹掉。**从 R12 起强制金控校准。**

### 金控帧怎么选
- R13 起**固定金控 = A0_02 / D_07 / B9_05 / B1_22**（单帧自洽；B4_10 单帧不可用）。固定后各轮 Δ 才可比；这四镜所在的场景变体（`r2_plates` freighter / cleanroom、`r2_misc` photons、`r2_source` amps）不改像素。若某轮必须改其中一镜，换镜并在 REVIEW 里给出「同金控口径」的上一轮校正分。
- 每轮独立审前，审稿包加入 **3–4 张金控帧**：上轮已打过分、**本轮像素未改**的镜。
- 优先复制上轮 `round{N-1}/` 对应 PNG（或 strip 中帧），文件名标 `ctrl_<shot>_r{prev}.png`（例：`ctrl_A0_02_r11.png`）。
- 另备一份**仅主进程可读**的上轮总分表（`ctrl_history_scores.json`：shot → 上轮总分）。**审稿 agent 盲审时不要把历史分给它看**，只给图。

### 流程
1. 审稿对金控镜与新镜**同一套 SCALE**盲打分（金控可放进任一路，或单独一小包，但必须先打完金控再汇总新镜结论）。
2. 主进程算 **Δ = mean(金控本轮盲分 − 金控历史分)**。
3. 本轮所有镜头分（含新渲）先减 Δ 得到 **drift-adjusted**；**过线只认校正后**（均分 ≥92 且单张 ≥88）。raw 仍要记账。
4. STATUS / REVIEW 结论必须同时写 **raw** 与 **drift-adjusted**；推 Carl 文案以**校正后**为准；时间轴可继续画 raw（旁注本轮 Δ）。
5. 若 `|Δ| ≤ 1.5`：注明「尺度稳定」；若 `|Δ| > 3`：STATUS **醒目标「尺度漂移大」**，并检查金控是否误用了已改像素的镜（若误用 → 换金控重算，勿硬扣）。
6. R21 起（R20 RETRO）：另报**第二口径**「像素未变的非金控镜 raw 相对上轮均差」与每张金控三路极差；金控 Δ 与第二口径相差 > 1.5 → STATUS 标「金控方差大」并写出两种校正。过线仍只认金控 Δ 校正。

### 审稿模型锁定（Carl 2026-10-24 · HARD）
- 3 路独立 REVIEW **必须用 Opus（`claude-opus-5-5`）**，与 R21 及以前同一把尺子。
- **禁止**为省额度把审稿车道换成 Sonnet / Haiku（R22 教训：车道极差从 0.65–2.8 涨到 3.2–5.2，校正分不可比，假跌）。
- 搬运 / 渲染 / 冒烟类子代理可用便宜模型；**只有评分车道锁 Opus**。
- `review_rN/run_lane.sh` 的 `--model` 必须是 `claude-opus-5-5`；复制模板时不得带回 Sonnet。
- STATUS / REVIEW 首行写明审稿模型；换模型的轮次不得与前后轮直接比涨跌。

### 禁止
- 只审改过的镜（漂移更看不见）。
- 把历史分塞进审稿隔离目录。
- 过线只看 raw、或只报 raw 不报 adjusted。
