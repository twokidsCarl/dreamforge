## 3. 逐镜意见

### A0_01（冷开场：锡滴 → 薄饼 → 等离子体）
画面：橙色激光打中锡滴，接着锡滴拍成波浪边的金属薄饼，最后变成紫色等离子辉光，旁边配一个 Sn⁸⁺–Sn¹⁴⁺ 圆形放大框。背景是虚焦的线缆束、管口和法兰。
封顶：无。三帧之间有真实的物体形变和焦点变化，H2 不触发。
1. 旁白第一句是「这是一滴锡，比头发丝还细」，可 25 % 帧里锡滴已经被橙色光晕吞掉，观众看不到一颗完整的锡球。**把第一帧前移到激光到达之前**：先给 1–2 s 干净的银色球体特写，并在同屏放一根虚焦的头发丝（80 µm）做 k7A 式尺度对照，标签再上屏。
2. 薄饼占了大半屏，表面是大块灰黑污斑，读起来像一只金属盘子。**降低粗糙度、加上液态锡的高光流纹和边缘碎滴**，污斑改成环境反射。
3. 放大框里 Sn⁸⁺ 的上标被波浪线压住。**把波浪线移开或放到上标下层**，避免 H10 风险；85 % 帧的辉光后面最好露出一点腔体轮廓（k3A），不要只剩纯黑虚化。

### A0_02（货机夜装）

封顶：无（没有航司标志，H12 不触发）。

2. 25 % 帧左下角的人头剪影被字幕条切掉一半。**把剪影移出字幕区**，或干脆删掉。
3. 可以再进一步：机舱内的板条箱露出铝框纹理（F17），和 A0_03 衔接。

2. 三帧机位几乎不变，D 只给 80。**加一段明显的升降或横移**，配合数字逐级堆叠。

### B1_08（HUD：每颗锡滴单独成像、瞄准）

- **B9_05**：宏观光刻胶线条 + 圆形放大框（3×3 nm² 格计数）。放大框嵌在宏观画面上，Macro/Micro 系统成立。问题是这张单帧没有写剂量，格子平均约 13 个光子，和「每 nm² 约 20 个」对不上，所以 C/F 扣分。
- **D_07**：写实洁净室，左侧是高密度设备侧墙（管路、阀块、箱体），两名洁净服人物背影，远处黄光区。达到 k9A/k8C 水准，看不到人脸。标签中间空着一行；「灯光一亮」这个节拍单帧看不出来。

## 3. 逐镜意见

### A0_06（85.7）
**画面**：半透明玻璃地球，欧洲中心发出青色弧线，右上计数器 957 → 3,605 → 5,100，左上有「荷兰 · 整机总装」标签。
**封顶**：无。属于 7C 边缘，但有 3D 实物地球，不判 H14。
**改法**：
1. 地球要做实。陆地现在几乎和海一样暗，玻璃壳像空泡泡。把陆地换成有夜灯 / 地形的实体（参考 k7A 和 r40 的地球），壳透明度降一半，光比拉到 ≥8:1。
2. 弧线现在穿出球体、悬在太空里，亚洲方向的弧线在背面看不见落点。弧线应贴球面走，镜头在 85 % 处转到能同时看到欧洲、美国、东亚三簇，「一张网」才读得出来。
3. 左下脚注「各地区数据据 ASML 年报」里的 ASML 被球体遮掉，而且字号太小。把它移到字幕条上方，加深色底，不压在球上。

### A2_03（86.9）
**画面**：机内紫光 W 折返光路做虚焦背景，前面是半透明底条上的公式 CD = k₁·λ/NA，四项各有中文名；λ 用紫色，NA 用青色。后面依次出现「k₁ 的物理极限：0.25」「镜子收光的锥角 → NA」。
**封顶**：无（背景是实物，k₁ 下标正确）。
**改法**：
1. NA 只有文字，没有画面。在引线指向的那面镜子上画一个半透明的会聚光锥并标出半角 θ，加一行 NA = sin θ，让「收光能力」能看见。
2. 光束是等宽、满是条纹噪点的发光柱。改成锥形收放、软边，镜面落点加亮斑（参考 k4A）。
3. 85 % 帧同时有 3 个标注框 + 字幕，还有一条没有标签的白色引线（上方从 450,105 到 555,155）。删掉孤立引线；k₁ 标注出现时把公式条上移或缩小，别压住镜座。

### A2_08（87.5）
**画面**：虚焦的机内紫光背景上，白色 193 nm 正弦波和紫色 13.5 nm 波上下对照。紫波逐段画出，青色括号标「1 个 193 nm 波长 = 14 个 13.5 nm」。
**封顶**：无。H14 合格，背景是实物。
**实测**：括号内约 14–15 个周期，比例基本对。但紫波周期从左到右在变（约 23 px 渐增到 28 px），细看像画错。
**改法**：
1. 紫波周期要恒定，括号端点对齐 193 波的同相位点。
2. 两条波都是纯 2D 线。给紫波加一点景深 / bloom，让它像「那支细笔」漂在机器里；或者让背景焦点在三帧里推移，加强 D 维。
3. 「193 nm 上一代光刻光（深紫外）」标签放在左上，不符合右上规范。可以把两个标签都放到右侧，按上下对齐。

### B4_07（87.3）
**画面**：圆柱镜坯切掉一个楔形扇区，紫光入射到镜面后反射。镜头推近切面，圆形放大框里是灰阶 TEM 多层（能数出约 40 对），右下标「钼/硅 × 40 对 · 每对约 7 nm，只在镜面最顶层 · 总厚约 0.3 μm」。
**封顶**：无。放大框引线锚点在镜面顶层边缘，符合检查重点；40×7≈280 nm ≈ 0.3 μm，数字自洽。
**改法**：
1. 镜坯和切面是哑光白石膏质感，像切开的蛋糕。镜坯换成微晶玻璃（半透、带内部层次），切面中性灰并加磨削纹；顶层膜在切面上要看出一条薄而发亮的线，和下面的基底区分开。
2. 光束落点处有一个实心白色胶囊端头（第 1 帧 400,180）。去掉端头，改成镜面上的柔和亮斑 + 反射光束从同一点出射。
3. BRIEF 写的是「一路缩放到原子」，现在停在层级。85 % 处加二级放大：一对 Mo/Si 界面的原子格点。放大框刻度字太小读不出来，要放大，或者只留「10 / 20 / 30 / 40」四个刻度。

### B4_10（87.2）
**画面**：地球 → 月球 → 月面上一颗高尔夫球，一束橙色激光贯穿，标「< 0.1 nrad · 蔡司的比喻」，有月球距离标注和「高尔夫球 直径约 4 cm」。
**封顶**：无。
**改法**：
1. 橙色是片中 CO₂ 激光的专用色。这里是比喻光束，建议改成白色或冷白（加细青色测距线），避免观众以为是驱动激光。
2. 第 1、2 帧的白色虚线测距线和两条青色引线交叉，显得乱。测距线改成计量青，只保留一条，「月球」标签挪到月球右侧。
3. 激光现在从大气层边缘凭空出来。在地表加一个可见的发射点 / 小望远镜光斑；高尔夫球加一点影子和接触阴影，让它「落在月面上」更可信。

### B6_12（87.0）
**画面**：中灰棚拍台面上，带图形的掩模，上方是黑色细框张着的 pellicle，膜面上有几颗颗粒。标注依次为「保护膜 pellicle / 掩模（图形面朝上）/ 膜厚 13 nm / 间距（示意）」。
**封顶**：无。膜可见、有间隙、有掠射高光，不算 H1/H8。颗粒没有标注，但旁白不讲颗粒，不判 H6，只在 C 维扣分。
**改法**：
1. 框太简单：一根黑方管，没有夹扣、透气孔、贴合胶线。参考 k5A，加框角夹具和侧面气孔；膜做出极薄、微透、轻微张力起伏的掠射高光带。现在膜面是一片乳白平面。
2. 颗粒要么加一行标注「颗粒落在膜上 · 离焦不成像」（这是 pellicle 的作用），要么删掉，否则观众会问「这是什么」。
3. 第 3 帧右上有一道竖直白色亮条（约 450,130–500,250），像漏光 / 反射穿帮，去掉。标签集中在左侧，改到右上（最多 3 行）。

### B8_17（87.8）
**画面**：晶圆台上一片晶圆，场格逐个变紫，计数器 43 → 143 → 188 场/片，185+ 片/小时，3.4 万+ 次曝光/小时。
**封顶**：无。场格约 18 行 × 14 列在圆内，估算约 190 格，和 188 一致；数据同属 EXE。
**零件辨识度**：能叫出名字的约 5 种——物镜 / 对准头、波纹管（棱纹圆筒）、散热梳片、晶圆片架（堆叠晶圆）、工件台。墙面是素面板，没有同一种格子重复铺满。
**改法**：
1. 「正在曝光」这个动作没有画出来：物镜头下没有光，场格自己变紫。加一条紫色狭缝光带落在当前场上并扫动，场格曝光后再变色。
2. 晶圆缺 notch，边缘排除区也不明显；工件台是一整块平板。加 notch、吸盘环纹、台面编码尺 / 干涉仪反射镜条，提高 A 维密度。
3. 右侧片架被一块大斜板压着，结构读不懂。改成开口的 FOUP 或机械手取片位，标一个词。

### B9_05（88.5）
**画面**：宏观光刻胶线条阵列，光子水滴下落；圆形放大框里 3×3 nm² 格的光子计数随时间累加（中心格 3 → 16 → 20）。85 % 帧标「剂量 ≈ 20 光子/nm²（示意）· 落点随机 → 线条边缘起伏」。
**封顶**：无。
**和金控对比**：画面质量和 ctrl_B9_05_r12 相同。本镜多了剂量标注，计数累加到约 20，补上了 C/F 的缺口，所以 C、F 分高于金控；A、B 不变。
**改法**：
1. 光子画成拖尾泪滴，像雨点卡通。改成短而锐的紫色亮点 + 极短拖尾，落地时在胶面上留一个小闪光，「数得清的几滴」才精确。
2. 宏观线条是阶梯方块堆叠，「边缘起伏」没有和光子落点对应。让放大框旁边的一根线条边缘随落点密度局部凸凹，把「随机 → 粗糙」连起来。
3. 顶部有一圈半截圆环（第 1 帧上沿），来历不明。要么交代成投影物镜出口，要么裁掉。

### D_07（90.4）
**画面**：写实洁净室长廊，左侧是高密度设备侧墙（管路、阀块、电气箱、观察窗），两名洁净服人物背对镜头向远处黄光区走去。镜头前推，人物在走，有真实视差。
**封顶**：无。
**和金控对比**：画面质量和 ctrl_D_07_r12 相当，D 维因为三帧有真实推轨略高，C 维因为「灯光一亮」节拍缺失略低，总分持平（90.4 vs 90.5）。
**改法**：
1. BRIEF 要「灯光一亮」，三帧照明一直不变。25 % 帧前压暗（只亮设备轮廓光），55 % 起顶灯成排亮起。
2. 标签中间空着一行，「来源：ASML」字太灰。可以补一行「来源 ASML · 供应链约 5100 家」，或者收成两行。
3. 设备墙是通用制程设备，没有锚定到「它」（光刻机）。远景可以加一点前面镜头出现过的紫光窗口或熟悉的模块轮廓（不仿 ASML 外观），把「巨物 = 前面那台机器」接上。

## 4. 本路最值钱的改法

1. **光束统一改成锥形收放 + 软边 + 镜面落点亮斑**（A2_03、A2_08 背景、B4_07）。现在是等宽噪点管，并且有实心胶囊端头。这一条同时抬高 A、C，几个镜头 A 维各能涨约 3–4 分。
2. **把机理的「动作」画出来，不只靠计数器和文字**：B8_17 加狭缝扫描光带，A2_03 加 NA 光锥 θ，B9_05 让光子落点和线边粗糙联动。C 维是 25 % 权重，各镜可涨约 2–3 分。
3. **Macro 主体材质升级**：B4_07 的石膏镜坯换成微晶玻璃 + 顶层膜高光线；B6_12 的 pellicle 框加夹具、气孔、膜面张力高光；A0_06 的玻璃地球做成实体陆地 + 夜灯。这三镜是本路最低的三镜。
4. **配色和标注层纪律**：B4_10 的比喻激光不用橙色；测距线、尺寸线一律用计量青；标签收到右上、≤3 行；清掉孤立引线、漏光亮条（B6_12）、彩色斑点（A0_02）。
5. **补 BRIEF 写明但画面缺的节拍**：D_07「灯光一亮」，B4_07「缩放到原子」。
