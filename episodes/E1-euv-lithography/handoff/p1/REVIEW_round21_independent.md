## 3. 逐镜意见

### A0_01（冷开场锡滴 → 薄饼 → 等离子体）
画面：在光源腔里，先是一颗锡滴配“25 µm / 头发丝 80 µm”的标注，然后橙色激光把它打成 300 µm 的薄饼，最后变成一团紫光，旁边的圆形放大框里画了 Sn⁸⁺–Sn¹⁴⁺。三帧是真实的事件推进，D 给得好。封顶：无。
- 锡滴像一颗**带黑条纹的玻璃弹珠**，读不成液态金属。改法：换成高反射、低粗糙度的液态锡材质，反射里只留腔体环境，不要条纹贴图；加一圈细的轮廓光。
- 第 3 帧的等离子体是一个**悬空白点**，旁边看不到收集镜，也没有腔体光源。改法：把辉光做大到画高的 1/6 左右（参照 k3A），在它后面虚焦带出收集镜的弧面和中心孔，让这个点“有所依附”。
- 放大框里 Sn⁸⁺ 的字被光子波浪线压住了，第 1 帧的标注框也压到了锡滴边缘。改法：把波浪线绕开离子标签，标注框往右上挪 40 px，中间那行空行删掉。

### A0_02（夜间货机发货）
画面：和金控是同一个场景，机位缓慢横移，有真实的视差。H2 不命中。封顶：无。
- 机身上的彩色小穿帮点在三帧里都有。改法：修掉。
- 左下的黑色剪影抢视线。改法：去掉，或者做成清楚可认的地勤 / 锥桶。

### A0_03（250+ 箱 → 43 集装箱 → 几架货机 → 20 辆卡车）
画面：实拍感的停机坪上排满白色铝框箱，右上角有一个信息图面板逐级长出来。封顶：无（面板在变，不算三帧几乎相同），但背景完全不动，D 给 80。
- 面板只占画面约 1/5，第 3 帧的货机 / 卡车图标在 960 宽下只有几像素，**“压迫感”没有出来**。改法：面板放大到占画面 40–50 %，或者直接让 3D 箱子按 10×25 在地上排开，镜头拉高展示，把数字压在实物上（k7A 读法）。
- 背景是静帧。改法：加一个慢推加升的机位，让箱阵产生视差。
- “43 个航空集装箱”的图标和 250 个格子的比例看不出“装满”的意思。改法：画一个格子流进集装箱的动作，两段之间加一个箭头动画。

### B1_08（每颗锡滴单独拍照、单独瞄准）
画面：锡滴从喷嘴落下，两侧相机（带绿色 LED 环）拉出青色视锥，青色 HUD 准星跟着两颗锡滴走，橙色虚线是激光路径。封顶：无。
- **零件辨识**：能叫出名字的有喷嘴、相机 / 成像镜头、LED 环形照明、激光路径，背景里有几块虚焦的法兰 / 端口，一共约 4–5 种。墙面不是重复格子铺满，但全部虚掉了。改法：在背景加一个能认出来的真空法兰 + 观察窗，景深收一点。
- 锡滴还是玻璃弹珠质感，问题同 A0_01。
- 橙色虚线只画在左侧，读起来像一条 UI 刻度。改法：换成细的、软边、低亮度的橙色瞄准线，终点落在准星中心，和“瞄准”对应起来。

### B1_10（预脉冲 → 300 µm 薄饼）
画面：橙色预脉冲打中锡滴，然后锡滴被压成一张占满画面的镀铬圆盘，左上的放大框给出 25 µm 圆点和 300 µm 椭圆的对比，右侧有尺寸线。封顶：无。
- 薄饼读成了**一面带腿的镜子 / 锅盖**：边缘那几根带球头的“触须”像支架。量表要求“薄饼不能像玻璃片”，按这条扣 A。改法：边缘改成不规则、往外甩的液膜加碎滴，中心略厚、边缘透薄，粗糙度提高到 0.15 左右，并加一点熔融的橙红余辉。
- “25 µm”和“300 µm”在标注、放大框、尺寸线里各出现两到三次，太啰嗦。改法：尺寸只留放大框和尺寸线，右上标注改成“预脉冲：拍扁”。

### B1_15（暴力与温柔：等离子体旁就是镜面）
画面：从观察窗看进腔体，橙色激光穿过中心孔，打出紫色等离子体和飞溅碎屑，标签“收集镜”指向左上方一片铬色曲面。封顶：本条要求“等离子体在镜面光轴焦点、镜面看得出（H1）”。镜面勉强存在，所以不封，但 C 只给 80。
- 收集镜读成了**扭曲的液态铬面**，看不出椭球碗形，标签引线也落在一块说不清是什么的区域上。改法：机位往后退，让收集镜碗沿完整入框，并占画面 ≥1/3；中心孔、碗面和等离子体三者落在同一条轴上；镜面反射里映出那团等离子体，“温柔”的对照才成立。
- 右下有一条紫色**实心光柱**从等离子体直冲镜头，光路读不出来：EUV 应该是被镜面反射后向 IF 会聚，而不是从等离子体直接射出来。改法：删掉这条光柱，换成从镜面反射出来、向 IF 收拢的软边锥形光。
- 左上还有一团紫色拖尾，来路不明。改法：删掉。

### B1_18（谱线挤在 13.5 nm，选锡原因）
画面：背景是虚焦的真实腔体和等离子体辉光，左侧半透明面板上的直方图逐帧长成一座峰，标了“镜子反射窗口 ±1 %”和 Sn⁸⁺–Sn¹⁴⁺ 图例。H14 不命中，背景是实物。封顶：无。
- 图例用的粉 / 洋红渐变很接近 EUV 紫，“紫 = EUV”的约定被冲淡了。改法：离子价态改用中性灰阶，或者青到白的渐变；紫色只留给 13.5 nm 窗口。
- 背景机位基本不动。改法：加一个缓慢拉焦（腔体到等离子体），让 D 有真实的焦点运动。

## 3. 逐镜意见

### A0_06（infographic，5100 供应商地球）
画面：写实地球，欧洲光点簇向北美拉出青色连线，右上计数器 957 → 3,605 → 5,100，标「荷兰 · 整机总装」。
封顶：无。H2：地球自转 + 计数 + 连线生长，运动真实。
1. 55 % 帧的连线是直弦，直接穿出球体边缘，读着像平面贴图。改成贴球面的大圆弧，并抬一点高度，末端落在地表光点上。
2. 地球偏左，右半屏空黑，只有一块计数卡。可以把地球推到画面 60 % 宽、居中偏左；或者在右下补一条「主要供应国」小图例，用实物光点密度条，不要纯数字。
3. 5100 个光点只分布在欧 / 北美两簇，看不出「一张网」。在亚洲（日、韩、台）加稀疏光点和弧线，并在结尾帧让全网同时脉动一次。

### A2_03（type，CD = k₁·λ/NA）
画面：虚焦的机内实物背景（镜座、管线、晶圆台）上方是公式条，λ 紫、NA 青，逐项点亮；紫色光锥经折返镜会聚到晶圆，标「镜子收光的锥角 → NA」，末帧标「k₁ 的物理极限：0.25」。
封顶：无。H14：背景是实物（虚焦），合格。光束是锥形软边，拐点在镜座处，合格。
1. λ 的引线和 NA 的引线在光锥上方交叉，外行会读成两条光。λ 的引线改成不进画面（或只在公式下面加一条紫色下划线），只留 NA 一条引线指向会聚锥角。
2. NA 锥角没有画出角度：在晶圆会聚点加一条青色半角弧线，标「θ」，与 NA 字样同色。
3. 公式条占了上方约 25 % 高，压住镜座主体。字号可以缩 15 %，底条透明度再降一点，让机内层次露出来。

### A2_08（energy，193 nm vs 13.5 nm）
画面：虚焦机内背景前，白色 193 nm 正弦波和紫色 13.5 nm 波并排，末帧加青色量程「1 个 193 nm 波长 = 14 个 13.5 nm」。
封顶：无。H14：背景是实物，合格。14× 比例目测正确。
1. 紫波末端有 1–2 个周期扭折、断接（55 % 帧 x≈700），13.5 nm 的引线也直接穿过波形。修好波形尾段，引线改从标签框下方引出，避开波形。
2. 运动只有紫波生长，背景机位几乎不动。加一个缓慢横移或焦点从背景拉到波形，给 2.5 s 停顿一点呼吸。
3. 白波是纯 2D 细线，和紫波的辉光不是一套线宽。给白波也加一层淡辉光（中性灰白），两条线同一线宽体系。

### B4_07（sem，镜面 → 多层膜）
画面：带楔形切口的反射镜，紫色入射 / 反射光锥落在镜面一点；推进后，圆形放大框指向镜面顶层，里面是灰阶 TEM 式条纹，标「钼/硅 × 40 对 · 每对约 7 nm · 只在镜面最顶层 · 总厚约 0.3 μm」。
封顶：无。放大框正确指向顶层膜（检查点通过）；40 × 7 nm ≈ 0.28 μm 正确；无彩虹。
1. 基底切面是均匀哑光灰，楔形切口像蛋糕块。给切面加微晶玻璃的半透 / 细磨质感和倒角高光，镜面顶层画一条可见的薄亮边，让「膜只在最顶层」在宏观上也看得见。
2. 放大框里的刻度数字太小，540p 下读不出。按 k4D 的做法换成一根白色「50 nm」比例尺。
3. BRIEF 说「一路缩放到原子」，现在停在层级。末帧可以再嵌一个小框，显示 Mo/Si 界面的原子排列，或者在 BRIEF 里把终点改成「层」。

### B4_10（photoreal，地球 → 月球 → 高尔夫球）
画面：写实地球射出白色细光束到月球，再推到月面上一颗高尔夫球，标「< 0.1 nrad」「距地球约 38 万 km」「直径约 4 cm · 尺寸示意」。
封顶：无。0.1 nrad ≈ 4 cm / 38 万 km，数值自洽。
1. 末帧月面是光滑浅灰平面，没有陨坑、碎石、掠射阴影，像塑料（A 主扣点）。换高分月面位移 + 低角度太阳光，让高尔夫球投出长影。
2. 光束是均匀白线，终点没有落点光斑。在球面上加一个小亮斑，光束在终点收细，让「打中」被看见。
3. 中段月球是小圆盘，没有尺度感。可以在 55 % 帧把地球边缘留在画面一角，保留「两端同框」。

### B6_12（xray，掩模 + pellicle）
画面：掩模卡盘下视角，蓝色冷却管、金色接头、掩模版图形面朝下；标签「保护膜 pellicle」「反射掩模（图形面朝下）」；末帧圆形放大框显示「掩模图形面 / 间隙（几毫米）/ 13 nm 膜」，标「间距不按比例」。

3. 右上两个两行标签框加上放大框的三条标签，同屏 5 处文字，超过「≤3 行」。末帧去掉右上两个标签，只留放大框标注。

### B8_17（infographic，188 场 / 185 片 / 3.4 万次）
画面：物镜筒射出紫色锥形光，落在晶圆格子上的一个场；右侧是晶圆片堆，右上计数器 43 → 188 场/片、124 → 185+ 片/小时、3.4 万+ 次曝光/小时。
封顶：无。188 × 185 ≈ 3.48 万，数字自洽。
零件辨识度：物镜筒、晶圆卡盘、晶圆片堆（片盒）、线缆 / 气路管束、旋钮阀、控制面板，约 6 种。墙面不是同一格子重复铺满。
1. 场格不对应 188：格子是近正方形，圆内约 140–150 个整格。High-NA 半场是 26 × 16.5 mm 的长方形。按半场尺寸重画格子，让整格数正好 188（F 主扣点）。
2. 计数器到 188 时，晶圆上已曝光（变灰）的格子反而变少，进度和读数对不上。让灰格随计数逐格累积，188 时铺满，再换片。
3. 「188」数字用了 EUV 紫，紫色只该代表 EUV 光。数字统一改成白色或计量青。光束出口有几道条纹，像几根管子；改成单一软边狭缝光，落点画成细长狭缝，而不是方块。

### B9_05（energy，光子雨）
画面：紫色光子水滴落向光刻胶线条阵列，圆形放大框按 1 nm² 分格计数，随时间累积 3 → 16 → 20；末帧标「剂量 ≈ 20 光子/nm²（示意）· 落点随机 → 线条边缘起伏」，另标「1 个 EUV 光子 ≈ 92 eV」。
封顶：无。末帧计数均值约 20，和剂量一致。
1. 「落点随机 → 边缘起伏」只写在字上，画面里没有因果：光刻胶线条是规则的阶梯积木。末帧让线条边缘按计数多少出现可见起伏，计数少的格对应缺口（参照 F59 的粗糙 / 断线）。
2. 光刻胶材质是哑光紫色体素块，紫色占满整屏，和「紫 = EUV 光」冲突。改成中性灰或淡琥珀色胶层，紫色只留给光子。
3. 光子水滴的拖尾长短不一、方向略乱。统一成短软拖尾，并加景深，前景少量虚焦光子做出层次。

### D_07（documentary，5100 供应商 + 工程师）

1. BRIEF 要「灯光一亮，巨物旁边出现人」，三帧照明没有变化。在 25 % 帧之前做一次顶灯逐排点亮。
2. 标签框中间空了一行（主标题和来源之间有空行），压成两行。
3. 字幕到「一点一点做出来的」时，可以给左侧设备一处近景虚实转换（拉焦），突出「零件 / 手工」。
