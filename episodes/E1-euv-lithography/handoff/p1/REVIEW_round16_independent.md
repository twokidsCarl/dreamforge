## 下一轮最值钱的改法顺序

1. **B1_15 换路（三轮 H1）**：不再从收集镜内部 / 镜沿看（R15 偏轴 20°、R16 镜沿内光轴都失败）。改为**外部剖切 3/4 视角**：直接复用 B3_02（r2_cutaway collect，审稿认可「镜子像镜子」）的收集镜几何 + 镜面材质，半剖开的椭球镜占画面 ≥1/3，等离子体在第一焦点，镜面上映出等离子辉光；1.5 s 内机位推近 8–10 % + 焦点从等离子拉到镜面（解 H2）。删镜沿霓虹亮边与左上重影。
2. **回退 R16 引出的新负向**：r2_source 的 B2_08 / B1_18 恢复 R15 的腔体补光层级（不恢复会在锡上映出方形的灯片）；B2_08 收集镜用 B3_02 的实心椭球镜面。锡薄饼：去掉深色粗边框 + 透明折射读法——薄饼改不透明、中心略厚、边缘冠状液丝（几何），A0_01 / B1_10 / B1_08 共用。
3. **光束读法换路**：两轮（R14 交替收放、R16 锥形淡出）改形状都没在 960×540 读出来。下一轮不再改锥形参数，改成**「镜面落点高光 + 光束只在镜—镜之间保留细芯、体积雾降到能看见镜子」**，每屏一条主光路（A0_10 删中舱交叉段）。

## 3. 逐镜意见

### A0_01（86.0）
**画面**：光源腔内景依次出现三个状态：悬着的锡滴、橙色激光打出的薄饼、带 Sn 离子放大框的紫色等离子体。
**封顶**：无。三帧之间状态和机位都有真实变化。
**问题**：
1. 中帧的薄饼读成「带黑框的玻璃透镜 / 舷窗」（量表 3：薄饼像玻璃片，A −10）。改法：薄饼改成不透明的液态锡，做成中心厚、边缘碎成冠状液丝的金属盘；去掉透明折射和深色粗边框，换成拉丝银灰金属高光。
2. 末帧放大框里的 Sn⁸⁺ 角标被原子球挡住了一半。改法：标签移到球外，或者放大框里的标签全部压在最上层。
3. 锡滴在首帧像一颗大钢珠，没有尺度感。改法：景深再浅一些，并加一根头发丝剪影作同屏比例（k7A 思路），和标注「头发丝约 80 μm」对上。

### A0_02（90.4，与金控同画面）
**画面**：夜雨机坪，747 货机机头开舱，装车平台把白色铝框箱送进机舱，机位缓慢推近，前景人物有视差。
**封顶**：无。
**问题**：
1. 机身上的彩色小点三帧都在。改法：删掉这个调试标记。
2. 前景剪影人只露出半个头，读成一团黑块。改法：让人完整入画并保持逆光，或者干脆拿掉。

### A0_03（86.0）
**画面**：夜雨机坪俯瞰，大片铝框板条箱方阵，背景是货机和航空集装箱，机位边推边摇；数字靠引线标签逐个出现。
**封顶**：无（实拍感的 3D，不是 7C 家族）。
**问题**：
1. 三个数字都只是标签，实物数量对不上：板条箱远多于 250 个；「43 个集装箱」的引线指向一个 ULD，画面里只有十来个；「20 辆卡车」时只看得见一两辆（C −）。改法：把箱阵数到约 250（例如 10×25），集装箱排成可数的 43 个一组，末帧摇到一排 20 辆平板挂车。用计量青的分组框把每组框出来，配合计数器。
2. 箱阵是同一个模型均匀复制，CG 感明显。改法：加入轻微的朝向和高度抖动、货网、标签贴纸，以及箱子之间的工作人员和叉车。
3. 标签没有统一放在右上，在画面里四处跳。改法：数字固定在右上计数，引线只负责指认。

### B1_08（86.4）
**画面**：喷嘴下落的锡滴被两台环形灯相机照着，青色 HUD 准星逐颗锁定，左侧有一条橙色虚线。
**封顶**：无（三帧都有锡滴下落、准星跟随）。
**可叫出名字的零件**：喷嘴（锡滴发生器）、相机 ×2（环形补光）、激光束（虚线），约 3 种。背景虚焦太重，几乎全黑。
**问题**：
1. 橙色激光画成三段等距短线，像 UI 虚线，不像光束。改法：画成一束连续、带锥形软边的激光，从画外射向锡滴的预定落点。
2. 背景信息太少，像暗房里的 UI。改法：把背景的光源腔法兰、观察窗、冷却管束从「全黑」提到可辨的暗部细节，光比保持 8:1。
3. 相机投出的青色光锥看起来像实心的光柱。改法：降低不透明度、做成软边，或者只保留相机镜头的高光。

### B1_10（86.5）
**画面**：橙色预脉冲打到锡滴；左侧放大框里，侧视的 25 μm 圆点被拍成细长薄饼；主画面是正视的椭圆薄饼，标注 300 μm。
**封顶**：无。
**问题**：
1. 主画面薄饼像一面带黑边框的椭圆玻璃 / 镜子，下半部还有一块黑色月牙反射，读不出「液态锡」（A −10）。改法：同 A0_01，做成不透明的银灰液态金属，边缘飞溅出液丝冠，中心略厚，去掉黑色月牙。
2. 末帧「300 µm」重复标了两次（放大框里一次、主画面一次）。改法：只保留主画面的计量青尺寸线，放大框里只标 25 μm 对比。
3. 首帧的放大框里只有一个小点和一条细弧，信息很弱。改法：首帧就给出 25 μm 圆珠和 300 μm 的虚线轮廓预告。

### B1_15（69.7）
**画面**：从一个发光的圆形法兰环往里看，中心偏右是紫色等离子体加橙色火花，左上还有一团虚化的紫色重影；「收集镜」引线指向左上角的一个小零件。
**封顶**：**H1**（镜面看不出来：收集镜要讲的「原子级精度的镜面」画面里读不到，引线还指错了对象）→ C ≤ 60；**H2**（1.5 s 镜头，三帧几乎一样，只有火花在变）→ D ≤ 55。
**可叫出名字的零件**：法兰环、喷嘴、管道、电子盒，3–4 种；盒子用的是同一种蓝边方块重复铺。
**问题**：
1. 收集镜必须看得出是镜子：把它画成大口径、深凹的椭球金属反射面（带中心孔），占画面 ≥1/3，等离子体正好在它的光轴焦点上，镜面映出等离子体的倒影。「收集镜」引线改指镜面本体。
2. 去掉等离子体左上方的紫色重影（会被读成第二团等离子体），法兰环的霓虹白边也降亮，不要让它比主体还抢眼。
3. 加一个 1.5 s 内看得见的运动：机位向镜面推 5–10 %，或者从等离子体到镜面做一次焦点拉移，表现「暴力 vs 温柔」的对照。

### B1_18（85.6）
**画面**：左侧是逐步长出来的谱线直方图（Sn⁸⁺–Sn¹⁴⁺，13.5 nm 处有反射窗口），右侧是虚焦背景里的紫色等离子体。
**封顶**：无。背景有实物管道，H14 不成立；直方图压在实物画面上属于标注层。
**问题**：
1. 背景几乎读不出零件，只有几根弯管和圆环。改法：把光源腔（收集镜边缘、喷嘴、法兰）做成可辨的虚焦实物，等离子体放到收集镜焦点。
2. 离子图例的颜色从紫渐变到粉红 / 橙粉，越出了色板，而橙色是激光的专用色。改法：Sn 价态只用紫色的明度梯度（或紫→青）。
3. 背景和等离子体是静止的，只有图表在动。改法：给背景加慢推或焦点推移，让「谱线堆起来」和等离子体变亮同步。

### B1_22（89.7）
**画面**：CO₂ 放大链长镜头，机位沿鳍片放大管平移，进度条从种子光逐级点亮到「放大 4 · 数十 kW」，管内有橙色激光。
**封顶**：无。标了「示意 · 非真实结构」，数值属于同一代。
**可叫出名字的零件**：放大管（鳍片 / 冷却）、手轮阀、观察窗面板（三圆窗）、竖排阀门气路面板、线缆束、工作台、背景盘管，约 6–7 种。鳍片管重复出现，但背景墙不是同一种格子铺满。

- **D_07**：洁净室走廊，左边设备高密度去壳，右边两名洁净服人物背影，远端黄光区。质感接近 k8C/k9A。问题：标签框中间留了一行空白，下面只有一行「来源：ASML」，排版失衡。

## 3. 逐镜意见

### A0_06（地球 + 5100 光点）
画面：地球缓慢转动，荷兰总装点向全球发出青色弧线，光点从 957 增长到 5,100，右上角是计数器。
封顶：无。H2：转动和计数都是真运动，不触发。
1. **85 % 帧的计数框压住了荷兰总装点**，「荷兰·整机总装」标签也被挤到框下面。修改：计数框移到画面左上或右下的空太空区域，让总装点始终在框外，并保持距离 ≥ 60 px。
2. 光点在欧洲堆成一团白色噪点，读不出「一张网」。修改：光点按地区聚成 6–8 个大小不同的圆点（面积 ∝ 供应商数量），用细弧连回荷兰；去掉散点粒子。
3. 地球顶部被画框切掉，构图偏低。修改：机位上抬约 10 %，让北欧和北美都完整入画；地球加一圈 2A 风格的轮廓光，把它和背景拉开。

### A2_03（CD = k₁·λ/NA 公式）
画面：去壳机内 CG 做背景（是实物，虚焦，H14 不触发），公式卡逐项点亮，λ 用紫色，NA 用青色，下方有「镜子收光的锥角 → NA」和「k₁ 物理极限 0.25」的注释。
封顶：无。
1. **背景里有 3–4 条紫光柱交叉，并且都从朝向镜头的发光圆盘出来**，外行会把镜子读成「射灯」，也违反每屏一条主光路。修改：背景只保留一条 V 形折返光路，光束做成锥形收放、带软边，落点在镜面上能看到高光；镜座圆盘去掉自发光，改成金属镜面加反射。
2. 公式底板是一块不透明的大黑条，把机器中心整个挡住。修改：底板改成半透明（约 55 %），高度压缩约 20 %，上移到画面上 1/3。NA 锥角注释要和画面里的实际光锥对齐。
3. 能叫出名字的零件只有电缆槽、真空规、环形管、机柜梯架约 4 种，而且都是同一种灰白面板。修改：加一处波纹管和一个气路面板，提高前景的材质对比。

### A2_08（193 nm vs 13.5 nm 波形）
画面：虚焦的机内背景前，一条白色 193 nm 正弦波和一条紫色 13.5 nm 密波同框，85 % 帧有尺寸线「1 个 193 nm 波长 = 14 个 13.5 nm」。
封顶：无（H14：背景是实物，虽然虚焦，不触发）。
1. 紫色密波的振幅只有白波的一半，而且发光更强，容易被读成「更弱 / 不同的东西」。修改：两条波用相同振幅，只改变波长；紫波的 bloom 降到和白波相同。
2. 尺寸线只量了半个画面，而且字很小。修改：尺寸线卡在白波的一个完整周期两端，对应的紫色周期逐个点亮并计数 1…14，数字用等宽字体，字号放大约 1.5 倍。
3. 背景虚焦里仍然能看到几条交叉的紫光柱，和前景的紫波抢色。修改：背景紫光降饱和或换成中性冷灰，让紫色只属于主角波形。

### B4_07（镜面 → 多层膜放大）
画面：一面切开扇形缺口的多层膜反射镜，镜面上方有一束紫光 V 形反射；镜头推近切口，圆形放大框里是灰阶 TEM 式 Mo/Si 层，标注「钼/硅 × 40 对 · 每对约 7 nm · 总厚约 0.3 μm」。
封顶：无。放大框指向镜面最顶层的白色薄层，满足检查重点。
1. **入射点下方有紫光透进镜体**（55 % 帧缺口处有一团紫色辉光），会被读成光穿过了镜子。修改：落点只保留镜面上的一个椭圆高光，镜体内部和缺口侧面不要有任何紫光。
2. 基底是粉褐色哑光材质，像陶土或塑料。修改：基底改成微晶玻璃（ULE）质感，带浅灰半透、细抛光侧面和倒角高光，镜座加螺栓和柔性支撑细节。
3. 放大框里的刻度数字（10/20/30/40）在 960 宽下读不出来，而且没有比例尺。修改：加一条「10 nm」比例尺（k4D 写法），刻度字号放大到画面高度的 ≥ 2.2 %。

### B4_10（地球—月球—高尔夫球比喻）
画面：地球射出一条白色激光到月球，镜头一路推到月面上的一颗高尔夫球，标签分别是「月球 距地球约 38 万 km」和「高尔夫球 直径约 4 cm·尺寸示意」。
封顶：无。
1. **高尔夫球的凹坑是随机分布的大小坑，看起来像一颗小月球**，而且比例很大。修改：改成规则的六边形排布浅凹坑、白色微光泽塑料材质；按「示意」把尺寸压到画面高度约 1/6，并加一圈青色定位环。
2. 85 % 帧的月面是一块模糊的灰泥，没有环形山，材质比 55 % 帧的月球远景还差。修改：给近景月面高分辨率的位移和法线贴图（月壤颗粒、小坑），并在球下压出接触阴影。
3. 激光在 25 % 帧里是从地球边缘「插进去」的。修改：起点放在地表一个可见的小亮点（标「激光站」），光束带极细的发散锥。

### B6_12（掩模 + pellicle）
画面：中灰棚拍底上，黑色掩模的图形面朝上，上方是金属框绷着的 pellicle；85 % 帧推近，有掠射高光、「膜厚 13 nm」标注和「间距：膜面 ↔ 图形面」的尺寸线。
封顶：无（膜可见、间隙可见，H1 不触发；无彩虹，H8 不触发）。
1. 膜像一块茶色玻璃板，透过去的图形被整体压暗，不像 k5A 那种「几乎看不见、只有掠射高光」的薄膜。修改：膜的透射提高到 ≈ 90 %、去掉染色，只保留边缘张力引起的细微反光渐变；把「几乎透明」交给高光来表达。
2. 掩模本体是哑光黑板，看不出反射式掩模的镜面多层膜。修改：图形区底面改成深色镜面（能反出棚灯条），吸收层图形做哑光，形成反射/吸收的对比。
3. 55 % 帧里掩模标签的引线指向底座边缘，不是图形面。修改：圆点锚放到框内露出的图形上。

### B8_17（晶圆格子 + 三个计数器）
画面：工件台上的晶圆按场格逐行变紫（曝光），右侧晶圆盒里的晶圆堆叠增加，右上计数器依次是 43→143→188 场/片、124→185+ 片/小时、3.4 万+ 次曝光/小时。
封顶：无。场格：约 12 列 × 17 行宽矩形格，边缘裁掉后大致落在 180–200，宽高比符合半场；与 188 场/片不冲突（单帧无法逐格精确核对）。H9：188 和 185+ 都属于 EXE 一代，不混代。
零件辨识（背景）：CF 法兰观察窗、波纹管直线进给器、导轨、拖链、电控箱（带指示灯）、晶圆盒，共约 6 种。墙面不是同一种格子铺满，但零件挂在墙上，像工具展示板。
1. **曝光点是一条悬空的白色短线，上面一团紫雾**，外行读成「悬空白点」，看不出光从哪里来。修改：从画面上缘引下一条锥形收窄的紫色狭缝光带，落到晶圆上成一条亮狭缝，随扫描移动。
2. 已曝光的场是均匀发光的紫色平块，像屏幕贴图。修改：已曝光的场改成硅片底上带细微图形纹理的暗紫色潜像，正在曝光的那一条最亮，让「一条一条扫过」可读。
3. 背景零件像挂在墙上的道具。修改：把法兰和波纹管做成接到腔体上的结构（有管路连接），后景加一层虚焦的设备层次，形成 ≥ 3 层景深。

### B9_05（光子雨 + 1 nm² 计数）
画面：紫色光子拖着尾迹落在光刻胶线条上，圆形放大框里的 3×3 nm² 网格计数随时间增加（中心格 3→16→20），85 % 帧出现「剂量 ≈ 20 光子/nm²（示意）」和「落点随机 → 线条边缘起伏」。
封顶：无。55 % 帧与金控帧完全一致。整镜比金控单帧多了剂量标注和计数过程，C/F 各 +2/+4，属于信息上的真实差异。
1. 胶线是一摞重复的砖块，看不出「线边粗糙」是由光子落点造成的。修改：把线条做成连续的胶体，用位移贴图做出边缘起伏；起伏程度随计数过程增大，与放大框里的随机分布对应。
2. 光子形状像带尾巴的雨滴/精子，尾迹太长。修改：缩短尾迹，头部改成小而锐利的亮点，落地时溅出一个短促的环形闪光。
3. 网格角落的计数数字太小（约 9 px）。修改：只保留中心格的大号计数，周围格改用亮度深浅表示多少。

### D_07（洁净室 + 两名工程师）
画面：与金控同一张洁净室图，从 25 % 到 85 % 慢推，人物姿态完全不变；「5100 家供应商」标签在 85 % 帧消失。
封顶：无（有推镜，不按 H2 判；但人物冻结，D 维按近静帧扣到 80）。
1. **人物在三帧里姿态完全一样，只是图片在放大**，是 2.5D 推照片的感觉。修改：人物分层做行走循环（至少脚步和手臂在动），或者加视差，让设备层和人物层的位移不同。
2. BRIEF 要的是「灯光一亮，巨物旁边出现人」，画面里没有亮灯这个事件。修改：开头 20 % 先压暗，顶灯成排亮起，人物在亮灯后出现。
3. 标签框中间空了一行。修改：补一行「欧洲为主 · 全球分布」或者把框高压缩为两行。

## 4. 本路最值钱的改法

1. **每屏只留一条锥形主光路**（A2_03、A2_08 背景、B8_17）：删掉交叉和多余的紫光柱；光束做成锥形收放加软边，落点是镜面上的高光，镜座不自发光。预计每镜 C/A 各 +2–3。
2. **B8_17 加狭缝光带并区分曝光状态**：从上方引下收窄的紫色狭缝光，替代悬空白线；已曝光、正在曝光、未曝光三种状态的场格分开画。
3. **材质专项**：B4_07 基底改成 ULE 玻璃，B4_10 的高尔夫球和月面重做，B6_12 掩模加镜面多层膜、膜透射提高到约 90 %。这三镜的 A 维都在 82–88，是本路最大的短板。
4. **D_07 做真运动**：人物行走循环或分层视差，再加一个亮灯事件；D 从 80 提到 ≥ 88 就能单镜过线。
5. **标注排版统一检查**：A0_06 的计数框避开焦点，B4_07 和 B9_05 的小字放大到画面高度的 ≥ 2.2 %，D_07 去掉标签空行。
