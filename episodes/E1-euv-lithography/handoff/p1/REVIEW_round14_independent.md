### A0_01（冷开场锡滴，photoreal）
- 画面：25 % 处，暗腔里一颗反光锡滴，标签「锡滴 ≈ 25 µm（头发丝约 80 µm）」。55 % 处，一张褶皱的银灰圆盘占满画面，中心有橙色激光斑。85 % 处，紫色等离子辉光，加一个 Sn⁸⁺–Sn¹⁴⁺ 放大框。
- 封顶：无。片名卡不在冷开场，H7 不适用。
- 问题与改法：
  1. **55 % 帧读不懂**：薄饼整屏放大，像揉皱的铝箔或水花，看不出尺度，也看不出「连打两次」。改法：把机位拉远，让薄饼只占画面约 1/3，保留腔壁和喷嘴做尺度参照；表面换成薄液膜（边缘更薄更亮、中心略透），去掉粗的金属褶皱；橙色主脉冲画成从侧面射来的锥形光束，不要画成贴在盘心的圆斑。
  2. 放大框里「Sn⁸⁺」被紫色波浪线压住了。改法：把波浪线绕开离子标签，或者把标签放到离子下方。
  3. 85 % 帧腔体太暗太空，远不到 k3A 的金属腔密度。改法：等离子体背后补一圈有轮廓光的收集镜沿和腔壁法兰，把亮暗比拉到 ≥8:1。

## 3. 逐镜意见

### A0_06（infographic，5100 家供应商）
写实地球，荷兰处放射出青色弧线和成团光点，右上等宽计数器 957 → 3,605 → 5,100，左下注明「光点位置为示意」。没有命中封顶；地球是 3D 实物，不算 7C。
- 光点都挤在西欧，成了一团白色噪点，「一张网」读不出来。修改：给北美、日本、韩国、台湾、以色列各放一个可见的光点簇，弧线落点要落在这些簇上，不要飞出球体边缘消失在太空里；光点改成大小不一、带辉光的点，荷兰主节点放大一档。
- 运动只有弧线生长和计数器，机位几乎不动。修改：加一次缓慢的地球自转加推近（例如 10°/镜），后段转到能看到美洲的角度，让 H2 的视差更明确。
- 「荷兰·整机总装」标签压在格陵兰 / 冰岛上方，引线又细又短。修改：标签挪到荷兰东侧空白处，引线用 1.5 px 加圆点锚，直接落在主节点上。

### A2_03（type，CD = k₁·λ/NA）
公式衬线排版，叠在半透明深色底条上，四项各有中文名，λ 紫、NA 青；背景是真实的镜路剖视（镜座、线槽、环形管），有推轨和焦点变化，H14、H2 不命中。
- 第 3 帧里镜座机构挡在「k₁·λ」字形前面（或透出底条），公式本身被遮住。修改：公式底条不透明度提到约 85 %，或者给公式层设 holdout / 放到最上层合成；机构的运动避开公式区域。
- 「k₁ 的物理极限：0.25」标签压在「镜子收光的锥角 → NA」上，两个标签打架。修改：两个标签不要同时出现（先 NA 锥角，再换成 k₁），或者 k₁ 标签挪到左侧 k₁ 正下方。
- 背景有 4–5 根粗实心紫色光柱交叉成网，抢了公式的戏，也违反「每屏一条主光路」。修改：只留一条 W 形折返光路，光束改成锥形收放、软边，镜面上能看到落点；其余光束删掉或压暗 70 %。NA 锥角的示意线目前太淡，改成一束从镜子向焦点收的半透明光锥，配青色角度弧。

### A2_08（energy，13.5 的细笔）
虚焦的机内背景（实物，H14 不命中）上叠了 193 nm 白色正弦和 13.5 nm 紫色细波，第 3 帧有尺寸线「1 个 193 nm 波长 = 14 个 13.5 nm」。我量了周期比，约 15:1，基本对。
- 背景里的紫色光束和 13.5 nm 紫波同色，又是大片高亮斜线，跟主角抢眼。修改：背景光束降到 30 % 亮度，或者换成冷灰虚焦金属，让紫色只留给前景这条细波。
- 尺寸线跨度和 193 nm 的一个周期对不齐（括号比实际周期宽）。修改：括号两端对准 193 nm 波形的相邻两个波峰，在括号内同步数出 14 个紫色周期（每个周期一个刻度点）。
- 第 2 帧「13.5 nm」标签压在紫波末端。修改：标签往下挪 20 px，或放到波形右端外侧。

### B4_07（sem，镜面 → 多层膜）
一面切掉一块扇形的圆镜，紫色入射光和反射光落在镜心，镜头推近到切口顶缘，圆形放大框里是 TEM 风格灰阶截面，刻度 0–40 对，标注「钼/硅 × 40 对·每对约 7 nm / 只在镜面最顶层·总厚约 0.3 μm」。放大框引线确实指向镜面顶层，满足本轮检查重点。这是本路信息最清楚的一镜。
- 基底切面是一整块哑光灰面，像蛋糕切口，没有抛光基底和镀膜层的区分。修改：切面上沿画一条极细、亮的镀膜带（顶层 0.3 μm 用高光线强调），基底用细磨玻璃 / ULE 材质（微透、细颗粒），和金属镜座区分开。
- 第 1 帧右侧有一大块过曝白区加噪点斑；第 2 帧镜面反射里有一块模糊的矩形「文字块」。修改：压掉这盏补光灯（或给它加柔光箱），把场景里反射到镜面的 HUD / 平面物体隐藏掉。
- 放大框里只有对数刻度，没有 nm 比例尺。修改：在框左下加「10 nm」比例尺（照 k4D 的做法）。

### B4_10（photoreal，地月高尔夫球）
写实地球 → 月球 → 月面上的高尔夫球，白色光束一路命中；顶部标注「<0.1 nrad·蔡司的比喻」，有出处。
- 第 1、2 帧有零碎的青色虚线段（月球标签下方、字幕上方），像断掉的尺寸线，读起来是穿帮。修改：要么画成从地球到月球的完整距离尺寸线，两端带端点，标「约 38 万 km」；要么删掉。
- 高尔夫球标签用了橙色竖条，橙色应该只留给激光。修改：改成计量青或线稿白。
- 高尔夫球相对月面大得离谱，而且没标示意。修改：标签加「尺寸示意」，或者用放大框（圆形 Micro 框）展示球，宏观镜头里只留一个小亮点。

### B6_12（xray，pellicle 13 nm）
中灰棚拍里，掩模图形面朝上，上方是张在金属框上的 pellicle；标注写明保护膜、掩模、「膜厚 13 nm」「间距（示意）」。不是 5C 扁平剖面，棚光接近 k2A。
- **H6**：膜面上有 3–4 颗棕色颗粒，既没有标注，旁白也没说，观众会以为是脏点或渲染瑕疵。修改：加标签「颗粒落在膜上 → 离焦，不会成像」，或者这一镜直接删掉颗粒（留给讲颗粒的镜头）。
- 「间距（示意）」的工字尺量的是角上的支撑块高度，不是膜面到掩模图形面的距离。修改：把尺寸线移到框内侧，两端分别落在膜平面和掩模图形面上，最好配一个侧向微剖切，让间隙看得见。
- 膜的「几乎透明」读不出来，现在像框上盖了一层灰雾。修改：参照 k5A，膜本身做到 90 % 透明，只在掠射角给一条细高光带，边缘留一圈微皱 / 张力反光，图形面透过膜要清晰。

### B8_17（infographic，188 场 / 185 片 / 3.4 万）
晶圆放在卡盘上，曝光头下面的紫光逐格点亮场格，右侧是片架（晶圆盒）里一摞晶圆，右上计数器 43 → 143/124 → 188 / 185+ / 3.4 万+（188×185 ≈ 3.48 万，对）。场格约 13 列 × 20 行，切边场也算上，数量和 188 量级一致；格子是横向长方形，符合半场形状。
- 零件辨识度：能叫出名字的有物镜头、晶圆卡盘、片架、线缆卷 / 管束卷、蓝色接插件排，共 5 种；墙面没有重复铺格子，但这些零件全挤在上沿，被裁掉一半。修改：机位降 10°，把物镜筒和片架完整收进画面；再加一个双台（第二个卡盘）在旁边待命，「每小时 185 片」才有机构上的根据。
- 曝光光斑是一个方形辉光块，读不出扫描狭缝。修改：改成细长条狭缝光带，在当前场内扫过，扫完才点亮该格。
- 右上计数面板第 1 帧有一大块空黑底，三个数又分两种颜色。修改：面板高度随行数增长；数字统一用青色（188 可以保留紫色表示曝光，但要在图例里说明）。

### B9_05（energy，光子雨）
泪滴状光子落在抗蚀剂线条上，圆形放大框是 3×3 个 1 nm² 格子，中心格计数 3 → 16 → 20；第 3 帧出现「剂量 ≈ 20 光子/nm²（示意）· 落点随机 → 线条边缘起伏」，格内均值约 20。机理讲清了。
- 光子画成带长尾的泪滴 / 彗星，外行可能读成「水滴」或「精子」。修改：尾巴缩短到 1/3，头部改成小而亮的点，再加一个落地时的闪点（小 bloom）。
- 宏观表面上的线条是均匀的规整楼梯，「线边粗糙」只在文字里讲了，画面看不到。修改：末段让宏观线条的边缘出现随机起伏（LER），放大框的引线指到起伏处。
- 第 1 帧顶部有一个被裁掉一半的环形物体。修改：要么完整入画（作为光来自投影镜的锚），要么移出画面。

### D_07（documentary，5100 家供应商和工程师）
和金控同一画面：高密度设备墙（真空腔、阀组、管路、电源箱、观察窗），两名洁净服人员背身走向黄光区，人在走，机位微推，有真实的运动。
- BRIEF 的「灯光一亮」没有体现。修改：开头 0.5 s 先暗，再让顶灯分段点亮（从近到远逐排亮起）。
- 右上标签中间一行空着（只有标题和来源）。修改：补一行「荷兰 · 德国 · 美国 · 日本…」或者删掉空行，把卡片压成两行。
- 前景设备墙左侧过曝发灰。修改：压暗左侧高光 0.5 EV，加一点前景景深，把视线引到人物身上。

## 4. 本路检查重点核对
- H9：本路 F 维没有发现混代（B8_17 用的是 High-NA 188 场；其余镜头不涉及 NA / 倍率）。
- H14：A2_03、A2_08 的背景都是实物机内（可以虚焦），不算 7C。
- B8_17：场格数约 188，和计数器一致。B4_07：放大框指向镜面顶层，满足要求。
- 配色：B4_10 高尔夫球标签用了橙色竖条，违规；其他镜头里橙色没有出现在激光之外。
- 光束外行读法：A2_03、A2_08 背景里有多根实心紫光柱交叉（「实心光柱」读法），每屏不止一条主光路；B8_17 的曝光光斑是方块辉光，不是狭缝。

## 5. 本路最值钱的改法
1. **B6_12 去掉 H6**：膜面颗粒要么加标签「颗粒落在膜上 → 离焦」，要么删掉；间隙尺寸线改成量膜面到图形面。单这一项就能让 C 从 70 回到约 88，总分 +4.5。
2. **A2_03 / A2_08 的紫光柱只留一条、做成锥形软边**，公式层改成不透明底条，放在最上层合成；k₁ 和 NA 两个标签分时出现。A2_03 预计 +4。
3. **B8_17 曝光光斑改狭缝扫描，再补第二个工件台**，机位下压，让物镜和片架完整入画。
4. **B4_10 / B4_07 清掉穿帮**：断掉的青色虚线、过曝补光、镜面反射里的矩形块、橙色标签；B4_07 加 10 nm 比例尺和切面上的镀膜亮带。
5. **A0_06 光点按地区分簇、地球缓慢自转**，「一张全球网」才读得出来，同时补足 H2 视差。
