- 「5100 个光点」读不出来：现在的光点和城市夜光混在一起。关掉城市夜光贴图，只留供应商光点，光点随计数器逐批点亮。
- 极地视角让人难认出欧洲。机位往南压 20° 左右，让荷兰和欧洲轮廓先被认出来，再往外拉弧线。

**A2_03**：CD = k₁·λ/NA 公式条浮在 CG 机舱上方，λ 紫、NA 青，下方有一道照到晶圆的光锥，标「镜子收光的锥角 → NA」。
- 中帧同时有两道紫光（光锥向上进镜子，镜子又射向右侧），而且和 θ 引线交叉，读起来像「光在空中分叉」。每屏只留一条主光路：只留会聚到晶圆的光锥，θ 标在锥的两条母线之间。
- 背景零件：镜座、hexapod 式支架、仪表墙、拖链 / 线槽、真空管件，约 5 种。但右侧墙是同一种仪表格子铺满，要换成 2–3 种不同模块（阀岛、电源箱、气路面板）。
- 公式条遮住了画面上方 1/4 的机械。条带降低不透明度，或改成只给公式本身加暗底。

**A2_08**：虚焦机舱前叠一道白色 193 nm 波和一道紫色 13.5 nm 波，下方括号标「1 个 193 nm 波长 = 14 个 13.5 nm」。
- 括号与 193 nm 一个周期基本对齐，比例正确。但 55 % 和 85 % 两帧几乎一样（紫波在 55 % 已经画完）。后半段加一个动作：两道波同步向右平移，或括号从 0 数到 14 逐格亮起，避免近静帧。
- 白波线宽和亮度偏弱，像引导线不像光。白波改成冷白发光线，与紫波同等粗细。

**B4_07**：镜面被切掉一个楔角，两道锥形紫光在镜面上反射（落点可见、软边），放大框指向**顶层膜**，里面是 TEM 风格的 40 对层，标注「钼/硅 × 40 对 · 每对约 7 nm，总厚约 0.3 μm」。机理和事实都对。
- 放大框里的层号刻度（10/20/30/40）是青色叠在灰底上，几乎看不清，左下角的比例尺「…00」被圆框裁掉。刻度加深色描边或底条，比例尺整体移进框内。
- 85 % 帧的左半屏是大片空灰基底。机位向右收，让镜面上的光落点留在画内，宏观与微观同框。

**B4_10**：地球 → 月球 → 月面高尔夫球，白色激光贯穿，标注 < 0.1 nrad。
- 地球云层略软、略卡通。云层用更高分辨率贴图，并加大气散射边。
- 「地球」标签用的是方框底，与另外两个标签的竖线样式不一致。统一成竖线 + 深色底条。

**B6_12**：从下往上仰视掩模台：反射掩模图形面朝下，金属框上张着 pellicle，掠射高光可见；85 % 帧有放大框，标出掩模图形面 / 间隙（几毫米）/ 13 nm 膜，并注明「间距不按比例」。
- 放大框内容太抽象（白块 + 一根 I 形标尺），看不出是膜。框内改画「掩模图形 → 空隙 → 一条极细亮线（膜）」的侧视切面，膜加掠射高光。
- 画面上的文字太多（两条引线标签 + 放大框里 4 行），超过「≤3 行」。85 % 帧去掉上方两条标签，只留放大框的标注。
- 夹持块是黄铜 / 橙色，接近激光橙。降饱和，改成中性金属。

**B8_17**：晶圆台上方有物镜筒和紫色光锥，晶圆上画了场格；计数器 43 → 143 → 188，185+，188 × 185 = 3.4 万+。能叫出名字的零件：物镜筒、电路板机柜、线缆 / 气管束、晶圆盒、接线盒、带磁轨的工件台，约 6 种。墙面没有用同一种格子重复铺满。
- **场格数和 188 对不上**：圆内大约 13–15 列 × 10 行，约 110–120 格，而且是方格。按 High-NA 半场（约 26 × 16.5 mm）改成长方形格，排到 188 个整场 + 边缘场。
- **曝光进度和计数器矛盾**：143 帧里只有右侧约 1/4 是白格。按蛇形扫描逐格变亮，亮格比例跟随计数器（143/188 ≈ 76 %）。
- 右上角晶圆盒最上面一片有运动模糊拖影，压在标签后面。去掉拖影，或把晶圆盒移出标签区。

**B9_05**：光子雨落在紫色光刻胶线条上，放大框计数 3 → 16 → 20；85 % 帧出现「剂量 ≈ 20 光子/nm²（示意）· 落点随机 → 线条边缘起伏」。85 % 帧的格均值约 20，与标注一致。
- 剂量标注只在最后才出现，前 2/3 的计数（3、16）会被误读成「平均就这么多」。剂量标注提前到 25 % 出现，计数改成累计进度条。
- 光刻胶线条用的就是 EUV 紫，与「紫 = EUV 光」的约定冲突，而且线条边缘起伏不明显。光刻胶改成中性灰或琥珀色，在放大框旁再加一张线边粗糙特写。

**D_07**：洁净室设备墙旁，两个洁净服人物背影向黄光区走去，机位缓推。
- BRIEF 要的「灯光一亮」没有出现。前 25 % 先压暗，再让顶灯分段亮起，人随之出现。
- 「5100 家供应商」标签框中间是空行。补一行「和无数工程师」，或把框收窄。

## 本路最值钱的改法

1. **B8_17 重做场格**：画 188 个长方形半场，曝光按蛇形扫描、亮格比例跟随计数器。这一镜只要改这一项，C/F 预计能 +8。
2. **每屏只留一条主光路**：A2_03 去掉第二道紫光，θ 只标在光锥上。B6_12 和 B9_05 的紫色只留给 EUV 光（光刻胶换色，夹持块去橙）。
3. **A0_06 提亮主体、去掉城市夜光**：给地球加轮廓光，只留供应商光点并随计数器逐批点亮，机位往南压到能认出欧洲。
4. **标注可读性**：B4_07 放大框刻度加描边、比例尺移进框内；B6_12 把文字压到 3 行以内；D_07 / B4_10 统一标签样式、填掉空行。
5. **消除近静段**：A2_08 后半段加平移或括号计数，B9_05 剂量标注提前出现，D_07 加「灯光一亮」。
