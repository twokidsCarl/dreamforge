## 逐镜点评

**A0_10 片名卡**：白棚灰地上放着一台去掉侧板的白色整机，从左到右是光源腔、照明和投影几个舱；紫光束逐帧点亮；两个白色洁净服人偶，标「人≈1.8 m」；上方是白色衬线片名。
- 封顶：无（H7 不触发，有片名）。H13 逐条看：镜子带镜座✓；体积光✗（光束是扁平半透明条）；≥3 层景深基本✓；剖切壳厚✓（白框）；一条光路大致✓。达标但很勉强，所以不封，A 给 79。
- 改法：① 舱内密度要提 3 倍以上：后墙大片空的灰格子换成线缆槽、电控箱、真空管和法兰（对照 k1C 机身里密密麻麻的机电件）；② 光束加体积散射和端面光斑，让光路从光源一路亮到晶圆；③ 按 EXE 分层重排（掩模层在顶、光学在中、晶圆在底，光源单独在旁），现在是水平三舱，F 扣 4 分。
- 对应点选 k1C + k2A：差的是机身内部密度，以及人和机器的尺度冲击（人偶太显眼，机器显得矮）。

**A0_01 锡滴冷开场**：橙色激光打中锡滴 → 液态铬亮的薄饼 → 白色等离子球，旁边一个放大框画 Sn⁸⁺–Sn¹⁴⁺ 离子。
- 封顶：无。
- 改法：① 等离子体现在是一个平白圆盘，改成有内核梯度、紫粉色辉光、带碎屑喷溅的体积等离子（k3A）；② 放大框里离子的上标压在球体上，标签要移到球外；③ 背景腔体虚得太平，至少给一圈收集镜边缘的金属高光当宏观锚。
- 对应点选 k3A + k3D：等离子体的体积感和腔体写实度还差一截。

**A0_02 夜间货机装货**：雨夜机坪，大型货机机头打开，钠灯，升降平台上是白色铝框箱，有地勤，机身无航司标志。
- 封顶：无（H4、H12 都没触发）。
- 改法：① 三帧只有轻微推进，加一层前景运动（升降台起降或地勤走动）把 D 拉上 85；② 左下角被裁掉一半的人影要么去掉，要么完整做成逆光剪影。
- 对应点选 k8A：已经基本并排不输，差的是运动层次。

**A0_03 数量链条**：前景一排白色铝框箱，背景是货机和卡车队，逐级叠出「250+ 箱 / 几架货机 / 20 辆卡车」标注。
- 封顶：无。
- 改法：① 「43 个集装箱」只写在字里，画面上没有，在中景补一排集装箱或货网托盘；② 「几架」的引线横穿标签本身，改成从标签下沿的圆点锚引出。
- 对应点选 k8A + k7A：数字没有都压在对应实物上。

**B1_10 预脉冲拍饼**：激光打中锡滴；放大框里 25 μm 的点在三帧里变成 300 μm 的侧视薄饼，主画面是液态金属薄饼。
- 封顶：无。
- 改法：① 薄饼中心有一个黑色「星裂」伪影，去掉；② 背景竖条太素，换成虚焦的腔体零件和喷嘴。
- 对应点选 k3A + k3D：放大框的用法已经对路；宏观腔体的写实度还不够。

**B1_15 等离子 × 镜面**（全片最低）：正面看收集镜，紫色碗面加螺栓边圈；中心是白色等离子，带一个白色圆环；四周飞溅橙白色碎屑。
- 封顶：无（H1 不触发，镜面看得到；等离子大致在光轴中心上）。
- 改法：① 中心那个白色细圆环看起来像 UI 圆圈或渲染错误，删掉，改成球形辉光；② 镜圈右下有黑白椒盐状飞点（采样或粒子穿模），要修；③ 背景钢板上的散点孔和大黑洞像玩具面板，换成有法兰、管线和传感器的腔壁；④ 镜面加真实反射（映出等离子和腔体），把「原子级光滑」演出来；⑤ 三帧只有火花在变，相机加缓推或焦点拉移。
- 对应点选 k3A：腔体写实度和镜面反射质感差得最多。

**B3_02 椭球收集镜**：剖开的真空腔里，左边是金铜色收集镜，橙色激光从中心孔穿过；紫色光锥向右会聚到中间焦点 IF（锥管颈部的一个点），过 IF 后继续往前走。
- 封顶：无。光锥会聚到 IF 画对了；IF 不是镜子；中心孔有标注。H13 五条基本达标（腔体带壳厚，有管线法兰，体积光锥，三层景深）。
- 改法：① 收集镜的金铜色加橙色加热丝感，跟「激光橙」撞色，镜面应该是银灰多层膜的冷反射；② 标签有 4–5 个，中帧「第一焦点」被「中间焦点 IF」压住，按 ≤3 行原则分时出现；③ 三帧机位几乎不动，加推轨或焦点从镜面拉到 IF。
- 对应点选 k3A + k4A：镜面材质和标注干净度还差。

**B4_10 地月高尔夫球**：写实地球射出橙色激光到月球，再推到月面上的一颗高尔夫球。
- 封顶：无。
- 改法：① 中帧月球标签旁有断裂的白色虚线（引线渲染残片），要清掉；② 第三帧的月面像一块灰墙，加月壤颗粒和低角度光。
- 对应点选 k7A：实物同屏方向对；月面质感和引线干净度差。

**B5_01 照明系统**：IF 射出的光 → 顶部场分面镜（方形小镜阵列）→ 左下光瞳分面镜（圆内排着光斑）→ 聚光镜 → 往掩模方向。背景是带青色 LED 的机柜格子墙。
- 封顶：无（H13 勉强达标：实心镜加镜座，三层景深，一条光路；但体积光偏扁平）。
- 改法：① 光束现在是平板式半透明条，改成带体积散射和端部光斑的光锥；② 场分面镜按事实写成弧形长条小镜，现在是方块阵列，F 扣分；③ 后墙格子和机柜改成有真实机电件的真空腔壁，去掉「游戏关卡墙」感；④ 到处戳出来的橙色细杆（橙色专属于激光）改成灰或黑的线缆。
- 对应点选 k4A：镜座金属质感和光束体积感还差一截。

**C_03 一镜到底**：IF 锥管 → 照明舱 → 抬头看到顶部掩模，紫光斜入射再反射下去；机位一路移动。
- 封顶：无（H13 达标但勉强）。
- 改法：① 掩模只是顶上一块小黑片，认不出是掩模：要放大，给出反射面和吸收图形的高光，以及夹持台和 pellicle 框；② 第三帧光束交叉很多，突出主光路，次要光路压暗；③ 右侧的环形管和橙色天线状杆件散乱，改成镜座和支撑结构；④ BRIEF 要求的「扫描光带扫过、墙壁变幽灵玻璃」三帧里没看到。
- 对应点选 k2B / k4A：结构密度和「光一拐弯就是镜子」的清晰度差。

**B6_12 掩模 + pellicle**：中灰棚拍，掩模图形面朝上，上方是黑色金属框绷着几乎透明的膜，有掠射高光，标注「膜厚 13 nm」「间距（示意）」。
- 封顶：无（H8 不触发，没有彩虹；膜和间隙都看得到）。
- 改法：① 膜上的黑色颗粒没有说明，补一句「颗粒落在膜上 → 离焦不成像」，或者删掉；② 第一、二帧膜几乎看不见，把掠射高光提前，让三帧都能读出这层膜（k5A）；③ 掩模加一点玻璃基板的边缘厚度和反射。
- 对应点选 k5A：薄膜的微透与边框质感接近，掠射高光不够。

**B1_22 CO₂ 驱动激光**：螺纹散热的放大器管线，内部有橙色激光；下方 HUD 逐级点亮「种子 ~W → 放大 1–4 → 数十 kW」。
- 封顶：无。
- 改法：① 顶上漂着的蓝色弯管没有依托，看着像穿帮，接到机柜上或删掉；② 背景加楼板（华夫板）或长光路的纵深，把「光路约 30 m」的尺度带出来。
- 对应点选 k3A / k2B：硬件质感不错，环境密度不够。

**A2_08 193 vs 13.5 波形**：虚焦的机内实景（有紫光）上叠白色 193 nm 正弦和紫色 13.5 nm 正弦，后者逐渐铺开，标注「1 个 193 nm 波长 = 14 个 13.5 nm」。
- 封顶：无（H14 检查：背景是虚焦实物，不触发）。
- 改法：① 虚焦背景里的紫光束和波形抢视觉，背景压暗 1 档；② 13.5 nm 波形加一点辉光，做成「细笔」的高光。
- 对应点选 k7A：数字压在实物上的方向对。

**B9_05 光子雨**：泪滴形紫色光子落在光刻胶线条上；圆形放大框里是 3×3 个 1 nm² 网格，中心格计数 3 → 16 → 20。
- 封顶：无（H15 不触发，有放大框和宏观锚）。
- 改法：① 光刻胶线条是方块拼的低模，加圆角和边缘粗糙度（顺便演示线边粗糙）；② 画面上半是空的黑天，给出投影镜底部或晶圆台的虚焦结构。
- 对应点选 k6D：放大框用得对；宏观晶圆的质感差。

**B2_08 氢自由基清洗**：收集镜面带锡斑；放大框里 H· 抓住 Sn 变成 SnH₄ 被泵抽走；右上有泵口标注。

- 改法：① 右下大白光斑（lens flare）抢视觉，删掉或减半；② 镜面加多层膜的冷光泽和环境反射，现在像拉丝灰板；③ 泵口的锥形件要标出名字。
- 对应点选 k3A + k3D：放大框对路；镜面材质不够。

**B4_07 镜面 → 电镜截面**：多层膜镜切出一块楔形，推到镜面顶层，圆形放大框里是灰阶电镜质感的 Mo/Si 层叠，带刻度和「×40 对·每对约 7 nm·总厚约 0.3 μm」。
- 封顶：无。放大框锚点落在顶层膜的边缘，指得对。
- 改法：① 楔形切面和侧壁是哑光白塑料，换成抛光的玻璃陶瓷或 ULE 基板质感（k4A 的镜子是金属与玻璃）；② 首帧右侧白区的噪点和飞点要修；③ 镜座的铜线加精细的固定件。
- 对应点选 k4D：截面已经接近；宏观镜体的材质差。

**B8_03 掩模台 / 晶圆台反向扫描**：去壳展示照明舱和投影舱，切面是粉橙色；顶部掩模台带标尺向右移，底部晶圆台带 ×4 放大标尺；HUD 读数 2.00/0.25、4.40/0.55、6.80/0.85 格。
- 封顶：**H13，A ≤ 75**。两个舱是简单矩形盒加粉橙切面，舱内是零散的小镜和叫不出名字的细杆件，机电件大多认不出来；光束是细线，没有体积；投影舱里多条光束交叉，拓扑难读。
- 正面的地方：三帧读数都严格 8:1，标注写了「约 5.4°（图中角度放大示意）」和「High-NA 缩小 8×」，同一代数据，H9 不触发；掩模斜入射、斜反射的 V 字可读。
- 改法：① 两个舱要按 k2B 重建：带镜座的实心镜，加真空腔壁、线缆、传感器和冷却管；② 光路拓扑一笔讲清：照明 → 斜射掩模 → 反射进投影 → 晶圆，每段一束，次要反射去掉；③ 晶圆台位移只在 ×4 放大框里能看到，晶圆本身认不出是晶圆，要画出带场格的晶圆，并让放大框里的位移明显；④ 粉橙切面跟激光橙撞色，改成中灰或冷白切面。
- 对应点选 k2B + k4A：这是全组离锚最远的一镜，差的是结构密度和光路可读性。

**B7_06 投影物镜棚拍**：白棚转台上是剖开前盖的物镜舱，紫光在 M1–M6 之间折返，右边站一个 1.8 m 的白色洁净服人偶。
- 封顶：无（H13 达标：镜带镜座，有壳厚，光路单一；密度中等）。

- 对应点选 k2A + k9B：棚光和人做尺度的方向对；结构密度差。

**B1_08 逐颗拍照瞄准**：金属竖条背景前，锡滴一颗颗飞过，每颗套一个青色 HUD 准星。

**D_07 洁净室两人**：照片质感的冷白洁净室，左侧是机台，远处有黄光区，两名洁净服人员背身走远。

**A0_06 5100 家供应商地球**：半透明玻璃质感的地球，荷兰光点向外拉弧线，计数从 957 涨到 5,100。

**A2_03 CD 公式**：虚焦的机内光路背景，上面是半透明底条的衬线公式 CD = k₁·λ/NA，各项依次点亮（λ 紫、NA 青），附「k₁ 的物理极限 0.25」「镜子收光的锥角 → NA」。
