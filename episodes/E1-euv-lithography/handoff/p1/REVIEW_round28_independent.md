## 3. 逐镜意见

### A0_06（地球 + 供应商光点，5,100 计数器）
画面：写实地球从欧洲特写拉远，荷兰发出青白色弧线连到北美和亚洲，右上计数器 957 → 3,605 → 5,100。封顶：无。
1. 「5100 个光点织成一张网」读不出来：光点挤在西欧一团，弧线只有十几条，亚洲（日、韩、台）几乎看不到点。建议按真实分布在美、日、韩、台、中加密光点，85 % 帧至少 60–80 条细弧，粗细随距离渐细。
2. 弧线是等宽的亮青白线，在地球边缘处显得「实心」。建议改成两端细、中段略粗的渐隐弧，亮度降 30 %，让光点本身做主体。
3. 计数器用等宽数字，带来源和「光点为示意」，做得对。「荷兰·整机总装」标签到 55 % 才出现，可以提前到 25 % 帧，和第一批光点同时出。

### A2_03（CD = k₁·λ/NA 公式叠在机内实景上）
画面：机内镜座、晶圆台实景（前虚后实），顶部是公式条，λ 紫、NA 青；光锥会聚到晶圆，θ 角标出 NA。封顶：无。H14 检查：背景是实物，不是纯深底，通过。
零件辨识：镜座（hexapod 式）、晶圆卡盘、环形导轨、离子泵状圆罐、阀块、电路板、线槽，约 6–7 种。右侧墙面是同一种「圆罐 + 阀」单元按格子重复铺满，一眼能看出是复制。
1. 右墙的重复格子要打散：换 3–4 种单元（波纹管、观察窗、气路面板、电源箱）随机混排，并加深度错落。
2. 85 % 帧里同时有两段紫光（右镜 → 顶镜、顶镜 → 晶圆），外行可能读成两条光路。建议让右镜那段亮度降一半，或者在顶镜落点加一个可见的高光点，让人看出「在镜子上拐弯」。
3. 公式条占画面上方约 1/4，25 % 帧里 NA 是暗灰色几乎看不见。建议把公式条压到约 18 % 高，暗态项保留 40 % 不透明度。

### A2_08（193 nm 与 13.5 nm 波形对比）
画面：虚焦的机内实景上叠白色 193 nm 正弦和紫色 13.5 nm 密波，85 % 帧写「1 个 193 nm 波长 = 14 个 13.5 nm」。封顶：无（背景是实物虚焦，H14 通过）。
1. 紫色密波在 55 % 和 85 % 帧都冲出了右侧边界竖线，而且压在「13.5 nm」标签上。建议让波形在边界线处截止，标签移到边界外下方。
2. 紫波画成高亮细线，缩到样片尺寸后像弹簧，有锯齿。建议线宽加 30 %，加轻微辉光，或把振幅降到白波的 50 %，强化「更细的笔」。
3. 25 % 帧的紫波只画了 1/3，没有标签；13.5 nm 的名字可以从第一帧就挂上。

### B4_07（多层膜反射镜楔形剖切 + 电镜截面放大框）
画面：镜座上的圆镜切掉一个扇形，两束紫光在镜面上入射、反射，落点可见；推进到镜面顶层，圆形放大框里是灰阶 Mo/Si 截面，标注「钼/硅 × 40 对 · 每对约 7 nm · 只在镜面最顶层 · 总厚约 0.3 μm」。封顶：无。放大框锚点落在镜面顶层的白色薄膜上，指向正确；截面是灰阶，没有彩虹（H8 通过）；40 × 7 nm ≈ 0.28 μm，数值自洽。
1. 旁白要求「从镜面一路缩放到原子」，这里停在层级，没有到原子。建议在 85 % 帧放大框里再嵌一个小框，画一对 Mo/Si 界面的原子格点。
2. 镜体和镜座材质偏平：镜体是匀灰哑光块，镜座只有一圈螺栓，背景是空暗场。建议镜体切面做喷砂陶瓷质感（微糙 + 边缘倒角高光），镜座加 3 个柔性铰链和冷却管，背景虚化出一角真空腔壁。
3. 放大框里的刻度数字（10/20/30/40）太小，和条纹重叠。建议把刻度移到框外侧弧上。

### B4_10（地球 → 月球 → 高尔夫球，< 0.1 nrad）
画面：白色激光从地球射向月球，推进后镜头落到月面，光束打在一颗写实高尔夫球上。封顶：无。0.1 nrad ≈ 4 cm / 38 万 km，数值自洽。
1. 25 % 帧地月同框，距离被压缩了，但没有标「距离不按比例」（高尔夫球那一帧标了「尺寸示意」）。建议在月球标签里补一行「距离示意」。
2. 55 % 帧几乎只有月球和一根线，信息量偏空。建议这一段把机位推得更快，或者在光束上加一个缓慢移动的亮点，做出「飞行」感。
3. 月面和高尔夫球的材质都很好。光束从画面外斜着射入，可以在落点加一点散射和球面高光，让「打中」更明确。

### B6_12（倒装掩模 + pellicle，放大框说明间隙）
画面：卡盘吊着图形面朝下的反射掩模，下方是框装的 pellicle，掠射高光扫过膜面（有 k5A 那种「几乎看不见的膜」的感觉）；85 % 帧的放大框标出掩模图形面、几毫米间隙、13 nm 膜和「间距不按比例」。封顶：无（膜可见、有间隙，H1 不触发；没有彩虹，H8 不触发）。
零件辨识：静电卡盘、掩模、pellicle 框、吊臂 / 夹爪、冷却管、侧面相机 / 传感器筒，约 5 种；背景是纯黑虚空。
1. 25 % 和 55 % 帧里两条标注引线互相交叉，「保护膜」的引线指向画面下方，「反射掩模」的引线指向左边，读起来是反的。建议让引线不交叉：保护膜标签移到右下，接到膜边框的高光处。
2. 85 % 帧的放大框发暗、发糊，里面「膜」那一层几乎看不见。建议放大框内提亮 1.5 档，13 nm 膜画成一条亮白细线加掠射高光。
3. 背景是纯黑，看不出「装在机器里」。建议远处虚化出掩模台导轨、观察窗和气路面板，补一层景深，也是 brief 里「透明剖视」要的语境。

### B8_17（晶圆曝光场计数 188 / 185+ / 3.4 万+）
画面：投影物镜筒下的紫色光锥逐场照在晶圆上，右侧是片盒，计数器 43 → 143 → 188、124 → 185+、188 × 185 = 3.4 万+。封顶：无（188 场是 High-NA 数字，没有混代）。
零件辨识：物镜筒、晶圆工件台 / 卡盘、片盒（FOUP 内片架）、接线盒、电路板机架、线束 / 拖链、气路接头，约 7 种。背景不是同一种格子重复，密度好。
1. **计数器和画面进度对不上**：55 % 帧写着 143/188（≈ 76 %），但晶圆上已曝光的暗格只占右侧约 1/4。建议已曝光的暗格按计数逐格点亮，两者严格同步。
2. 场格数一眼核对不了 188：现在格子约 17 列 × 11 行，看不出整片是 188。建议格子按 High-NA 半场比例（26 × 16.5 mm）排，85 % 帧在晶圆旁小字标「188 场」。
3. 55 % 帧同时跑「场/片」和「片/小时」两个计数器，外行会搞混。建议改成先数完一片的 188 场，再切到片盒连续进出、开始数片/小时。

### B9_05（光子雨 + 每 nm² 计数放大框）
画面：紫色光子像雨点落在抗蚀剂线条上，圆形放大框九宫格计数从 3 → 16 → 20 累积；85 % 帧标注「剂量 ≈ 20 光子 / nm²（示意）· 落点随机 → 线条边缘起伏」。封顶：无。
和金控 B9_05 相比，分数高约 2：85 % 帧补上了剂量标注，计数均值约 20 且有散布（14–26），F 和 C 都对上了。这是像素内容的差别，不是尺度漂移。
1. 「落点随机 → 线条边缘起伏」只写在字里，画面上看不到因果：线条从第一帧就是锯齿的。建议 25 % 帧线条边缘平直，随光子累积，边缘逐步长出起伏。
2. 抗蚀剂是方块体素，有积木感。建议做成带圆角的连续条带，表面加微弱次表面散射，起伏用位移贴图而不是方块。
3. 光子画成带拖尾的亮滴，读法清楚。上方镜环（顶部弧形金属）可以再虚一些，避免和「光从哪来」打架。

### D_07（洁净室：设备内部 + 两名洁净服人物）
画面：实拍质感的洁净室长廊，左侧是去面板的设备（阀块、腔体、线束、管路），两名洁净服人物背影走向黄光区，机位轻推。封顶：无（人物有真实走动，机位在推，H2 不触发；没有写实人脸和标志）。
1. brief 要的「灯光一亮，巨物旁边出现人」没有发生：三帧光照不变，人从头到尾都在。建议 0–25 % 先压暗只留设备轮廓光，在 40 % 左右顶灯逐排亮起，人物在亮起后进入画面。
2. 「5100 家供应商」标注框的第二行是空的，排版有缺口。建议把行距收紧成两行，或补一行「和无数工程师」。
3. 三帧差异小，D 只给 84。建议把推轨速度提高一倍，或加一点焦点从设备转到人物的拉焦。

## 4. 本路最值钱的改法

1. **B8_17 计数器和曝光格严格同步**，并让场格比例能对出 188。这是本路唯一的语义错位，C/F 提到 90 就能 +2 分。
2. **D_07 补「灯光亮起 → 人出现」的事件**：现在是近静态的漂亮照片，补上叙事动作后 D 和 C 能各 +5。
3. **A2_03 / A0_06 / B6_12 去掉「重复格子墙」和纯黑虚空**：用 3–4 种可叫出名字的零件（波纹管、观察窗、气路面板、电源箱、离子泵）混排出景深，A 维能稳到 90+。
4. **B9_05 / B4_07 把机理因果画出来**：光子累积 → 线边起伏逐步长出；镜面 → 层 → 原子的最后一跳。C 能到 92 左右。
5. **标注层清洁**：引线不交叉（B6_12），波形不冲出边界、不压标签（A2_08），压缩了比例就标「示意」（B4_10）。
