  - H2：每镜三帧之间都有真实的机位、物体运动或读数变化。

## 每镜点评

### A0_10 片名卡 — 87.50
- **画面：** 白色衬线片名「一台光刻机里发生了什么」配紫色短线，下面是一台去壳的白色机架剖视。左边是光源腔，中间是照明系统的 Z 形紫光柱，右边是投影舱的 W 形光路；前景站着两个洁净服白模人，旁边标「人≈1.8 m / 机器为示意」。三帧里光束逐段点亮，机位缓慢推进。
- **封顶：** 无。H13 逐条过了：有实心镜和镜座，光是体积光柱，景深 ≥3 层，机架有壳厚，一条光路。没有仿 ASML 外观，也没有标志。
- **要改的：**
  1. 舱内多是重复的「绿 LED 盒 + 管件」贴图件，叫不出名字。把 3–4 个主模块（锡滴发生器、真空泵、掩模台、晶圆台）做成可辨认的造型，并降低重复率。
  2. 中段光束从 IF 出来后向上的走向和照明舱交代不清。让 IF → 场分面镜 → 光瞳分面镜 → 掩模的转折都落在可见的镜面上。
  3. 人物白模太干净、太小。给洁净服加褶皱和半逆光；尺度标签移到人物头顶，不要贴着字幕区。
- **对应的 Carl 点选：** k1C + k2B。
- **离锚还差：** k1C 的机身里有上千个真实零件，这里的密度大约只有它的 1/3，而且模块重复。

### A0_01 冷开场锡滴 — 88.30
- **画面：** 激光橙光束打中发光的锡滴；下一帧是近景的金属薄饼；最后一帧是紫色等离子球，左侧圆形放大框里画着 Sn⁸⁺…Sn¹⁴⁺ 离子和光子波线。
- **封顶：** 无。
- **要改的：**
  1. 放大框里的波浪光子线压住了「Sn⁸⁺」的上标。把离子标签移出波线，或者给标签加深色底。
  2. 背景腔体虚得太狠，只剩几条弧线。按 k3A 补出可读的金属腔壁、法兰和喷嘴，光比保持 ≥8:1。
  3. 第 2 帧薄饼占满画面但没有尺度。角上加一个「约 300 μm」的尺度线。
- **对应的 Carl 点选：** k3A + k3D。
- **离锚还差：** 腔体结构几乎看不见，没有 k3A 那种金属腔体包住紫光的「真东西」感。

### A0_02 夜间货机 — 88.00

- **离锚还差：** 没有金属腔体包围紫色辉光的层次，主体和背景的光比不够。

## 前 5 个全局差距（按问题类别）

1. **舱内细节重复、叫不出名字。** 2B 组 6 镜、B1_22、B8_17 的背景都用同一套 LED 盒加管件的贴图，结构可信度停在 85 上下。
2. **关键机理件缺席或画错形态。** C_03 和 B8_03 的掩模、B5_01 的场分面镜、B7_06 的 M5/M6 中心孔、A0_03 的集装箱，直接拉低 C 维。
3. **主体材质偏平涂，像 CAD。** 薄饼、切面基板、晶圆场格、光子雨胶面、掩模边框，缺少 k3A / k6C 那种金属和镀膜的高光层次。
4. **光源段的背景空洞、光比弱。** B1_08、B1_15、A0_01、B1_10 的腔体虚化成竖条墙或弧线，没有 k3A 的金属腔包裹感，主体与背景的光比不足。
5. **标注层排版。** 有标签重叠（B3_02）、引线落空或乱穿（A0_03、A0_06）、引线残留（B4_10 虚线）、一屏超过 3 组标注（B8_03）、色板外用色（B1_15 的橙色碎屑、B1_18 的粉色谱线、A2_08 的白色 193 波）。

## 最值钱的下一轮改法（按顺序）

1. **做一套 6–8 个可辨认的高精度舱内资产，全片复用，替换现在的 LED 盒贴件。** 资产清单：镜座 hexapod、真空腔法兰和观察窗、冷却管束、掩模台磁悬浮导轨、晶圆台平面电机、锡滴发生器、阀岛和线缆束。这一项同时抬 2B 组 6 镜加 B1 组的 A 维，预计 +3–5。
2. **补齐机理主角件。** 包括 C_03 和 B8_03 的反射掩模（带图形、入射和出射两束实心光锥、5.4° 示意）、B5_01 的弧形场分面镜阵列、B7_06 的 M5/M6 开孔镜，以及 A0_03 的 43 个集装箱。主要抬 C 维 +4–6。
3. **重做光源段。** B1_15 的等离子体换成体积辉光核，碎屑改成锡灰，修好镜口的白色锯齿瑕疵；B1_08 和 B1_10 补出 k3A 式的金属腔体与喷嘴。最低分镜头预计 +5。
4. **材质一轮。** 薄饼加液态金属高光，晶圆场格改成反光的图形，胶面做出半透明，镜面改成超光滑反射，切面用中性灰配抛光质感。
5. **标注层排版走一遍规范检查。** 去掉标签重叠和引线残留，每屏最多 3 组、集中到右上，色板只用紫、橙、青、白。这一项改动成本最低，E 维可整体 +3。
