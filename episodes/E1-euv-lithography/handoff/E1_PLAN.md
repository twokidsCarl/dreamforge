## 2. 每类镜头的工具（按 science-video-shot-routing 的决策顺序）

| 镜头类 | 例 | 工具 | 理由 |
|---|---|---|---|
| 机器内部结构、光路、镜子、掩模、工件台（photoreal / xray / blueprint / clay） | B3、B5、B6、B7、B8、C | **参数化 Blender**（现有 `build_machine.py` 等），不用 AI 生成 | 结构必须对（决策第 1 条）；Carl 和观众会逐项检验 |
| 看不见的物理（energy）：等离子体、衍射、EUV 光束、光子雨 | A2、B1、B9 | Blender 程序化 + 合成器（bloom 0.25 / 阈值 2.0、色散 0.004，按镜覆盖） | 要精确时序、对准关键词 |
| 纳米尺度（sem） | A1、B4、B6 | Blender sem 风格 | 结构可控 |
| 信息图、排版、HUD、光的账本 | A0_06、A2、B8、B9、D | `mograph`（Pillow 分层），每张加持续缓动 | 数字和文字要准；避免 H2 近静帧 |
| 纪实/环境（机场、车队、洁净室、大厅剪影） | A0_02、A0_03、D_06–07 | 先用 Blender 极简布景 + 雾 + 剪影；**P1 打分不过时**的备选：AI 静帧 + 图生视频（Wan）做无字背景板，标签后加 | 这类不涉结构，氛围优先；但 E1 的 WORKFLOW 只批了 Qwen TTS 和 ElevenLabs 两个付费工具，用 image2/Wan 要 Carl 同意 |
| 周边道具（货机、卡车、板条箱） | A0_02、A0_03 | 程序化建模、提升材质（去白模玩具感） | WORKFLOW 6.4 允许 Tripo/Meshy，但 `.env` 没有它们的 key，不能调用 |
| 品牌片头、片尾、号召 | sting_open / sting_end / end card | `brand/eigenlens_logo_locked/build.py` + end card 叠 eigenlens.ai | 标志锁定稿不改 |

一条规则：同一个镜头不混两套管线；文字一律后加，不进图生视频。
